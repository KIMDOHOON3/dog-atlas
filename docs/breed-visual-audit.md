# 견종 외형 일러스트 점검 기록

> 최초 점검: 2026-08-11
>
> 대상: 도감에 노출되는 카드 일러스트 368종, 그리고 교체 후보의 역사 일러스트
>
> 목적: 파일 무결성 검사와 실제 견종 외형 검수를 구분하고, 교체 우선순위를 지속해서 기록한다.

## 이 문서가 보장하는 범위

- 카드 자산 368종을 한 번에 비교할 수 있는 접촉 시트로 1차 시각 점검했다. 일반 카드 361개와 별도 앞면 카드 7개를 모두 포함했다.
- 외형 차이가 큰 후보는 원본 해상도로 다시 보고, FCI·AKC·국가 기관·학술 자료처럼 출처가 분명한 자료와 대조했다.
- 삽살개와 아래의 `교체 필요` 항목은 카드뿐 아니라 역사 장면에서 같은 잘못된 형태가 반복되는지도 확인했다.
- 이 점검은 전문 심사위원의 개별 견종 컨포메이션 심사가 아니다. 1차 점검에서 표시되지 않은 그림도 아직 `외형 승인 완료`로 간주하지 않는다.
- 기존 테스트가 확인하는 것은 경로, WebP 형식, 크기, 중복 여부다. 실제 귀·머리·체형·피모·꼬리·모색의 정확성은 이 기록의 별도 검수 절차를 따른다.

## 상태 기준

| 상태 | 의미 |
|---|---|
| 교체 완료 | 출처를 다시 확인하고 카드·역사 자산을 새 그림으로 교체함 |
| 교체 필요 | 현재 그림과 공식 외형 설명 사이에 큰 충돌이 확인됨 |
| 집중 재확인 | 잘못됐다고 단정할 단계는 아니지만 대표 특징이 약하거나 혼동 가능성이 큼 |
| 1차 점검 | 큰 오류는 즉시 발견되지 않았지만 개별 출처 검증은 아직 완료되지 않음 |

## 교체 완료

### 삽살개 (`sapsaree`)

기존 그림은 눈이 드러난 짧은 얼굴털, 뾰족하게 선 귀, 스피츠형 꼬리와 실루엣 때문에 삽살개보다 진돗개 계열 장모 변형처럼 보였다. 새 그림은 아래 특징을 우선했다.

- 눈을 대부분 덮는 풍성하고 긴 장모
- 털에 가려지는 늘어진 귀
- 중형의 단단하고 약간 긴 몸, 넓은 머리와 큰 발
- 짧은 털의 스피츠형으로 오해되지 않는 꼬리와 전체 실루엣

- 역사: `public/illustrations/v3/sapsaree-history.webp`

## 교체 필요

| 견종 | 현재 그림에서 확인한 큰 차이 | 우선 범위 | 비교 근거 |
|---|---|---|---|
| 아리에주아 (`ariegeois`) | 긴 털의 목양견 또는 흰 스피츠처럼 보인다. 실제 표준은 짧고 고운 털, 길게 늘어진 귀, 흰 바탕과 검은 무늬를 지닌 후각 하운드다. | 카드·역사 | [FCI 표준 20](https://www.fci.be/Nomenclature/Standards/020g06-en.pdf) |
| 빌리 (`billy`) | 뾰족한 귀와 말린 꼬리의 흰 스피츠로 표현됐다. 실제 표준은 납작하게 늘어진 귀와 짧은 털을 지닌 대형 하운드다. | 카드·역사 | [FCI 표준 25](https://www.fci.be/Nomenclature/Standards/025g06-en.pdf) |
| 둔커 (`dunker`) | 크림색 리트리버 또는 흰 스피츠에 가깝다. 실제 표준은 늘어진 귀, 짧고 단단한 털, 특징적인 흑·황갈 또는 블루멀 계열 무늬를 지닌 후각 하운드다. | 카드·역사 | [FCI 표준 203](https://www.fci.be/Nomenclature/Standards/203g06-en.pdf) |
| 아이디 (`aidi`) | 흰 스피츠의 선 귀와 단단히 말린 꼬리로 표현됐다. 표준은 반쯤 늘어진 귀와 길고 풍성한 꼬리를 설명하며, 영구적인 선 귀와 등에 단단히 말린 꼬리를 중대한 오류로 본다. | 카드·역사 | [FCI 표준 247](https://www.fci.be/Nomenclature/Standards/247g02-en.pdf) |
| 에스트렐라 마운틴 도그 (`estrela-mountain-dog`) | 흰색이 넓게 퍼진 전형적 가축보호견으로 그려져 고유 모색과 실루엣이 흐려졌다. 표준의 황색·황갈·회색 단색, 울프 그레이 또는 브린들 범위를 기준으로 다시 그려야 한다. | 카드·역사 | [FCI 표준 173](https://www.fci.be/nomenclature/Standards/173g02-en.pdf) |
| 댄디 딘몬트 테리어 (`dandie-dinmont-terrier`) | 정사각형에 가까운 흰 소형 장모견처럼 보여, 길고 낮은 몸·큰 머리·실키한 톱노트·늘어진 귀가 드러나지 않는다. | 카드·역사 | [AKC 견종 표준](https://images.akc.org/pdf/breeds/standards/DandieDinmontTerrier.pdf) |
| 사우스 러시안 셰퍼드 도그 (`south-russian-shepherd-dog`) | 카드의 얼굴과 몸 윤곽이 너무 또렷하고 피모가 짧아, 머리·다리·꼬리까지 덮는 거칠고 긴 셔기 코트의 핵심 인상이 약하다. | 카드 우선, 역사 재확인 | [FCI 표준 326](https://www.fci.be/nomenclature/Standards/326g01-en.pdf) |

## 집중 재확인

아래 항목은 현재 단계에서 `오류 확정`으로 부르지 않는다. 다음 이미지 교체 배치 전에 원본과 공식 자료를 다시 나란히 확인한다.

| 견종 또는 묶음 | 다시 볼 특징 |
|---|---|
| 베들링턴 테리어 | 배 모양 머리, 귀 끝의 술, 굽은 등선과 시미터형 꼬리가 작은 카드에서도 충분히 읽히는지 |
| 노르웨이안 룬데훈트 | 여분 발가락과 유연한 체형 같은 고유 특징이 단순화 때문에 사라지지 않았는지 |
| 마렘마 앤 아브루초 셰퍼드 | 카드의 꼬리가 평상시 형태보다 지나치게 높고 단단히 말려 보이지 않는지 |
| 페키니즈 | 넓고 납작한 얼굴, 앞부분의 체중감과 특유의 실루엣이 일반 장모 소형견으로 흐려지지 않았는지 |
| 스카이 테리어 | 매우 길고 낮은 몸, 큰 귀와 직선으로 떨어지는 긴 피모가 충분히 구분되는지 |
| 한국 토종견 스피츠형 묶음 | 진돗개·동경이 등 가까운 실루엣끼리 꼬리, 몸 비율, 귀와 지역적 특징이 서로 복제된 듯 보이지 않는지 |

## 다음 교체 배치의 검수 절차

1. 국제 표준이 있는 견종은 FCI 또는 국가 켄넬클럽 표준을 먼저 읽는다.
2. 국가 보존 토착견과 랜드레이스는 국가 기관·보존 기관·동료 심사 논문을 우선하며 FCI형 단일 외모를 억지로 적용하지 않는다.
3. 성견 참고 자료에서 머리와 귀, 몸 비율, 피모, 꼬리, 허용 모색을 각각 기록한다.
4. 카드와 역사 그림을 한 묶음으로 비교해 같은 잘못된 형태가 반복되지 않게 한다.
5. 전체 몸, 네 발, 귀, 꼬리가 카드 크기에서도 읽히는지 확인한다.
6. 검수 날짜와 출처, 변경 파일, 사용 프롬프트를 이 문서와 개별 프롬프트 기록에 남긴다.

화면에서는 개별 외형 승인이 끝나지 않은 그림을 `검수된 일러스트`라고 부르지 않고 `편집 일러스트`라고 표시한다.
