# 초소형견 첫 카드 · 치와와

앞면은 멕시코 돌마당에 선 전신, 뒷면은 같은 마당에서 앉은 성인의 신발 옆에 선 가까운 구도다. 기존 견종발견 치와와를 외형 참고로 사용했다. 크기 비교는 생성 삽화이며 실측 도식이 아니다. 지역의 일상 복장을 표현했다.

- FCI [치와와 표준](https://www.fci.be/Nomenclature/Standards/218g09-en.pdf): 원산지 멕시코, 반려견, 치와와주에서 유래한 이름, 몸무게 1–3kg. 표준은 키를 규정하지 않는다.
- VCA [Chihuahua](https://vcacanada.com/know-your-pet/chihuahua): 높이 6–9인치(약 15–23cm), 수명 14–16년을 참고 범위로 표기했다.
- 생성 도구: 내장 image_gen. [앞·뒷면 프롬프트](../design/card-backs/chihuahua-prompts.json).
- 최종 WebP: `public/illustrations/card-studies/chihuahua-front-v1.webp` (358,930B), `chihuahua-back-v1.webp` (189,316B).
