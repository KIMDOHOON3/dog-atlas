# 래브라도 — 착지와 도약의 물리 반응

`motion-refined`를 보존하고 몸통의 수작업 상하 곡선을 접촉 힘 계산으로 바꾼 별도 시안이다. 발로 체중을 받은 뒤 다시 밀어내는 변화와 머리·귀의 지연 반응을 검토한다. 원본 메시와 DQS 변형을 이어받았으며 얼굴과 털을 새로 조형하지 않았다.

## 계산하는 부분

- 사용자 정의 Python 솔버. 몸통은 질량 3kg, 중력 9.81m/s², 피치 관성 0.025kg·m²의 단순화한 물체다. 실제 자견의 계측값이 아니라 이 모델 크기에 맞춘 제작 매개변수다.
- 정해진 접지 구간에서 각 다리의 스프링 800N/m·감쇠 40N·s/m와 능동적인 길이 변화가 위쪽 지지력을 만든다. 지면은 몸을 아래로 당기지 않으며 다리당 힘 상한은 85N이다.
- 힘의 합에서 중력을 빼고 속도와 높이를 적분한다. 앞뒤 지지력의 모멘트와 자세 제어 토크로 몸통 기울기를 계산한다. 무하중 구간의 수직 가속도는 정확히 -9.81m/s²다.
- 머리와 귀 뿌리/끝은 몸통의 각가속도·상하 가속도에 반응하는 감쇠 스프링이다. 꼬리의 좌우 흔들기는 수작업 주기 동작을 유지한다.
- 고정 간격 0.0003125초로 계산하고 정상 반복 상태를 48장에 기록한다. 한 주기는 0.48초이며 Blender는 100fps다. 미리보기의 100fps는 샘플 시간 기준이며 모니터 실측 재생률을 뜻하지 않는다.

## 계산하지 않는 부분

전신 뼈·근육·관절의 강체 시뮬레이션이나 학습된 보행 제어기는 아니다. 발 순서·접지 시간·회수 경로는 정해져 있고, 발의 자세는 2관절 IK로 맞춘다. 수직·피치만 계산하며 수평 가속, 마찰, 지형 충돌, 넘어짐과 회복은 없다. 귀의 공기 저항도 모델링하지 않았다. 결과는 Blender 키프레임으로 저장되므로 Blender 재생 중 물리 엔진이 실시간으로 실행되지는 않는다.

관절 변형과 어깨 안쪽 주름, 뒷무릎 형상은 여전히 제한이 있다. 물리 계산의 통과는 실제 개와 같은 동작·포토리얼 품질의 판정이 아니다. 푸터 연결은 하지 않았다.

## 보기와 파일

`review.html`은 정지·¼ 속도로 시작한다. 새 시안과 이전 시안은 같은 주기 내 프레임을 유지하며 전환하지만, 정상 주기는 각각 0.48초/0.8초이고 접지 시간도 다르다. 이전 모션을 새 모션의 속도나 힘 값으로 표시하지 않는다.

- `exports/puppy-run-study.blend`: 22개 컨트롤러, DQS 메시/털과 1–48프레임 모션. 종점 49는 시작 자세와 같다.
- `textures/`: 상대 경로로 연결한 기존 4K 맵 4장. Blender 파일만 이동하지 말고 상위 폴더 구조를 유지한다.
- `frames/side`, `frames/three-quarter`: 실제 Cycles·AgX·960×720·24 samples 각 48장.
- `preview-*.webp`: 정상 480ms·¼ 속도 1,920ms 미리보기 4개.
- `../puppy-physics-run.zip`: 필요할 때 `package_motion.py`로 생성하는 전달용 묶음. 중복 용량 정리를 위해 2026-09-13 로컬 ZIP은 제거했으며 원본과 미리보기는 유지한다.

재생성은 전체 프로젝트와 기존 `motion-refined` 원본을 요구한다. Blender `--python build_physics.py -- build`로 만들고 `-- render side`/`-- render three-quarter`로 렌더한다. PNG가 모두 나온 뒤 Pillow가 있는 Python으로 `package_motion.py`를 실행한다. `.blend` 재생에는 제작 스크립트가 필요 없다.

## 검증

`reports/dynamics-verification.json`: 계산 간격을 절반으로 줄였을 때 높이 최대 차이 0.0314mm, 피치 최대 차이 0.000088rad. 평균 지지력 29.43N은 설정 체중과 수치 오차 범위에서 일치한다. 음의 지지력 없음, 뉴턴 힘 평형·무접촉 중력·중력 제거·정상 반복 루프 검사를 통과했다. 강성을 20% 낮추면 최대 높이 차이가 10.72mm 생겨 설정에 실제로 반응함을 확인했다.

`reports/verification.json`: Blender 재열기 검사. 몸통 높이 폭 41.38mm, 몸체·얼굴·귀·털 루프 차이와 누락 텍스처/비정상 좌표 0. 발바닥/발톱 최저점 +1.20mm. 힘이 0인 프레임과 모든 발이 떠 있는 프레임은 구분해야 한다. 주기 시작은 발끝 접촉과 힘 발생의 경계다. 피부와 발바닥 지지 높이·개별 메시 오류를 확인하지만 전체 자가 교차/털 충돌 전수 검사는 포함하지 않는다.

`verify_player.mjs`는 JSDOM으로 속도·프레임·비교 전환·힘 표시·화면 밖 정지와 이미지 경로를 확인한다. 실제 브라우저 렌더링이나 실기기 성능 측정은 포함하지 않는다.
