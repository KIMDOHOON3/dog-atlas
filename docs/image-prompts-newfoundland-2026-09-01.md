# 뉴펀들랜드 상세 이미지 프롬프트 기록 — 2026-09-01

## 생성 기준

- 생성 방식: Codex 내장 ImageGen, 대표 카드 이미지 참조 모드
- 최종 형식: 1200×900 WebP, Dog Atlas의 편집 수채화 질감
- 동일 개체 기준: 대표 카드와 같은 검은 성견 뉴펀들랜드. 길고 균형 잡힌 강한 몸, 깊은 가슴, 곧고 충분히 보이는 다리, 넓고 각진 주둥이, 작은 늘어진 귀, 촘촘한 장모성 이중모, 낮게 이어지는 굵은 꼬리를 유지한다.
- 공통 제외: 짧고 뭉툭한 비만 체형, 흰 가슴 무늬, 다른 견종, 여러 마리, 돌진, 제압, 팽팽한 리드, 강압 장비, 기본 입마개, 글자와 로고.

## 프롬프트 세트

1. `newfoundland-history.webp`
   - 19세기 후반 뉴펀들랜드 항구. 검은 성견 한 마리가 젖은 줄을 배 옆 어부에게 건네고 주변에 어망과 목선이 보이는 수상 작업 협력 장면. 개는 물속이 아니라 부두의 안정된 지면에 있고, 역사 편집 삽화의 차분한 거리감을 유지한다.
2. `newfoundland-feature-safe-water-entry.webp`
   - 오늘의 잔잔한 호숫가. 몸에 맞는 구명조끼를 입은 검은 성견이 미끄럽지 않은 낮은 출입 경사면의 얕은 물에서 스스로 보호자의 손 신호를 확인한다. 떠 있는 안전 라인은 느슨하고, 억지 입수나 구조 시범은 없다.
3. `newfoundland-feature-guided-turn.webp`
   - 한국의 넓은 공원 산책로. Y형 하네스를 착용한 검은 성견이 느슨한 J자 리드로 보호자에게 돌아와 보상을 받으며 방향을 바꾼다. 돌진·제압·팽팽한 리드·입마개는 없다.
4. `newfoundland-feature-massive-dog-route.webp`
   - 한국의 주거 공간 앞 대형 SUV. 보호자의 손 목표와 느슨한 리드를 따라 검은 성견이 넓고 낮은 미끄럼 방지 경사로로 스스로 차량에 오르는 장면. 사람이 개를 들어 올리거나 뒤에서 밀지 않는다.
5. `newfoundland-feature-wet-coat-drying.webp`
   - 현대 주택의 덮인 테라스. 큰 미끄럼 방지 매트 위 검은 성견의 귀 뒤와 가슴 속털을 보호자가 수건으로 나누어 말리고, 낮은 바람의 드라이어는 안전한 거리에 둔다. 개는 서서 편안하게 협력한다.
