## 생성 공통 프롬프트와 판정

공통 프롬프트는 따뜻한 한국어 편집 삽화용 수채·구아슈, 크림 종이 질감, 4:3 가로 화면, 성견 한 마리의 자연스러운 전신, 여유 있는 모바일 크롭을 고정했다. 강아지·추가 동물·사람·문자·로고·워터마크·콜라주·분할 화면은 금지하고, 각 프롬프트에 FCI 외형 표지와 장면의 안전 경계를 구체적으로 적었다.

- 생성 원본은 프로젝트에 귀속된 PNG로 보존하고 화면 자산은 1200×900, 품질 84 WebP로 변환했다.
- 40개 신규 파일의 경로는 상세 데이터의 네 장면 경로와 일치하며, 견종 안에서 다섯 장이 중복되지 않는지 자동 검사한다.
- 쿠바스 이중문 초안은 문이 열려 있어 폐기하고 두 문이 모두 닫히고 잠긴 장면으로 재생성했다.
- 샘플 육안 검수에서 체형 표지, 전신 노출, 장면 도구와 카피의 일치, 4:3 크롭을 확인했다.
- 이번 판정은 빠른 제작 초안 게이트다. 300종 완성 뒤 한국어 편집, 이미지 전수 비교, 전문가 검수를 별도로 진행한다.
