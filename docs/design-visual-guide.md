# 살아 있는 견종도감 비주얼 에셋 가이드

## 1. 목적

이 문서는 홈 → 재패니즈 스피츠 상세 → 유사 견종 → 2종 비교 흐름에 사용되는 이미지의 역할과 품질 기준을 정의한다.

핵심 원칙은 다음과 같다.

> 역사와 역할은 일러스트로 이해시키고, 실제 외형은 사진으로 확인시킨다.

일러스트는 감정과 맥락을 전달하는 장치이며, 사진은 사용자가 견종의 실제 모습을 오해하지 않도록 확인시키는 근거다. 둘 중 하나가 다른 하나를 대신하지 않는다.

## 2. 이미지 역할 분리

| 영역 | 기본 에셋 | 목적 | 허용되는 연출 |
|---|---|---|---|
| 홈 히어로 | 통일된 스타일의 일러스트 | 낯선 강아지와 마주치는 첫 감정 형성 | 단순 배경, 자연스러운 자세, 약한 모션 |
| 편집형 도감 섹션 | 일러스트 또는 단색 실루엣 | 계통·역할·발견 주제 구분 | 장면 중심 구도, 크기가 다른 편집형 배치 |
| 견종 상세 히어로 | 역할 장면 일러스트 | 견종이 왜 그런 행동 경향을 갖게 되었는지 설명 | 원래 역할과 환경을 포함한 장면 |
| 역사·계통 | 일러스트, 지도형 그래픽, 도식 | 시대·지역·역할의 맥락 전달 | 사실과 연출을 구분하는 캡션 |
| 실제 외형 확인 | 라이선스와 출처가 명확한 사진 | 체형·얼굴·피모·색상 다양성 확인 | 성견 중심, 필요한 경우 자견·측면·정면 보조 사진 |
| 행동·생활 정보 | 아이콘과 간단한 선화 | 정보 스캔과 비교 지원 | 장식보다 의미 전달 우선 |
| 건강·주의 정보 | 중립적인 도식 또는 이미지 없음 | 신뢰감과 가독성 유지 | 귀여운 캐릭터 연출 지양 |
| 유사 견종·비교 | 동일 조건의 사진 또는 중립 실루엣 | 견종 간 외형 차이를 공정하게 비교 | 같은 비율·배경·크롭 규칙 적용 |

## 3. 일러스트 스타일 원칙

### 기본 톤

- 따뜻하고 친근하되 유아용 캐릭터처럼 과장하지 않는다.
- 종이 도감이나 자연사 삽화처럼 차분한 질감과 제한된 색을 사용한다.
- 견종마다 화풍을 바꾸지 않고 선 굵기, 명암 단계, 배경 밀도를 통일한다.
- 머리만 크게 만드는 SD 캐릭터 비율을 사용하지 않는다.
- 옷, 왕관, 희귀도 효과 등 반려견을 수집 대상으로 보이게 하는 장식을 사용하지 않는다.

### 권장 구도

- 홈 히어로: 전신이 보이는 3/4 방향, 눈높이는 강아지와 비슷하게 설정한다.
- 역할 장면: 강아지만 크게 놓지 말고 환경과 대상까지 포함해 역할이 읽히게 한다.
- 상세 도입: 행동 중인 전신과 여백을 함께 두어 제목이 장면을 가리지 않게 한다.
- 비교: 감정적인 포즈보다 중립적인 서 있는 자세를 사용한다.

### 모션 적용 시

- 걷기, 귀 움직임, 시선 이동처럼 2~4초 안에 끝나는 미세 동작만 고려한다.
- 반복 모션은 주의를 빼앗지 않아야 하며 `prefers-reduced-motion` 대체 상태를 제공한다.
- 움직임이 없어도 모든 정보와 화면 구성이 완성되어야 한다.
- 첫 MVP에서는 정적 일러스트를 기본으로 하고 반응이 확인된 히어로 한 장면만 모션 후보로 둔다.

## 4. 생성형 일러스트 외형 정확성 체크

생성 결과는 분위기보다 아래 순서로 검수한다. 하나라도 핵심 오류가 있으면 수정하거나 사용하지 않는다.

### 공통 체크리스트

- 성견 기준의 실제 신체 비율과 크기감이 유지되는가?
- 주둥이 길이, 머리 형태, 귀의 모양과 위치가 대표적인 외형 범위 안에 있는가?
- 몸통 길이, 다리 길이, 가슴 깊이와 꼬리 형태가 다른 견종과 섞이지 않았는가?
- 단모·장모, 이중모, 털의 흐름과 볼륨이 실제 구조와 맞는가?
- 해당 견종에서 인정되거나 실제 관찰되는 색과 무늬 범위인가?
- 발가락, 다리 관절, 눈, 치아, 꼬리가 비정상적으로 생성되지 않았는가?
- 자견의 특징을 성견처럼 표현하거나 반대로 성견을 지나치게 아기처럼 만들지 않았는가?
- 귀·꼬리 절단 등 인위적 외형을 기본 모습처럼 미화하지 않았는가?
- 비만 또는 과도하게 마른 체형을 대표 외형처럼 사용하지 않았는가?
- 역사적 역할 장면이 실제 역할과 배치되지 않는가?
- 특정 개체의 사진을 그대로 복제한 듯한 구도·무늬·배경이 아닌가?

### 첫 5개 견종 검수 항목

아래 항목은 이미지 제작 전 공식 견종 표준과 신뢰할 수 있는 다각도 사진을 참고해 더 구체화한다. 이 목록만으로 외형을 확정하지 않는다.

- 재패니즈 스피츠: 쐐기형 얼굴, 직립 귀, 풍성한 이중모, 등 위로 올라가는 꼬리, 포메라니안이나 사모예드와 혼동되는 체격 과장 여부
- 몰티즈: 작은 체격, 길고 곧게 흐르는 흰 피모, 얼굴과 주둥이 비율, 비숑 프리제처럼 곱슬거리게 표현되는 오류
- 보더콜리: 운동성 있는 중형 체형, 다양한 피모와 색의 가능성, 흑백 무늬만 유일한 표준처럼 고정하는 오류
- 그레이하운드: 깊은 가슴, 잘록한 허리, 긴 다리와 유선형 체형, 지나치게 마르거나 위협적으로 표현하는 오류
- 사모예드: 중대형 체격, 풍성한 이중모와 스피츠형 실루엣, 재패니즈 스피츠를 단순 확대해 놓은 것처럼 표현하는 오류

### 검수 절차

1. 제작 전에 견종별 레퍼런스 보드에 공식 표준 출처 1개 이상과 실제 성견 사진 3장 이상을 둔다.
2. 첫 결과물은 디자이너가 공통 체크리스트로 검수한다.
3. 외형이 비슷한 견종끼리 나란히 놓고 차이가 유지되는지 교차 검수한다.
4. 상세 페이지 공개 전 견종 경험자 또는 전문가에게 사실 오류만 확인받는다.
5. 승인된 이미지에는 검수일, 참고 출처, 생성·수정 방식을 내부 메타데이터로 남긴다.

## 5. 실제 사진 사용 원칙

- 직접 촬영, 명시적 사용 허가, 상업적 사용이 가능한 라이선스 중 하나만 사용한다.
- 검색 결과나 SNS 이미지를 출처 표기만 하고 가져오지 않는다.
- 사진마다 원작자, 원본 URL, 라이선스, 다운로드일, 수정 여부를 기록한다.
- 인물이나 식별 가능한 위치가 포함된 사진은 모델·장소 사용 권한을 별도로 확인한다.
- 대표 사진 한 장만으로 견종 외형 전체를 일반화하지 않는다.
- 실제 외형 영역은 가능하면 성견 전신 측면, 성견 얼굴, 피모·색상 차이 순으로 구성한다.
- 극단적으로 미용된 모습, 의상 착용, 광각 왜곡, 과도한 보정 사진은 외형 확인용으로 사용하지 않는다.
- 비교 화면에서는 두 견종에 같은 크롭 기준과 비슷한 촬영 각도를 적용한다.

사진 메타데이터 예시:

```yaml
asset_id: japanese-spitz-adult-side-01
breed: japanese-spitz
creator: "작가명"
source_url: "원본 URL"
license: "라이선스 명칭"
downloaded_at: "YYYY-MM-DD"
modifications: "crop, brightness"
usage: "breed-detail / appearance"
```

## 6. 사진 없는 MVP 플레이스홀더

사진을 확보하지 못한 상태에서도 깨진 이미지나 임의의 생성 사진을 넣지 않는다. 초기에는 아래 순서로 대체한다.

### 1순위: 중립 실루엣 카드

- 승인된 일러스트에서 외곽선만 추출한 단색 실루엣을 사용한다.
- `실제 외형 사진 준비 중`이라는 짧은 상태 문구를 함께 표시한다.
- 견종별 고유 실루엣을 사용하되 세부 외형을 증명하는 자료처럼 보이게 하지 않는다.

### 2순위: 형태 체크 도식

- 전신 실루엣 주변에 `중소형`, `직립 귀`, `이중모` 같은 검증된 핵심 항목만 배치한다.
- 불확실하거나 개체 차이가 큰 항목은 넣지 않는다.
- 도식 하단에 `대표적 경향이며 개체 차이가 있음`을 표기한다.

### 3순위: 비주얼 없이 텍스트 우선

- 사진 영역을 억지로 채우지 않고 견종명, 계통, 역할, 핵심 설명으로 레이아웃을 완성한다.
- 배경 질감과 타이포그래피만으로 빈 공간의 의도성을 만든다.
- 사진이 나중에 추가되어도 정보 순서와 페이지 높이가 크게 바뀌지 않도록 고정 비율 슬롯을 유지한다.

금지하는 플레이스홀더:

- 견종과 무관한 일반 강아지 사진
- 출처를 확인하지 않은 스톡 이미지
- 실제 사진처럼 보이는 미검수 생성 이미지
- 모든 견종에 같은 강아지 아이콘 사용
- `이미지 없음`만 표시된 회색 박스

## 7. 개발 전달 규격

### 권장 슬롯

| 슬롯 | 비율 | 최소 제공 크기 | 모바일 초점 |
|---|---:|---:|---|
| 홈 히어로 일러스트 | 4:5 | 1200×1500 | 전신과 얼굴이 중앙 60% 안에 위치 |
| 역할 장면 | 16:9 | 1600×900 | 핵심 행동이 중앙 70% 안에 위치 |
| 실제 외형 사진 | 4:3 | 1200×900 | 크롭해도 귀·발·꼬리가 잘리지 않음 |
| 견종 카드 | 1:1 | 800×800 | 얼굴만 확대하지 않고 실루엣 유지 |
| 비교용 사진 | 3:4 | 900×1200 | 서 있는 전신, 같은 여백 규칙 |

### 파일과 구현

- 파일명: `{breed}-{usage}-{view}-{index}.{ext}`
- 예시: `japanese-spitz-appearance-side-01.webp`
- 사진은 WebP 또는 AVIF를 우선하고 원본 보관 경로를 분리한다.
- 일러스트가 투명 배경을 필요로 하면 SVG 또는 투명 WebP를 사용한다.
- `srcset`과 `sizes`를 제공하고, 첫 화면 히어로 외 이미지는 지연 로딩한다.
- 이미지의 고유 크기를 지정해 레이아웃 이동을 방지한다.
- 대체 텍스트는 감상 문구가 아니라 보이는 내용과 정보 목적을 설명한다.
- 장식용 배경 일러스트는 빈 대체 텍스트를 사용하고 본문에서 같은 정보를 제공한다.
- 사진이 없을 때 사용할 플레이스홀더 상태를 컴포넌트 API에 포함한다.

권장 에셋 상태:

```ts
type BreedVisualStatus = 'illustration-approved' | 'photo-approved' | 'placeholder';
```

## 8. 첫 MVP 적용 범위

- 홈: 낯선 견종 히어로 1장, 편집형 역할 장면 2장, 견종 카드용 실루엣 5종
- 재패니즈 스피츠 상세: 역사·역할 일러스트 1장, 실제 외형 사진 슬롯 3개, 생활 정보용 선화
- 유사 견종: 재패니즈 스피츠와 사모예드의 실루엣 또는 승인 사진
- 비교: 두 견종의 동일 조건 전신 이미지 각 1장

사진 확보가 늦어지면 승인된 실루엣과 형태 체크 도식으로 먼저 출시할 수 있다. 단, 해당 화면을 `실제 외형 확인`이라고 부르지 않고 `대표 형태 살펴보기`로 명확히 구분한다.

## 9. 출시 전 최종 확인

- 일러스트만 보고 실제 외형을 확인했다고 오해할 가능성이 없는가?
- 매력적인 장면 바로 다음에 가정에서 필요한 책임이 연결되는가?
- 비슷한 견종의 이미지가 서로 구별되는가?
- 사진의 라이선스와 출처 기록이 완전한가?
- 모바일 크롭에서 귀, 발, 꼬리 등 핵심 형태가 잘리지 않는가?
- 이미지가 없어도 텍스트 정보와 탐색 흐름이 완성되는가?
- 건강·주의 영역이 지나치게 귀엽거나 가볍게 보이지 않는가?
