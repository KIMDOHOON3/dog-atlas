# 원고 3차 점검과 README 조정 — 2026-10-24

사용자 요청에 따라 로컬에서만 수정했다. 커밋·푸시·배포는 하지 않는다. 이전 작업은 [2차 보고서](rights-second-pass-2026-10-24.md)에 보존한다.

## README

서비스 소개를 중심에 두고 ‘로컬에서 둘러보기’와 실행 명령은 제거했다. 마지막에 사용 기술 한 문단과 주요 폴더의 역할을 짧게 추가했다. 실행·환경변수·검증·배포 절차는 [개발 안내](development.md), 상세 배치 규칙은 [코드 구조](code-structure.md)에 둔다. 이번에는 폴더를 다시 이동하거나 제품 기능을 바꾸지 않았다.

## 검토 범위와 결과

## 기록과 누적 수치

- [이번 검토 39곳](audits/editorial-third-pass.json)에 실제 데이터 위치, 최종 문장, SHA-256, 출처, 수정·유지 이유를 기록했다. 이전 오스트레일리안 셰퍼드 유지 판단은 `supersededDecisions`에 보존했다.
- [수정 기록](audits/editorial-rights-changes.json)은 후속 점검 누적 **53종 80개 텍스트 단위**다. 견종 전체를 검수한 수치가 아니다.
- 활성 유지 기록은 이전 정적 기록 14곳과 이번 실제 데이터 기록 22곳, 합계 36곳이다. 이전 보고서의 유지 15곳 중 1곳이 수정으로 바뀌었으므로 단순 합산하지 않는다.
- `pnpm audit:rights`가 이번 39곳을 실제 모듈에서 불러와 견종·공개/원본 구분·필드·문장·해시까지 검증한다. 기록 중복 또는 문장 불일치는 실패한다. 조합된 문장을 정적 문자열 검사만으로 확인했다고 처리하지 않는다.
- `pnpm audit:editorial`의 정적 선별 범위는 비테스트 소스 145파일, 한국어 문자열·JSX·템플릿 조각 11,112개다. 수정 기록 80곳과 이전 활성 유지 기록 14곳의 존재를 확인한다. 이번 실제 데이터 검증 39곳과 집계 단위가 다르다.
- 자동 후보 0은 전체 원고의 대조 완료나 저작권 승인이라는 뜻이 아니다. 다른 문단과 전체 외부 원문 유사도, 건강·행동 정보의 전문가 검수는 남아 있다.
- 이미지 파일은 변경하지 않았다. 공개 자산 1,880개는 기존 HEAD와 동일하며 기존 제작 기록·사용자 진술 분류를 유지한다.

## 검증

- `pnpm lint`, `pnpm typecheck` 통과.
- `pnpm test --maxWorkers=4`: 65파일·1,717테스트 통과. 기존 테스트를 삭제하거나 문구 검사를 약화하지 않았다.
- `pnpm build`: 프로덕션 빌드 성공, 387페이지 생성.
- `pnpm audit:editorial`, `pnpm audit:rights` 통과. 실제 데이터 39곳 일치, 공개 자산 1,880개 HEAD 동일성 유지. 이전 오스트레일리안 셰퍼드 유지 기록의 문장 변경을 감사가 감지해, 기존 판단을 보존하고 수정 기록으로 전환했다.
- 로컬 Chrome에서 홈+15종 상세를 PC1440px·모바일390/320px, 총 48화면 확인: HTTP 200, 가로 넘침·JavaScript 오류 없음. 공개 수정 5종의 본문과 화면에 보이는 이미지의 로딩·디코딩을 확인했다. 셔틀랜드 모바일·복서 PC 캡처로 줄바꿈과 배치를 추가 확인했다.
- 문서 내부 링크·Git diff 공백 검사 통과. 실기기 iOS는 미검증.
- 검증한 프로덕션 빌드를 http://127.0.0.1:3000/ 에서 실행 중이다. 로그·캡처는 Git에서 제외된 `tmp/rights-third-*`에 있다. 커밋·푸시·배포 없음.
