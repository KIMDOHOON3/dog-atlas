# 함께 갈 곳 — 사진 없는 공공데이터 장소 안내

2026-09-14 사용자가 장소 탐색 범위를 다시 승인했다. 푸터의 애견카페 마당 안내판에서 `/places`로 이동한다. 사진, 지도 SDK, 병원 데이터는 추가하지 않는다.

## 데이터 연결

- 공식 서버: `https://apis.data.go.kr/B551011/KorPetTourService2`. 이전 버전은 실호출에서 400, 현재 버전은 기존 `PUBLIC_DATA_PET_TOUR_SERVICE_KEY`로 정상 응답했다. 키는 `.env.local` 및 배포 환경의 같은 서버 변수에서 읽는다. 환경 파일은 Git 제외이며 키를 클라이언트로 전달하지 않는다.
- 목록: `areaBasedList2`, 이름 검색: `searchKeyword2`, 지역: `ldongCode2`. 초기 화면은 산책·관광이며 모든 장소 또는 음식점/숙박 등 다른 유형도 선택 가능하다. 20개씩 실제 총수 기반 페이지 이동, 지역·유형·검색어를 URL에 보존한다.
- 상세: `detailCommon2` + `detailIntro2` + `detailInfo2` + `detailPetTour2`. 제목/주소/소개, 운영·이용 정보, 반복 안내, 동반 조건을 표시한다. 빈 값은 생략하고 기술 코드/좌표/등록·수정 시각은 펼쳐보기에 둔다. 알려지지 않은 텍스트 필드도 버리지 않는다.
- 이미지 전용 API를 호출하지 않는다. 응답의 image/photo/img 필드는 서버에서 제거하고, 원격 HTML은 텍스트로 바꾼다. 장소 화면에 이미지·빈 썸네일·원격 이미지 요청이 없다.
- Zod 응답 검증, 12초 요청 제한, 정제한 응답 1시간 캐시. 오류는 인증 URL을 포함하지 않는 공통 문구로 바꾼다. 상세 부가 조회 중 일부 실패 시 성공한 정보는 유지하며 실패와 미제공을 구분한다.
- 출처는 한국관광공사·공공데이터포털로 표시하며 방문 전 운영·동반 조건 확인을 안내한다. 공식 서비스 설명: https://www.data.go.kr/data/15101578/openapi.do (국문 서비스의 공통 상세 항목 설명). 실연결은 반려동물 전용 서비스다.

## 마당과 접근성

Blender에 8패널 크림 파라솔, 원형 원목 테이블, 의자 2개, 뒤쪽 부분 울타리를 추가했다. 정적 재질 병합과 독립 장난감 루트를 유지한다. GLB 1,330,920B / 18메시 / 41,084삼각형. 새 가구의 단순 충돌체도 추가했다. 이전 Blender 안내판은 제거하고 Three.js에서 별도 생성한다.

사용자가 HTML 문구를 얹은 이전 표현을 거절했다. 이제 안내판의 판자·기둥·덮개·나사와 글씨 모두 `yard-sign.ts`의 Three.js 메시다. 표면 글씨는 투명 CanvasTexture를 Standard 재질로 입혀 카메라·조명·가림을 따른다. Raycaster로 실제 보드를 클릭하며 터치는 최소 44px에 맞춘 보이지 않는 3D 판정 볼륨을 사용한다. 드래그·pointercancel은 이동을 취소한다. 화면에 HTML 문구를 얹지 않는다. 시각적으로 숨긴 의미 링크는 키보드/스크린리더와 WebGL 실패 시 대체 이동에 사용하며, 키보드 포커스는 3D 재질 강조로 표시한다. 링크 prefetch를 끄고 클릭 시에만 장소 데이터를 조회한다.

## 검증

기존 키로 전체 9,679개, 산책·관광 752개 응답 확인(조회 시점 수치). `애견` 이름 검색과 삼막애견공원 상세에서 실제 운영시간·주차·이용료·동반조건 표시를 확인했다. 새 테스트는 사진 필드 제거, HTML 정제, 빈/단일/오류 응답, 요청 범위 검증, 비밀이 포함된 오류 차단, 상세 부분 실패 유지, 잘못된 ID 차단을 다룬다.

배포 환경에도 `PUBLIC_DATA_PET_TOUR_SERVICE_KEY`가 필요하다. 로컬 파일이 Vercel로 자동 전송되지는 않는다.

공개 배포 검증: 기능 커밋 c8286a4의 Vercel 배포 성공, 공개 마당/안내판과 GLB HTTP 200 확인. 공개 장소 목록은 조회 실패 상태이며 로컬 목록·상세는 정상이다. Vercel 로그인/CLI 인증이 없어 배포 키 설정과 서버 로그를 아직 확인하지 못했고 사용자에게 로그인을 요청했다. 키 미설정으로 단정하지 않는다.
