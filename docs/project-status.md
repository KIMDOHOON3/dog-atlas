# Dog Atlas 프로젝트 현재 상태

> 마지막 갱신: 2026-09-06. 현재 상태의 진입점이며 이전 실험 분석은 정리했다.

## 제품과 보존 범위

- 메인 `/`: 초대형견 8종의 양면 수채화 카드. 그레이트 피레니즈·세인트 버나드·그레이트 데인·아이리시 울프하운드·티베탄 마스티프·캉갈 셰퍼드 도그·코카시안 셰퍼드·몽골 방카르.
- `/discover`: 전체 376종의 발견·검색·필터·국내 익숙한 견종 시작 목록. URL/뒤로가기 상태와 점진 표시를 유지한다.
- 모든 `/breeds/[slug]` 상세와 기존 원고·그림·데이터·공통 로직을 보존했다. 8종 이외의 상세도 삭제하지 않았다. 등록된 표준 상세와 제작 초안의 구분을 유지한다.
- 상세가 연결하는 `/beginner-guide?breed=...` 및 진행 상태를 보존한다. 상세 디자인 재구성과 다른 크기 카드 추가는 다음 논의 대상이다.

## 현재 카드 디자인과 성능

- 사용자가 30개 후보 중 로고 **L01**, 뒤집기 **F08**, 자세히보기 **D10**을 최종 승인했다. 한글 로고와 32px 아이콘을 승인된 원래 색으로 적용했다. 현재 견종 상세 링크·모바일 두 버튼·prefetch OFF를 유지한다. 정적 WebP 3개 합계 53,760B이며 렌더러 변경은 없다. [승인 자산과 프롬프트](brand-mark.md).
- 사용자 요청으로 비교 페이지·3003 서버·미선택 시안·이전 로고/아이콘 실험 자산을 정리했다. 승인된 PNG 3개와 프롬프트만 `design/brand/`에 보존했다. 기록된 미선택 생성 원본 35개도 삭제했다.

- 앞면은 견종 전신·역사 배경, 뒷면은 사람 옆 크기 비교와 출신/국기·크기·수명·짧은 역사. 생성 그림은 비교 예시이며 정확한 측정 도식이 아니다. 방카르 수명은 자료 부족으로 남긴다.
- 현재 이동은 실제 WebGL 격자/버텍스 변형이다. 다음 카드는 위부터 왼쪽으로 휘어 빠지고, 이전 카드는 왼쪽에서 돌아와 펴진다. 카드 전체 HTML을 준비 단계에서 텍스처로 캡처하며 그림·글이 함께 휜다. 이동은 820ms다.
- 포일 1개와 전환 1개의 캔버스/컨텍스트를 재사용한다. 전환 때 기본 포일 렌더링은 멈추며 두 면만 그린다. 최대 60Hz·110만 픽셀·GPU 텍스처 LRU 4장으로 제한하고 유휴/숨김/화면 밖에서는 중지한다. reduced motion은 즉시 교체하며 WebGL/캡처 실패만 CSS 대체 경로를 사용한다. [구현·예산·검증 한계](card-transition.md).
- 번호 선택 밑줄, 카드 이미지 뒤집기 아이콘과 순차 문구 전환, 붉은 ON 표시등·강도·빛 시연을 유지한다.

## 2026-09-06 승인된 정리

- 사용자는 현재 메인·견종발견·모든 상세와 공유 파일 보존을 최종 승인했다. 이전의 과도한 2,078개 삭제안은 폐기했다.
- 기존 메인 전용 스타일/생활조건 컴포넌트·이름/주제 탐색·중복 card-lab, 게임·퀴즈·엽서, 장소 검색·공공 API 수집 데이터·카카오 지도, 영상 분석 및 관련 임시 자료를 삭제했다.
- 305개 기능/분석 파일과 참조 없는 이미지 6개를 삭제했다. 이미지 참조 검사는 로컬 콘텐츠를 실행해 동적 경로도 확인했으며, 남은 1,794개 이미지는 보존했다.
- 지도 전용 proj4와 전용 의존 패키지를 manifest/lock에서 제거하고 메타데이터·사이트맵·메뉴를 남은 경로에 맞췄다. API 키 환경 파일은 변경하지 않았다.
- 상세·발견 제작 지침과 현재 카드 자산/출처 문서는 보존했다. 내용은 편집 초안이며 수의사·행동 전문가 검수 완료로 표시하지 않는다.

## 검증

- L01/F08/D10 최종 적용: lint/typecheck·51파일 1,646테스트·385페이지 빌드 통과. 3000/3001 반영. 실제 인앱 메인과 390px에서 배치 확인, 8종 상세 링크 200·방카르 상세 클릭 진입·두 버튼 한 줄·46px 터치 높이·브라우저 오류 없음. 비교 페이지 삭제와 3003 서버 중지, 승인 PNG 보존 해시 확인. 사용자가 오늘 작업 커밋과 main 푸시를 승인했다.

- 장식 축소 후 lint/typecheck·51파일 1,646테스트·385페이지 빌드 통과, 3000/3001 반영. 실제 인앱 화면에서 한글 텍스트 로고와 낮은 대비 버튼 확인. 390px에서 두 버튼 한 줄·46px 높이·가로 넘침 없음, 8종 상세 HTTP 200 및 실제 상세 클릭 확인, 브라우저 오류 없음.

- 한글 로고·카드 행동 버튼: lint/typecheck·385페이지 빌드 통과. 전체 1,646개 실행 중 로고 추가에 따른 기존 이미지 선택자 2개 실패를 카드 그림 이름으로 교정했고 해당 16개 재실행 통과(나머지 1,630개 통과). 인앱 화면과 390px Chrome에서 가로 넘침 없음·두 버튼 한 줄·최소 높이 46px 확인. 8종 링크 모두 HTTP 200, 방카르 상세 실제 클릭 진입, 브라우저 오류 없음. 3000/3001 반영.

- WebGL 이동 후속: lint·typecheck·51파일/1,646테스트·385페이지 빌드 통과, 3000/3001 반영. 실제 Chrome 22개 전환(8종 앞뒷면·모바일·포일 OFF·reduced motion) 오류 없음. rAF p95 최대 20.9ms, 33.4ms 초과 간격 총 1회. 최종 인앱 프로덕션 전환은 p95 20.8ms·33.4ms 초과 0회, 캐시 준비 상태에서 클릭 후 준비 2.00ms였다. 기본 포일은 전환 중 정지, 완료 후 HTML 복귀·캐시 4장·유휴 중지 확인. 이는 로컬 CPU/rAF 측정이며 실기기 GPU/표시 FPS 보장이 아니다.

- 슬라이드 후속 수정: lint·typecheck·51파일/1,644테스트·385페이지 빌드 통과, 3000/3001 반영. 데스크톱과 390px 실제 전환에서 이전 카드의 음수 X 위치·위쪽 레이어·완료 후 모션 상태 제거를 확인했다. 유휴 main 이미지 3개(앞/뒤/버튼), 전환 중 4개, 캔버스 1개. 가로 넘침·브라우저 오류/경고 없음. 기기별 FPS 개선율은 측정하지 않았으며 사용자 체감 확인이 남아 있다.

- 정리 후 lint·typecheck·51파일/1,643테스트·385페이지 production build 통과. 3000/3001에 반영했다. 오래된 Next 개발 타입 캐시를 지운 후 깨끗하게 빌드했다.
- 실제 브라우저에서 메인→견종발견→말티즈 상세 진입, 데스크톱/390px 이미지·레이아웃과 오류 없음을 확인했다. 유지 경로는 HTTP 200, 제거한 장소/게임/엽서/이름/주제/card-lab 경로는 404다. 동적 콘텐츠까지 평가한 이미지 검사에서 1,794개 모두 참조되고 미사용 0개다.
- 이전 카드 전환 검증: 데스크톱/390px, 앞뒤·정역 이동·홀로그램 OFF, 단일 캔버스·가로 넘침/브라우저 오류 없음. 실제 모바일 기기의 GPU 성능과 사용자 체감 평가는 별도다.
