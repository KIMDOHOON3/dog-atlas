## 서비스와 코드

- 홈 `/`: 소형 16·중형 12·대형 13·초대형 8, 총 49종의 양면 수채화 카드. 검색은 전체 376종의 이름·별칭을 지원하며 카드가 있으면 카드, 없으면 상세로 이동한다. 서비스 소개, 크기 선택, 한 장/펼쳐보기, 뒤집기를 제공한다.
- `/discover`: 376종의 견종 검색·필터. `/breeds/[slug]`는 기존 상세와 원고를 유지하고, 공개 표준 상세·제작 초안·보류 상태를 구분한다. 모든 원고가 전문가 검수를 마친 것은 아니다.
- 메인 카드 49종의 앞면을 `content/card-front-art.ts`에서 공통 관리한다. 견종발견·상세 대표 이미지·관련 견종·공유 메타데이터도 같은 그림과 대체 텍스트를 사용한다. 메인과 견종발견은 같은 상세 URL로 연결된다. 카드가 없는 327종과 역사·돌봄 본문 그림, 견종별 상세 템플릿은 유지한다.
- 메인·견종발견 검색 제안도 공통 이미지·카탈로그 별칭을 사용한다. 운영 카드의 크기·수명은 서버에서 상세와 같은 크기 프로필·수명 표시 데이터로 구성하고 미제공 수치를 채우지 않는다. 토이푸들·포메라니안·미니어처 닥스훈트의 대표 유형을 먼저 표시하며 다른 유형은 별도 펼치기로 구분한다. 모든 상세는 흰 배경의 공통 상단 정보·탐색 링크와 하단의 견종 발견/견종 카드 이동 영역을 제공하며 본문 내용·제작 상태는 유지한다.
- 견종 상세의 ‘유전 질환과 검사 기록’, ‘정보 출처와 편집 안내’ 접기 영역은 사용자 요청으로 제거했다. 조사 원고와 출처 데이터는 내부에 보존한다. 크기의 ‘크기 정보 보완 중’·‘공식 수치 확인 중’ 문구를 제거하고 제공된 수치만 표시한다. 불완전한 크기를 임의 분류하지 않는다.
- 맞이 준비 기능은 종료했다. 설문·점수·진행률에 더해 상세 하단의 첫 생활 안내·준비 가이드 버튼과 `/beginner-guide` 페이지·전용 컴포넌트도 제거했다. 공통 상세 정리 중 잘못 복원한 진입점을 다시 추가하지 않는다. 내부 원고·출처 자료는 보존한다.
- `/places`와 `/places/[id]`: 사진 없는 공공데이터 장소 검색·동반 조건·전화·주소·카카오맵 길찾기. 내 주변 검색은 사용자가 실행할 때 위치 권한을 요청하며 직선거리를 표시한다. 실시간 입장 여부·이동시간은 제공하지 않는다.
- 공통 상단 메뉴에 ‘함께 갈 곳’을 제공한다. 모든 견종 상세 하단에는 흰 배경·갈색 버튼의 장소 탐색 안내를 표시하고 방문 전 동반 조건 확인을 안내한다. 3D 운동장은 홈에만 유지하며 장소 목록·상세에는 같은 안내를 반복하지 않는다. 새 링크의 자동 prefetch는 끈다.
- 코드는 `src/app`의 라우트와 `src/features`의 기능별 구현으로 나뉜다. 공통 UI는 `components`, 공통 로직은 `lib`·`hooks`, 원고는 `content`에 둔다. [폴더별 역할](code-structure.md).
- Next.js App Router·strict TypeScript·CSS Modules·로컬 콘텐츠/Zod를 유지한다. 데이터베이스·로그인·CMS·커뮤니티는 범위 밖이다.

## 현재 화면과 운동장

- 메인·견종 발견·견종 상세·장소 목록/상세의 첫 화면에 공통 등장 모션을 적용한다. 주요 구역이 70~140ms 간격으로 나타나며 전체 760ms 이내에 끝난다. 이동량은 모바일 10px·PC18px이다. 검색 선택·필터 변경·스크롤마다 재생하지 않으며 공유 헤더는 움직이지 않는다. 동작 감소 설정에서는 모션 없이 표시한다.

- 사용자 피드백으로 검색 카드의 테두리 강조·들림·전용 자동 스크롤 효과를 제거했다. 검색은 카드 선택 또는 상세 이동만 수행하고 펼쳐보기의 검색 확대는 유지한다. 뒤집기·상세 보기·확대/닫기·장난감 초기화는 누르는 동안 짧은 눌림 반응을 제공한다.
- 흰 배경·갈색 강조와 수채화 카드가 기준이다. 첫 화면은 ‘그림으로 만나는 견종도감’과 역사·성격·돌봄 소개, 카드 뒤집기 안내를 보여 준다.
- 운동장은 밝은 조명과 낮춘 카메라, 좌우 24도 수동 회전을 사용한다. 빈 곳의 가로 드래그는 회전, 세로 드래그는 스크롤이다. 사용자 요청으로 왼쪽 보기·시점 초기화·오른쪽 보기 버튼과 전용 이벤트를 제거했다. 장난감 제자리로 버튼은 유지한다.
- 공·뼈다귀·원반·터그는 집기/던지기가 가능하고, 안내판은 함께 갈 곳으로 연결한다. 나비는 화면 안에서 계속 날며 화면 밖·숨겨진 탭에서는 정지한다. 동작 감소 설정은 유지한다.
- GLB 무손실 압축본은 633,616B. 운동장 근접 시 코드와 모델을 함께 준비하고 자체 렌더 미리보기를 먼저 표시한다. WebGL 실패 시 정적 이미지와 장소 링크를 유지한다. [성능 측정과 한계](yard-loading-performance.md).
- 강아지 3D 캐릭터는 현재 기능이 아니다. 운동장 Blender 원본과 제작 기록은 `design/yard-blender`에 보존한다.
