## 변경

- 좁은 눈을 세로로 더 열고 외측 눈꼬리 기울기를 낮췄다. 따로 돌출되던 홍채/동공 오브젝트를 연속된 곡면의 색으로 바꾸고 진한 갈색 홍채와 큰 동공을 사용했다. 얇은 눈꺼풀과 피부 전이 표면을 추가했다.
- 얼굴 아래쪽을 국소 변형해 입 벌림을 줄였다. 치아/송곳니 오브젝트는 유지하면서 입술 뒤로 넣었다. 혀 끝을 조금 넓히고 앞으로 내렸다.
- 각진 입꼬리를 덮는 볼륨을 코트 메시와 Boolean Union으로 합친 뒤 연결 부위만 평활화했다. 몸통 전체를 리메시하지 않았다. 짧은 주둥이 잔털을 추가했다.
- 귀의 높이를 조금 낮추고 끝을 뒤/바깥으로 기울였다. 귀 가장자리 베벨과 털을 수정하고 끝에서 뭉쳐 뻗는 가닥을 줄였다. 코의 돌출과 높이도 줄였다.
- 확대된 눈 영역을 가로지르는 털 40가닥을 제거했다. 변경된 얼굴의 털 뿌리는 수정된 실제 삼각형 표면에 다시 맞췄다.

## 재현과 검사

새 Blender 세션에서 원본 `../face-groom/exports/05-face-groom.blend`를 연다. `../soften_expression.py`를 import한 뒤 `apply()` → `soften_corners()` → `blend_muzzle()` → `tidy_groom()` → `render()` → `verify()`를 각각 한 번 실행한다. 반복 실행용 함수가 아니므로 재생성은 원본에서 시작한다. 원본 03/05 파일은 변경하지 않았다.

저장 파일을 다시 연 후 `reports/verification.json` 검사를 통과했다. 승인 기본 피부 전체, 얼굴 밖 코트 93,808개 정점과 꼬리 2개 메시의 좌표 서명이 동일하다. 코트·턱·코의 비매니폴드 모서리와 면적 0인 면, 누락된 파일 텍스처는 0개다. 털 좌표와 반지름이 정상이며 각 곡선 오브젝트의 약 500개 뿌리 표본은 표면에서 최대 약 0.009mm 이내다. Cycles 48샘플/AgX, 동일한 카메라·조명으로 4방향을 렌더하고 확인했다.

프로젝트 ESLint·TypeScript·Vitest 54파일/1,667개 테스트·Next.js 빌드를 통과했다. 테스트의 첫 시도는 샌드박스 디렉터리 접근 제한으로 시작되지 않아 권한을 적용한 재실행에서 통과했다. 모델의 시각 품질을 자동 테스트로 판정하지 않는다.

## 남은 범위

이전보다 치아 노출과 각진 눈매는 줄었지만 사진 같은 완성도는 아니다. 눈의 유리 같은 반사와 피부 접합, 입꼬리의 둥근 덩어리와 입술/턱 경계, 옆에서 얇아 보이는 귀를 더 다듬어야 한다. 새 눈은 정적 곡면 표현이며 실제 안구 내부 구조나 얼굴 변형 토폴로지 완성으로 보지 않는다. 리깅·동적 털 바인딩·전체 자가 교차·웹 성능은 검증하지 않았고 라이브 사이트에 적용하지 않았다.
