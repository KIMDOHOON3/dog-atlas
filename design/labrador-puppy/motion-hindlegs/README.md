# 래브라도 — 뒷무릎 높이 수정

앞다리가 자연스러워졌다는 사용자 피드백에 따라 `motion-anatomy`의 앞다리·목·몸통과 기본 메시를 보존하고 뒷다리만 수정했다. 무릎이 골반 쪽으로 들리는 5·39프레임을 중심으로 비교한다.

## 변경

뒷발의 전체 경로를 뒤로 35mm 옮기고, 기존 길이의 허벅지/하퇴로 두 관절 IK를 다시 계산했다. 무릎 자체를 아래로 강제로 이동하거나 다리 길이를 줄이지 않았다. 뒷다리 컨트롤러 6개만 갱신했고 발의 높이·접지 시간·0.48초 주기는 유지한다. 피부 가중치, 관절 평활, 털 연결, 앞다리와 목의 키프레임은 같다.

이전에는 뒷발이 골반보다 앞쪽으로 들어오는 구간에서 허벅지가 수평에 가까워졌다. 발 경로를 옮겨 해당 구간의 무릎을 낮췄다. 발이 실제 공간에서 뒤로 이동하므로 전체 보폭의 앞뒤 배치는 달라진다. 기존 단순화된 수직/피치 물리 계산은 유지하며 수평 추진력이나 마찰을 새로 계산한 것은 아니다.

## 보기와 파일

`review.html`은 측면·정지·¼ 속도로 시작하고 이전 `motion-anatomy`와 같은 프레임/속도로 비교한다. 5·39프레임에서 무릎 높이, 20프레임에서 뒤로 펴지는 다리를 확인한다.

- `exports/puppy-run-study.blend`: 수정 모션과 기존 피부·털·24개 컨트롤러를 포함한 원본.
- `textures/`: 기존 4K 맵 4장. Blender 파일과 상위 디렉터리 구조를 함께 유지한다.
- `frames/side`, `frames/three-quarter`: 실제 Cycles·AgX·960×720·24 samples 각 48장.
- `preview-*.webp`: 정상 480ms와 ¼ 속도 1,920ms의 렌더 미리보기 4개.
- `../puppy-hindlegs-run.zip`: 원본·텍스처·새 프레임·검사·플레이어와 비교용 이전 96장. 압축 해제 후 `motion-hindlegs/review.html`을 연다. 상위 정적 모델 링크는 전체 프로젝트에서만 유효하다.

재생성에는 전체 프로젝트와 이전 `motion-anatomy` 원본이 필요하다. Blender `--python build_hindlegs.py -- build`로 만들고 `-- render-both`로 양쪽 방향을 프레임마다 렌더한다. `-- render side`/`-- render three-quarter`도 지원한다. `.blend` 재생에는 제작 스크립트가 필요 없다. Pillow가 있는 Python으로 `package_motion.py`를 실행해 미리보기/ZIP을 만든다.

## 검사

`reports/hindleg-positions.json`은 48프레임 양쪽 무릎과 골반의 수직 간격, 발 높이 전후 차이를 기록한다. 프레임 사이를 포함한 192개 시점의 IK 도달성 검사에서 최대 거리는 두 구간 길이 합의 93.6%로 범위 안에 있다. 발 높이 변화는 0이다.

`reports/verification.json`은 Blender 재열기 결과다. 앞다리·목 등 18개 컨트롤러의 전체 키프레임 데이터와 몸체 기본 정점이 이전과 동일하다. 5·20·39프레임의 앞쪽 몸체 표면 차이는 0이다. 몸체·털 루프, 피부/발바닥 높이·유한 좌표·누락 텍스처를 검사한다. 9개 자세에서 약 1,500개씩 표본으로 고른 몸통 털 뿌리의 피부 거리는 최대 약 0.43mm다.

플레이어는 JSDOM으로 프레임·동일 속도·비교·키보드·화면 밖 정지와 이미지 경로를 검사한다. 실제 브라우저 렌더링과 실기기 성능 검사는 포함하지 않는다.

앞다리 전체 표면의 모든 프레임 비교나 전신 자가 교차 전수 검사를 한 것은 아니다. 기존 관절 평활의 부피 감소, 깊은 접힘의 조형과 프로덕션 뼈 리그 미완료 상태는 유지한다. 완성된 해부학/근육 시뮬레이션이 아니며 라이브 푸터는 변경하지 않았다.
