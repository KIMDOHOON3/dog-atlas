# 스피츠 얼굴·털 1차 수정

사용자가 승인한 `../exports/03-coat-shape-study.blend`를 기준으로 새 얼굴 사진을 참고했다. 기존 몸통/다리/목과 꼬리 형상은 유지하고 얼굴 영역만 수정했다. Blender MCP에서 직접 제작했으며 포토리얼 완성 판정이나 Three.js strict 게이트 통과를 뜻하지 않는다.

## 결과

- `exports/05-face-groom.blend`: 현재 수정본. 눈꺼풀 윤곽·갈색 홍채·동공, 열린 입·별도 턱/혀/치아/입술, 파인 콧구멍, 얇아진 귀, Hair Curves를 포함한다.
- `exports/04-face.blend`: 털 추가 전의 중간 작업본. 최종 입 안 재질/마감 수정은 `05`에 포함된다.
- `previews/face.png`, `front.png`, `side.png`, `body.png`: 최종 수정본의 Cycles/AgX 렌더.
- 털 283,662가닥과 별도 수염 12가닥. 주둥이와 턱은 짧고, 가슴/목/꼬리는 길게 배치했다. 약 1~36mm 범위이며 뿌리에서 끝으로 반지름이 줄어든다. 입 내부와 눈 영역의 털을 제외한다.

## 재현

승인된 `03-coat-shape-study.blend`를 연 뒤 `../refine_face_groom.py`를 import한다. 새 작업에서 `face()` → `polish_face()` → `groom()` → `oral_finish()` → `finish_boundaries()` → `verify()` → `render_views()` 순서로 각 1회 실행한다. 같은 장면에 반복 적용하는 함수는 아니며 시작 시 기준 파일을 다시 연다. 중간에 발견한 입안 덩어리/과도한 반사/외부 피부 재질 경계 문제의 수정도 해당 코드에 반영했다.

## 검사와 남은 범위

- 프로젝트 ESLint, TypeScript 검사, Vitest 54파일/1,667개 테스트, Next.js 빌드를 통과했다. 이는 모델의 시각적 완성도 판정과 별개다.
- 재열기 후 승인된 기본 피부 전체, 얼굴 밖 코트 정점 93,808개, 꼬리 2개 메시의 좌표 서명이 기준과 동일하다.
- 코트·새 턱·코의 비매니폴드 모서리와 면적 0인 면은 0개. 눈 패치는 개방된 표면이므로 폐곡면 조형 완료로 세지 않았다.
- 모든 털 좌표가 유한하고 반지름은 양수다. 렌더와 동일한 삼각형 구성을 사용한 각 곡선 오브젝트의 약 500개 뿌리 표본 검사에서 수염 포함 최대 거리 약 0.037mm. 초기 일반 다각형 BVH 검사는 비평면 사각형의 다른 삼각 분할 때문에 꼬리에서 0.344mm를 보고했으며, 검사기를 실제 렌더 삼각형 기준으로 수정했다.
- 누락된 파일 텍스처 0개. 재질은 내부 절차적 재질이며 외부 텍스처 다운로드는 없다.
- 사진과 비교한 얼굴 유사도는 완성 기준에 도달하지 않았다. 눈 주변 피부 접합·입꼬리/치열·귀 가장자리의 조형, 긴 털의 볼륨과 방향은 추가 다듬기가 필요하다.
- 털은 정적 표면 위에 배치했다. 움직이는 표면에 대한 바인딩, 전신 리깅, 전체 자가 교차, 웹 성능/GLB 내보내기는 검증하지 않았다. 라이브 사이트에 적용하지 않았다.
