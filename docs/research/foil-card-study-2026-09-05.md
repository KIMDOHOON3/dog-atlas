# 그레이트 피레니즈 카드 질감 실험 — 2026-09-05

## 후속 버전: 설산 그림과 각도에 숨은 무늬

사용자가 피레니즈부터 눈 결정·산 능선 질감을 발전시키고 그림도 새로 그려도 된다고 승인했다. 카드 전용 [새 이미지와 최종 프롬프트](great-pyrenees-alpine-art-2026-09-05.md)를 기록한다. 이전 도감 그림을 덮어쓰지 않았다. 이미지 전체가 잘리지 않도록 contain 배치하고 카드 하단을 차가운 종이색으로 맞췄다.

GLSL에서 각도를 60도 구간으로 접어 가지가 있는 6방향 눈 결정 7개를 계산한다. 무늬의 경계 상자 안에서만 선분 거리를 계산하며, 포인터와 함께 움직이는 좁은 빛 영역이 결정을 드러낸다. 산 능선은 상단에 곡선 등고선을 겹치는 방식이며 실제 지도 등고선은 아니다. 서리빛 반사는 푸른 은색과 옅은 무지개색을 섞고, 강아지 몸·얼굴 영역은 코팅 강도를 줄인다. 눈 결정·능선은 생성 이미지에 포함된 정적 장식이 아니다. 원래의 idle 중지·fallback·reduced-motion 처리를 유지한다.

후속 검증: lint·typecheck·전체 57파일/1,651테스트·403개 정적 페이지 생성 빌드 통과. 개발 중 갱신된 캔버스가 그려지지 않는 상태가 있어 새로 로드한 페이지에서 다시 시각 확인했다. 데스크톱과 390px viewport의 새 그림 전체 배치, 각도별 눈 결정/능선 표시, 홀로그램 끄기를 확인했다. 3001 프로덕션의 카드와 새 이미지 HTTP 200, 실제 카드 표시 및 빛 시연 확인. 모바일 실기기 GPU 성능은 미검증이다.

## 범위

사용자는 도감으로 돌아가기로 했으며 상세 구성은 이후에 고민한다. `/card-lab`에서 기존 `pyrenean-mountain-dog-card.webp` 한 장을 사용한다. 기존 도감·상세·원고·그림은 수정하지 않는다. 장소와 엽서는 주요 메뉴에서 내리고 직접 URL은 보존한다.

## 표현과 구현

- HTML 카드·이름·기존 원고에서 가져온 원산 지역/과거 역할. CSS perspective와 rotateX/Y로 기울기를 표현한다.
- 네이티브 WebGL vertex/fragment shader로 빛 위치에 따른 무지개 간섭색, 대각선 음각 무늬, 미세한 포일 입자를 렌더링한다. 그림 위 반투명 코팅이며 실물 광학의 엄밀한 시뮬레이션은 아니다.
- 마우스 위치, 터치 드래그, 키보드 방향키·Escape. 켜기/끄기·빛 강도·4.4초 빛 이동 시연과 중지 버튼.
- 기기 픽셀 비율 최대 1.5, 입력이 안정되면 RAF 중지, 숨긴 탭에서 시연/루프 중지. 종료 시 shader/program/buffer 정리. WebGL context 복구 시 재초기화.
- WebGL 실패 시 기존 그림과 문구를 유지한다. `prefers-reduced-motion`에서는 기울기·자동 시연을 막고 정적인 질감 비교를 제공한다.
- 외부 API·새 패키지·새 이미지·희귀도·스탯·게임·사용자 데이터 저장은 추가하지 않는다. 상세 수정과 도감 전체 카드 적용은 보류다.

## 검증

- 개발 브라우저에서 WebGL 프로그램 생성 성공(`data-renderer=webgl`), 실제 색 반사·카드 표시, 키보드 및 드래그에 따른 기울기 변경, 홀로그램 끄기와 강도 제어 비활성화를 확인했다.
- 자동 테스트는 WebGL 불가 시 읽기 가능 상태와 조절 비활성화, 움직임 줄이기에서 정적 비교, GPU 리소스 정리를 검증한다. 셰이더 컴파일/시각 품질은 모의 테스트가 아닌 브라우저 확인 대상이다.
- 390px viewport에서 가로 넘침 없이 카드와 조절 UI가 표시되고 WebGL 렌더링됨을 확인했다. 시연 시작/자동 종료, 브라우저 오류 0건 확인. lint·typecheck·57파일/1,651테스트·403개 정적 페이지를 생성하는 프로덕션 빌드 통과. 3001에서 최종 카드·WebGL 표시를 확인했다. 모바일 실기기 GPU 성능과 다양한 브라우저의 색 표현은 별도 확인이 필요하다.
