# 그레이트 피레니즈 카드 뒷면

> 후속 피드백으로 아래 도식/아이콘 디자인은 대체되었다. 최신 화면은 [전체 배경 수채화](great-pyrenees-human-back-art-2026-09-05.md)를 따른다. 정보 출처와 조작 구조는 유지한다.

## 승인 범위와 구현

사용자는 한 장의 앞면 그림·홀로그램을 유지하고 뒷면에 국기·출신, 크기, 수명, 과거 역할을 넣는 구성을 승인했다. `/card-lab`만 변경하며 전체 도감/상세는 그대로 둔다.

- 프랑스 삼색기, 종이 표면과 희미한 산 능선, 숫자 중심 구성.
- 코드 SVG로 사람 170cm와 어깨 높이 75cm 강아지의 비율 예시, 작은 양을 표시한다. 사실적인 외형 재현 또는 실측 이미지가 아니다.
- 560ms CSS 회전. 기존 기울기와 별도 transform 계층을 사용한다. reduced motion에서는 전환 시간이 0이다.
- 카드 클릭/탭, 별도 버튼, Enter/Space로 뒤집기. Escape로 앞면 복귀. 8px 넘게 움직인 경로(원위치 복귀 포함), 취소된 포인터 입력은 뒤집지 않는다.
- 비활성 면은 aria-hidden으로 읽기에서 제외한다. WebGL이 없어도 두 면과 버튼은 사용 가능하다.
- 뒷면 진입 시 시연·대기 입력·RAF와 포일 제출을 중지한다. 앞면 복귀 시 기존 텍스처를 재사용하며 GPU 객체를 재생성하지 않는다. 앞면 60Hz 기울기/약 30Hz 포일·너비 320 상한을 유지한다.
- 작은 모바일에서 읽기 위해 카드 폭을 76vw/330px 상한에서 88vw/350px 상한으로 늘렸다. 뒷면에 외부 이미지·라이브 API·새 의존성은 없다.

## 정보 근거 — 2026-09-05 확인

- [FCI 표준 137](https://www.fci.be/nomenclature/Standards/137g02-en.pdf): 출신 프랑스, 산악 가축보호 역할, 암컷 어깨 높이 65–75cm·수컷 70–80cm. 카드는 합친 범위 65–80cm. 표준의 +2cm 예외는 요약 범위에 넣지 않았으며 실제 개체 전체의 최솟값/최댓값이 아니다.
- [Hill’s Great Pyrenees 안내](https://www.hillspet.com/dog-breeds/great-pyrenees): 몸무게 85–120lb를 0.45359237로 환산하면 38.56–54.43kg, 카드에는 약 39–54kg. 일반적인 수명 10–12년. 측정된 모집단의 산술 평균으로 표시하지 않는다.
- [AKC 견종 안내](https://www.akc.org/dog-breeds/great-pyrenees/): 산에서 양 떼를 위협하는 늑대와 포식자를 막던 역할 확인.
- 원문 설명은 복사하지 않고 한국어 한 문장으로 재작성했다. 카드에는 성별·개체·환경 차이 안내, 카드 밖 접힌 ‘정보 출처’에는 수치와 환산 기준 링크를 제공한다. 수의사·행동 전문가 검수 완료를 뜻하지 않는다.

## 검증

관련 테스트 6개: 드래그/취소 후 클릭 억제, 다음 탭 허용, WebGL 없는 앞뒤 전환 및 활성 면 읽기, Escape, reduced motion, 뒷면 GPU 중지/앞면 복귀, 기존 240Hz 입력 제한과 정리.

lint·typecheck·전체 57파일/1,655테스트·프로덕션 빌드(403개 정적 페이지) 통과. 마지막 미정의 클래스 참조 제거 후 빌드/타입 검사를 재통과했다.

데스크톱 및 390px viewport에서 뒷면의 국기/전체 원고/수치와 도식, 앞면 복귀, 드래그 후 앞면 유지와 재탭 전환을 확인했다. 브라우저에서 발견한 뒷면 글 잘림은 폰트/줄 높이/여백을 조정해 해소했다. 3000/3001 프로덕션 서버를 최종 빌드로 다시 시작했으며 `/card-lab` HTTP 200·새 뒷면/출처 마크업, 기존 3001 카드 탭의 뒤집기, 재질 로딩 완료·캔버스 너비 320·브라우저 오류/경고 없음과 전체 뒷면 표시를 확인했다. 해당 탭을 뒷면 상태로 열어뒀다. 실제 휴대폰 GPU 시간이나 사용자 최종 디자인 평가는 이번 검증에 포함하지 않는다.
