# 재패니즈 스피츠 — 첫 정적 체형 시안

사용자가 제공한 사진 2장을 보고, 연결된 Blender 5.2.1에서 몸통 → 얼굴 → 털의 큰 윤곽 순서로 제작했다. 첫 사진은 외형 기준, 두 번째는 측면 구조 보조이며 두 이미지를 동일 개체의 보정된 다중 시점 자료로 취급하지 않는다.

## 승인된 체형과 얼굴 참고

2026-09-13 사용자가 현재 체형에 만족한다고 확인했다. `03-coat-shape-study.blend`의 목 길이·몸통 폭·다리 비율과 전체 자세를 기준으로 유지한다. 새 `references/face-primary.png`는 눈매·주둥이·편안하게 열린 입·귀 내부·부위별 털 방향 참고다. 얼굴과 털 수정은 아직 적용하지 않았다. 승인 기준 파일의 SHA-256과 관찰 내용은 `reports/body-approval-and-face-reference.json`에 기록했다.

## 현재 결과

- `exports/01-body-study.blend`: 털 부피를 제외한 몸통·목·네 다리.
- `exports/02-face-study.blend`: 귀·눈·주둥이·코·입선·꼬리 기본 곡선 추가.
- `exports/03-coat-shape-study.blend`: 목·가슴·몸통·꼬리의 털 부피를 별도 메시로 추가한 현재 시안.
- `previews/`: 현재 시안 정면·측면·후면·3/4 및 앞 단계 정면·측면 Cycles 렌더.
- `build_blender.py`: 장면 생성과 각 단계의 재현 코드. 연결된 Blender에서 import 후 `setup()`, `body()`, `details()`, `coat_shape()`를 순서대로 실행한다. 새 빈 장면에서 시작한다.
- `render_verify.py`: 기본 메시 검사 및 각 방향 렌더.

현재 파일에서 `Continuous base skin`은 숨겨 보존하고 `Coat silhouette`을 표시한다. 털의 부피는 피부 두께와 구분되지만 실제 Hair Curves 그루밍은 아직 없다. 리트리버 데이터는 새 파일에 포함하거나 수정하지 않았다.

## 스킬 적용 범위와 제한

`img2threejs`의 이미지 분석·참고 적합성·해부학적 관찰과 추정 구분·부품 분해·단계별 비교 방식을 사용했다. 이후 사용자가 Blender에서 제작 과정을 직접 보도록 요청하여 **네이티브 Blender 체형 시안**으로 진행했다. 스킬의 기본 TypeScript 팩토리, strict spec 및 Three.js 런타임 검수 과정을 완료했다고 주장하지 않는다. `.img2threejs/state.json`도 실제 완료한 분석 단계까지만 기록하며 Blender 시안은 별도 경로다.

사진에서 보이지 않는 실제 골격·털 아래 몸통·절대 크기는 추정이다. 얼굴은 아직 단순화되어 있고 귀 측면 두께·가슴에서 어깨로 넘어가는 형태·꼬리의 덩어리감은 추가 비교가 필요하다. 포토리얼 털, 발가락 세부 조형, 변형용 쿼드 리토폴로지, 리깅과 움직임은 이번 체형 단계에서 완료되지 않았다. 라이브 사이트/푸터에는 적용하지 않았다.

`reports/mesh-check.json`은 각 원본 메시의 유한 좌표·비매니폴드 모서리·면적 0인 면과 누락 파일 텍스처를 기록한다. 전체 오브젝트 사이 교차·사진 일치도·애니메이션 품질에 대한 검증은 아니다.
