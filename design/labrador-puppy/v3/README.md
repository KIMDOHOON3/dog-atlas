# 래브라도 v3 — 측면 체형 수정 시안

사용자가 다운받은 골든 리트리버 GLB를 Blender에서 시각적으로 참고하여, 기존 v2의 목·등·가슴 밑선·어깨와 골반 사이 거리·뒷다리 각도를 수정했다. 참고 모델의 메시나 텍스처는 결과물에 포함하지 않았다.

- `exports/labrador-puppy-fur.blend`: 수정한 메시, Hair Curves, 조명·카메라, 숨겨진 조형 원본.
- `exports/labrador-puppy-base.blend`: 털 없는 기본 메시와 조형 원본.
- `exports/labrador-puppy.obj`, `.mtl`: 털 없는 교환용 메시.
- `textures/`: v2에서 이어받은 4K 맵 4장. Blender 파일과 상대 경로를 유지해야 한다.
- `previews/03-*`: 털 없는 체형 검토. 최종 `front`, `side`, `rear`, `face`, `three-quarter`는 털 포함 렌더.
- `reports/`: 제작 방식, 개별 메시 검사, 재불러오기 결과.

Blender 4.5.9 / Cycles / AgX. 정적 외형 시안이다. 얼굴의 사실성·수작업 쿼드 리토폴로지·스키닝과 애니메이션은 미완료다. 자견의 비례와 해부학을 전문가가 검증한 모델이 아니며, 참고 모델 수준의 외형을 완성했다고 판정하지 않는다. 측면 윤곽과 어깨·골반 표면은 추가 조형 대상이다.

v1/v2 비교 화면과 자세한 제작 스크립트는 상위 폴더 `review.html`, `README.md`, `silhouette.py`에 있다. 라이브 사이트에는 적용하지 않았다.

최종 개별 메시 검사에서 열린 경계·비매니폴드·면 방향 불일치·퇴화/중복 면·음의 체적·비인접 삼각형 교차·누락 텍스처는 0건이었다. 네이티브 파일 두 개와 OBJ를 다시 불러와 텍스처 경로를 확인했다. 서로 다른 부품 사이의 관통이나 애니메이션 품질을 보증하는 검사는 아니다.

lint·typecheck·1,661개 테스트·385페이지 빌드 통과. 비교 화면은 코드에서 90개 시안/단계/방향 입력 조합의 유효 경로를 확인했고, Blender PNG를 직접 시각 검토했다. 브라우저 UI를 새로 검증했다고 주장하지 않는다.
