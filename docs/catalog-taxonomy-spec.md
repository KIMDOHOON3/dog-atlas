# 견종 도감 탐색 카테고리 체계

작성일: 2026-08-03  
문서 목적: 견종 데이터가 충분히 축적되었을 때 홈과 전체 도감에서 사용할 탐색 분류 정의  
기준 문서: `docs/product-brief.md`, `docs/catalog-20-proposal.md`  
검토 표본: 현재 5종 데이터와 초기 20종 편성안

## 1. 분류 목적

이 분류는 사용자를 대신해 견종을 고르는 추천 체계가 아니다. 외모나 인지도로 시작한 관심을 다음 질문으로 옮기는 탐색 장치다.

1. 이 견종은 어떤 환경에서 무슨 일을 해왔는가?
2. 그 배경이 오늘의 행동 장면과 어떻게 연결될 수 있는가?
3. 함께 살 때 어떤 시간·공간·관리·안전 조건을 확인해야 하는가?
4. 비슷해 보이는 견종 사이에는 어떤 생활 차이가 있는가?

카테고리는 `정답`이나 `적합도`가 아니라 여러 견종을 나란히 발견하는 입구로 사용한다. 한 견종은 여러 범주에 속할 수 있으며, 필터 결과는 순위를 매기지 않는다.

## 2. 분류 원칙

- 외모와 인기는 검색 보조 수단일 수 있지만 1차 탐색 축으로 사용하지 않는다.
- 역사와 원래 역할은 현재 행동을 확정하는 원인이 아니라 해석 맥락으로 제공한다.
- 크기, 활동, 피모 관리, 소리, 관계 성향을 하나의 `돌봄 난도`로 합산하지 않는다.
- `교감`과 `독립성`은 서로 반대되는 한 개의 척도가 아니다. 사람과 협력하면서 스스로 판단하는 견종도 있다.
- `활동량`과 `활동 리듬`을 분리한다. 짧은 질주와 긴 휴식이 필요한 개를 단순히 저활동으로 분류하지 않는다.
- `소리 표현`과 `경계성`을 동일시하지 않는다. 소리를 내는 맥락과 빈도는 환경·학습·개체 경험에 영향을 받는다.
- `피모 형태`, `털 빠짐`, `미용 부담`, `기후 주의`를 한 단어로 축약하지 않는다.
- 데이터가 없거나 검수되지 않은 값은 `보통`으로 추정하지 않고 `정보 확인 중`으로 둔다.
- 범주명은 성격 형용사보다 관찰 가능한 생활 장면을 사용한다.

## 3. 정보 구조: 홈 카테고리와 상세 필터

분류 체계는 두 층으로 나눈다.

### 3.1 홈의 1차 카테고리

홈에서는 여섯 개의 넓은 발견 입구만 노출한다. 사용자가 견종 용어를 몰라도 이해할 수 있는 질문형 제목을 사용한다. 각 입구는 자동 추천 결과가 아니라 해당 축의 대표적인 대비를 보여주는 편집 목록으로 연결된다.

| 순서 | 홈 카테고리 | 홈 설명 카피 | 연결하는 핵심 축 |
|---:|---|---|---|
| 1 | `어떤 일을 해왔을까` | `사람 곁의 반려견부터 목양견·사냥견·북방 작업견까지, 오늘의 행동을 이해할 역사적 배경을 살펴봐요.` | 역사, 계통, 원래 역할 |
| 2 | `하루 움직임의 리듬` | `오래 움직이는 활동, 짧은 질주와 휴식, 냄새 탐색처럼 서로 다른 하루 리듬을 비교해요.` | 활동 요구, 활동 리듬, 정신적 자극 |
| 3 | `몸의 크기와 생활 동선` | `성견의 체격뿐 아니라 안기·이동·계단·리드 관리에서 달라지는 현실을 확인해요.` | 체격, 힘, 이동과 공간 관리 |
| 4 | `털과 날씨 돌봄` | `털의 길이보다 빗질·미용·건조와 더위·추위에 필요한 관리를 함께 살펴봐요.` | 피모, 털갈이, 미용, 기후 |
| 5 | `사람과 관계 맺는 방식` | `가까운 교감, 사람과의 협력, 스스로 판단하는 경향을 서로 다른 항목으로 살펴봐요.` | 교감, 협력, 독립적 판단, 혼자 쉬기 |
| 6 | `주변 자극에 반응하는 방식` | `소리·움직임·낯선 변화에 주의를 기울이고 표현하는 장면을 확인해요.` | 알림 행동, 소리 표현, 자극 민감성, 추적·몰이 단서 |

홈에서는 여섯 범주를 모두 같은 크기의 필터 버튼으로 늘어놓기보다 2~3개씩 편집 묶음으로 보여준다. 각 카테고리에는 다음만 포함한다.

- 범주명과 한 문장 설명
- 서로 대비되는 대표 견종 3~5종
- 각 견종이 이 범주에 포함된 이유 한 문장
- CTA: `{카테고리명}으로 둘러보기`

결과 제목은 `이 조건에 맞는 견종`이 아니라 `이 관점으로 살펴볼 견종`으로 쓴다.

### 3.2 전체 도감의 상세 필터

상세 필터는 값을 이미 이해하고 있는 사용자가 목록을 좁힐 때 사용한다. 홈의 질문형 카테고리보다 세분화하되, 기본 화면에서는 접힌 상태로 둔다.

- 한 축 안의 복수 선택: OR
- 서로 다른 축의 선택: AND
- 선택 결과 정렬: 가나다순 또는 편집 순서
- 적합도·일치율·추천순 정렬: 제공하지 않음
- 결과가 없으면 조건을 자동으로 완화하지 않음

결과 상단 카피:

- `{n}종을 이 기준으로 살펴보고 있어요.`
- `이 필터는 생활 조건을 비교하기 위한 탐색 도구이며 개별 반려견의 성격을 보증하지 않아요.`

## 4. 상세 분류 축

### 4.1 역사와 원래 역할

홈 연결: `어떤 일을 해왔을까`

#### 필터 값

- 사람 곁의 반려
- 목양과 가축 이동
- 가축·영역 수호
- 조렵과 회수
- 냄새를 따라가는 사냥
- 시각으로 추적하는 사냥
- 굴 안팎의 사냥
- 썰매·운반과 북방 작업
- 복합 역할·지역 토종

#### 데이터 필드

- `lineageLabels[]`: 공식 그룹과 별개인 편집 계통
- `originalRoles[]`: 근거가 있는 원래 역할
- `historyRegions[]`: 국가 단정이 어려울 때 지역 또는 형성 배경
- `roleToTodayNotes[]`: 역할과 현대 생활을 연결하는 설명

`스피츠`, `하운드`, `리트리버` 같은 계통명과 `썰매`, `목양`, `회수` 같은 역할은 같은 필터로 섞지 않는다. 화면에서는 계통을 보조 라벨, 역할을 주요 탐색 값으로 둔다.

### 4.2 활동 요구와 하루 리듬

홈 연결: `하루 움직임의 리듬`

#### 필터 값

활동 요구:

- 낮은 편
- 중간
- 높은 편
- 매우 높은 편
- 정보 확인 중

활동 리듬:

- 짧고 규칙적인 활동
- 지속적인 야외 활동
- 짧은 전력 활동과 충분한 휴식
- 냄새를 따라 탐색하는 시간
- 과제와 협력 활동
- 복합형·개체 확인 필요

정신적 자극 맥락:

- 냄새 탐색
- 움직임 추적
- 문제 해결
- 사람과의 협력 과제
- 회수·물기 대체 놀이
- 차분히 쉬는 연습

`하루 30분`, `하루 2시간`처럼 품종 전체에 적용되는 절대 시간 필터는 사용하지 않는다. 날씨, 나이, 건강, 활동 강도에 따라 의미가 달라지기 때문이다.

### 4.3 체격과 생활 동선

홈 연결: `몸의 크기와 생활 동선`

#### 필터 값

편집 크기:

- 초소형
- 소형
- 중형
- 대형
- 초대형
- 경계 범주

생활 동선 확인:

- 안아서 이동하는 상황이 잦을 수 있음
- 계단·점프 관리 확인
- 성견의 힘과 리드 관리 확인
- 차량·대중교통 이동 계획 확인
- 넓고 안전한 회전·휴식 공간 확인
- 울타리·이탈 안전 확인

크기 범주는 검색 편의를 위한 편집 값이며, 상세에는 출처가 있는 성견 체중·체고 범위를 함께 제공한다. `아파트 가능`, `마당 필요`처럼 주거 형태를 품종 속성으로 단정하지 않는다. 주거 면적보다 활동 제공, 소음, 이동, 온도, 안전 동선을 구체적으로 설명한다.

### 4.4 피모와 관리

홈 연결: `털과 날씨 돌봄`

#### 필터 값

피모 구조:

- 단일모
- 이중모
- 장모
- 단모
- 곱슬·웨이브
- 거친 털·와이어
- 무모·특수 관리
- 유형 다양·확인 필요

일상 관리:

- 규칙적인 빗질
- 털갈이 시기 집중 관리
- 전문 미용 주기 확인
- 완전 건조에 시간 필요
- 눈가·귀·주름 등 반복 관리
- 피부·보온 환경 확인

관리 부담 단계는 `낮음/중간/높음` 보조 필터로만 제공하고, 반드시 실제 관리 행동을 함께 보여준다. `털이 안 빠져요`, `알레르기에 안전해요` 같은 카테고리는 만들지 않는다.

### 4.5 기후와 계절

홈 연결: `털과 날씨 돌봄`

#### 필터 값

- 더운 날씨 주의
- 추운 날씨 주의
- 높은 습도와 건조 확인
- 활동 시간 조정 필요
- 실내 온도 관리 확인
- 우천 후 피모·피부 관리
- 개체 건강에 따라 확인

기후 필터는 `더위에 강함`, `추위에 강함`이라는 장점 배지보다 `주의가 필요한 상황` 중심으로 쓴다. 단두형 호흡, 연령, 체중, 기저 질환처럼 건강과 결합되는 설명은 수의학 검수 이후에만 노출한다.

### 4.6 사람과의 교감·협력

홈 연결: `사람과 관계 맺는 방식`

#### 필터 값

사람과의 관계 장면:

- 사람 가까이 참여하려는 경향
- 사람의 신호와 협력하는 과제
- 반복적인 신체 관리 적응이 중요
- 낯선 사람과의 반응 확인
- 가족과 떨어져 쉬는 연습이 중요
- 개체와 성장 경험 확인

교감 수준을 `낮음/높음` 한 줄로만 보여주지 않는다. `사람을 좋아함`, `가족 친화적` 같은 표현 대신 어느 장면에서 관계 욕구가 나타날 수 있는지 설명한다.

### 4.7 독립적 판단과 환경 관리

홈 연결: `사람과 관계 맺는 방식`

#### 필터 값

- 사람의 신호와 자주 협력해온 배경
- 스스로 판단하는 역할의 배경
- 탐색 중 선택이 강해질 수 있음
- 중단 신호와 안전 관리 확인
- 혼자 편안히 쉬는 경험 확인
- 개체와 환경에 따라 확인

`독립성이 높다`는 `혼자 오래 둬도 된다`는 뜻이 아니다. 두 정보는 데이터와 화면에서 분리한다. 혼자 있는 시간은 품종 필터가 아니라 개체 경험, 연령, 생활 훈련을 확인하는 공통 안내로 제공한다.

### 4.8 소리와 주변 자극

홈 연결: `주변 자극에 반응하는 방식`

#### 필터 값

알림 행동 경향:

- 낮은 편
- 중간
- 높은 편
- 개체·환경 확인 필요

소리 표현 맥락:

- 낯선 소리·움직임 알림
- 흥분·요구 상황의 표현
- 후각 탐색 중 목소리 사용
- 독특한 발성 방식
- 지속적 알림이 중심은 아님
- 정보 확인 중

자극 반응 장면:

- 빠른 움직임 추적
- 사람·동물을 모으는 듯한 행동
- 냄새에 집중해 방향 전환
- 낯선 대상과 거리 확보
- 주변 경계와 확인

`조용한 견종`, `짖지 않는 견종`, `공격적인 견종` 카테고리는 만들지 않는다. 소리 빈도와 추적·몰이·경계 행동을 공격성으로 치환하지 않는다.

## 5. 축 사이의 중복과 경계 규칙

| 혼동하기 쉬운 축 | 경계 규칙 |
|---|---|
| 계통 ↔ 원래 역할 | 계통은 형태와 혈통의 편집 맥락, 역할은 수행해온 일이다. 각각 별도 필드로 저장한다. |
| 역사 ↔ 행동 | 역사는 행동을 이해할 단서일 뿐 현재 행동의 확정값이 아니다. 행동 화면에는 관찰 장면과 개체 차이 문구를 함께 둔다. |
| 활동 요구 ↔ 정신적 자극 | 움직이는 양과 과제의 종류를 분리한다. 높은 학습 요구를 단순 운동 시간으로 바꾸지 않는다. |
| 활동 요구 ↔ 체격 | 큰 개가 항상 고활동, 작은 개가 항상 저활동이라는 규칙을 만들지 않는다. |
| 활동 리듬 ↔ 휴식 | 질주 후 휴식은 저활동 판정이 아니다. 한 쌍의 리듬으로 기록한다. |
| 교감 ↔ 협력 | 사람 가까이 머무는 성향과 사람의 신호로 과제를 수행해온 배경은 다르다. |
| 교감 ↔ 독립성 | 반대 축으로 점수화하지 않는다. 한 견종이 두 특성을 모두 가질 수 있다. |
| 독립성 ↔ 혼자 있기 | 스스로 판단하는 작업 배경은 분리불안 여부나 혼자 둘 수 있는 시간을 뜻하지 않는다. |
| 알림 행동 ↔ 소리 표현 | 주변 변화 알림과 흥분·요구·탐색 중 발성은 맥락이 다르다. |
| 경계·추적·몰이 ↔ 공격성 | 행동의 대상·거리·자세·중단 가능성을 보지 않고 위험 성격으로 분류하지 않는다. |
| 피모 구조 ↔ 관리 부담 | 짧은 털도 피부·보온 관리가 필요할 수 있다. 구조와 실제 행동을 별도 필드로 둔다. |
| 털 빠짐 ↔ 알레르기 | 털 빠짐 정도로 알레르기 안전성을 판정하지 않는다. |
| 기후 ↔ 피모 | 피모는 중요한 요소지만 호흡, 체중, 연령, 건강도 영향을 준다. 기후 주의는 별도 검수한다. |
| 크기 ↔ 주거 적합성 | 크기는 이동과 힘의 현실을 보여줄 뿐 아파트·마당 적합 판정으로 사용하지 않는다. |

## 6. 사용하지 않을 위험한 카테고리

다음 표현은 홈 카테고리, 필터, 배지, URL slug에 사용하지 않는다.

| 금지 또는 제한 표현 | 위험 | 대체 방식 |
|---|---|---|
| `초보자가 키우기 쉬운 견종` | 돌봄을 단일 난도로 축약하고 개체·가정 조건을 숨김 | 활동·피모·소리·이동 등 독립 축 비교 |
| `나에게 맞는 견종` | 적합 판정으로 오인 | `이 관점으로 살펴볼 견종` |
| `아파트 견종`, `마당이 필요한 견종` | 공간 크기로 생활 가능성을 단정 | 소음, 활동, 이동, 안전 동선 분리 |
| `아이와 잘 지내는 견종` | 개체 경험과 감독 책임을 품종에 전가 | `가족 구성원과의 실제 반응 확인` 공통 안내 |
| `다른 동물과 잘 지내는 견종` | 사회화·추적 행동·개체 이력 누락 | 실제 만남과 관리 조건 확인 |
| `공격적인 견종`, `순한 견종` | 낙인과 과도한 안전 보증 | 관찰 가능한 행동 장면과 환경 조건 |
| `충성심 높은 견종` | 관계를 미화하고 경계·독립 행동을 오독 | 협력, 교감, 독립적 판단을 분리 |
| `똑똑한 견종` | 학습 속도를 쉬운 양육으로 오인 | 문제 해결·협력 과제 요구 설명 |
| `조용한 견종`, `짖지 않는 견종` | 개체와 환경 차이를 무시 | 알림·요구·탐색 발성 맥락 |
| `혼자 잘 있는 견종` | 장시간 방치를 정당화할 수 있음 | 혼자 쉬는 경험은 공통 보호자 확인 항목 |
| `털이 안 빠지는 견종`, `저알레르기 견종` | 절대적 건강·관리 보증 | 피모 구조, 털갈이, 미용 행동 분리 |
| `건강한 견종`, `수명이 긴 견종` | 개별 건강과 의료 책임을 오도 | 출처별 수명 범위와 검수된 건강 주의 제공 |
| `운동량 적은 견종` 단독 카테고리 | 활동의 강도·리듬·탐색 욕구 누락 | 활동 요구와 리듬을 함께 표시 |
| 인기순·등록순 | 인기 편향을 강화 | 가나다순, 편집 순서, 무작위 발견 |

건강 상태, 구조적 질환 위험, 법적 사육 제한은 발견을 위한 취향 필터가 아니라 별도의 중요 안내로 다룬다. 전문 검수와 현재 지역 기준을 충족하기 전에는 필터로 공개하지 않는다.

## 7. 현재 5종으로 검증한 분류 예시

아래는 분류가 실제로 서로 다른 견종을 설명할 수 있는지 확인하기 위한 편집 예시이며, 발행 확정 데이터가 아니다.

| 견종 | 역할·역사 | 활동 리듬 | 체격·동선 | 피모·기후 | 관계·독립 | 소리·자극 |
|---|---|---|---|---|---|---|
| 재패니즈 스피츠 | 사람 곁의 스피츠형 반려견 | 규칙적인 산책과 놀이 | 소형~중소형 | 이중모·털갈이 관리 | 가까운 교감, 혼자 쉬기 연습 | 낯선 변화 알림 가능 |
| 몰티즈 | 오랜 소형 반려견 | 짧고 규칙적인 활동 | 초소형·낙상과 핸들링 | 긴 피모·반복 관리 | 사람 가까이 참여, 독립 휴식 연습 | 외로움·자극 상황 표현 가능 |
| 보더콜리 | 양 떼를 모으는 목양 작업 | 지속 활동·과제·휴식 균형 | 중형·움직임 관리 | 털 유형별 관리 | 사람과 협력하며 판단 | 움직임 추적·몰이 단서 |
| 그레이하운드 | 시각 추적과 질주 | 짧은 전력 활동과 긴 휴식 | 대형·안전한 리드와 공간 | 단모·추위와 피부 확인 | 독립적 판단 가능 | 빠른 움직임 추적, 알림은 낮은 편 |
| 사모예드 | 북방 이동·생활 협력 작업 | 규칙적인 높은 활동 | 중대형·힘과 이동 | 두꺼운 이중모·더위·건조 | 사람과 협력·참여 | 주변 변화와 목소리 표현 가능 |

이 표에서 알 수 있듯 `작다/크다`, `활발하다/차분하다` 두 축만으로는 생활 차이가 설명되지 않는다. 특히 보더콜리와 그레이하운드는 모두 달리는 이미지가 강하지만 활동 리듬과 자극 종류가 다르고, 재패니즈 스피츠와 사모예드는 외형 계통이 비슷해도 체격·역할·기후 관리가 다르다.

## 8. 초기 20종에서의 범위 점검

초기 20종은 여섯 홈 카테고리를 시작하기에 충분한 대비를 제공한다.

- 역할: 반려, 목양, 수호, 회수, 후각·시각 사냥, 굴 사냥, 북방 작업이 포함된다.
- 활동: 짧고 규칙적인 활동, 높은 지속 활동, 과제형 활동, 냄새 탐색, 질주와 휴식이 포함된다.
- 체격: 초소형부터 초대형까지 포함되며 힘·이동·안전 동선 설명이 가능하다.
- 피모: 장모, 단모, 이중모, 곱슬 피모와 전문 미용·건조·보온의 차이를 다룰 수 있다.
- 관계: 반려 목적의 가까운 교감, 사람과의 작업 협력, 수호·사냥의 독립 판단 맥락이 포함된다.
- 소리·자극: 알림, 후각 집중, 움직임 추적, 몰이, 독특한 발성 같은 대비가 가능하다.
- 기후: 북방견의 더위 관리, 단모 시각 하운드의 추위 관리, 단두형의 더위·호흡 검수 필요성이 포함된다.

단, 20종만으로 모든 필터 값에 충분한 결과 수가 생기는 것은 아니다. 결과가 2종 미만인 세부 값은 홈 카테고리로 승격하지 않고 상세 정보 태그로만 유지한다.

## 9. 홈 편집 규칙

- 한 카테고리 안에 외형이 유사한 견종만 모으지 않는다.
- 익숙한 견종 1~2종과 낯선 견종 1~2종을 함께 둔다.
- 같은 범주 안에서도 생활 현실이 다른 견종을 배치한다.
- 각 견종의 포함 이유는 `이 범주에 적합하다`가 아니라 관찰할 차이를 설명한다.
- 카테고리 대표 이미지는 견종 한 마리의 미모 컷보다 역할·활동 장면을 우선한다.
- 한 견종이 홈의 여러 카테고리에 반복 노출될 수 있으나 같은 세션에서 동일 카드 카피를 반복하지 않는다.
- 홈 1차 카테고리는 최대 6개를 유지한다. 데이터가 늘어나도 세부 축은 전체 도감 필터에 추가한다.
- 편집 카테고리의 최소 견종 수는 3종, 권장 수는 4~8종이다.

카테고리 결과 카드 카피 구조:

```text
[견종명]
[역할 또는 생활 장면 1개]
[이 축에서 함께 확인할 현실 1개]
CTA: 이 견종의 일상 보기
```

예시:

```text
그레이하운드
빠르게 질주한 뒤 충분히 쉬는 리듬을 살펴봐요.
대형견의 체격과 안전한 추적 관리도 함께 확인하세요.
이 견종의 일상 보기
```

## 10. 전체 도감 필터 UX

### 기본 노출 필터

전체 도감 첫 화면에는 검색과 아래 네 축만 펼쳐서 보여준다.

1. 원래 역할
2. 크기
3. 활동 리듬
4. 피모 관리

`관계와 독립`, `소리와 자극`, `기후와 계절`, `정신적 자극`은 `필터 더 보기` 안에 둔다. 첫 진입부터 많은 성격 필터를 노출해 사용자가 원하는 성격의 개를 주문하듯 고르게 하지 않기 위함이다.

### 정확한 UI 카피

- 필터 패널 제목: `어떤 관점으로 살펴볼까요?`
- 필터 확장: `필터 더 보기`
- 필터 접기: `간단히 보기`
- 선택 초기화: `선택한 필터 지우기`
- 전체 초기화 확인은 요구하지 않음
- 결과 없음 제목: `이 조합으로 표시할 견종이 아직 없어요.`
- 결과 없음 설명: `조건을 하나씩 줄이거나, 전체 도감에서 서로 다른 생활 특성을 살펴보세요.`
- 결과 없음 CTA: `모든 견종 보기`

필터 칩에는 선택 상태를 체크 아이콘과 텍스트로 함께 표현한다. 필터를 적용할 때 페이지를 자동으로 결과 영역까지 스크롤하거나 포커스를 이동하지 않는다. 결과 수는 `aria-live="polite"`로 알린다.

## 11. 데이터 모델 제안

기존 `catalog`, `identity`, `tendencies`, `behaviorClues`, `careNotes`를 화면마다 재해석하기보다 탐색 전용 필드를 정규화한다.

```ts
type ReviewState = "draft" | "source-reviewed" | "expert-reviewed";

type TaxonomyValue<T extends string> = {
  value: T;
  note: string;
  sourceIds: string[];
  reviewState: ReviewState;
};

type BreedTaxonomy = {
  lineageLabels: TaxonomyValue<string>[];
  originalRoles: TaxonomyValue<string>[];
  historyRegions: TaxonomyValue<string>[];

  sizeBand: TaxonomyValue<"xs" | "s" | "m" | "l" | "xl" | "border">;
  adultWeightRange?: { minKg: number; maxKg: number; sourceIds: string[] };
  mobilityChecks: TaxonomyValue<string>[];

  activityDemand: TaxonomyValue<"low" | "moderate" | "high" | "very-high" | "unknown">;
  activityRhythms: TaxonomyValue<string>[];
  enrichmentContexts: TaxonomyValue<string>[];

  coatStructures: TaxonomyValue<string>[];
  groomingActions: TaxonomyValue<string>[];
  climateCautions: TaxonomyValue<string>[];

  relationshipScenes: TaxonomyValue<string>[];
  independentDecisionContexts: TaxonomyValue<string>[];
  alertingBand: TaxonomyValue<"low" | "moderate" | "high" | "individual" | "unknown">;
  vocalContexts: TaxonomyValue<string>[];
  stimulusResponses: TaxonomyValue<string>[];
};
```

### 데이터 운영 규칙

- 필터에는 `source-reviewed` 이상인 값만 사용한다.
- 건강·기후의 위험 설명은 필요한 경우 `expert-reviewed`에서만 필터에 노출한다.
- `draft` 값은 상세 페이지의 검토 중 문구로만 쓸 수 있다.
- 한 축의 값을 추가할 때 기존 20종에 적용 가능한지 먼저 점검한다.
- 동의어는 화면 라벨 하나로 통합하고 원문 용어는 별도 필드에 보존한다.
- 필터 slug는 번역 카피와 분리해 안정적으로 유지한다.
- 분류 변경 시 `taxonomyVersion`을 올리고 기존 URL 파라미터의 호환 규칙을 둔다.
- 범주별 결과 수가 0인 값은 비활성화하되 숨기지 않고 `현재 등록된 견종 없음`을 설명할 수 있다.

## 12. 접근성과 표현 기준

- 필터 그룹은 `fieldset`과 `legend`로 축을 구분한다.
- 체크박스는 실제 다중 선택 컨트롤을 사용하고 칩 모양은 시각 표현으로만 적용한다.
- 선택 여부를 색상만으로 전달하지 않는다.
- 각 축의 도움말은 버튼으로 열고 `aria-describedby`로 연결한다.
- `높은 편`, `낮은 편`에는 무엇의 정도인지 항상 함께 표시한다.
- 모바일 필터 바텀시트는 적용 전후의 결과 수를 보여주되 추천 점수처럼 표현하지 않는다.
- 결과 카드의 이미지가 없어도 견종명, 역할, 생활 장면이 읽혀야 한다.
- 필터 조합 URL에는 개인정보나 사용자의 주거·성격 입력을 저장하지 않는다.

## 13. 출시 단계

### 5종 단계

- 홈 여섯 카테고리를 모두 독립 섹션으로 출시하지 않는다.
- `역할이 만든 오늘의 모습`, `서로 다른 활동 리듬`, `털과 날씨 돌봄` 세 개의 편집 묶음으로 시험한다.
- 상세 필터는 원래 역할, 크기, 활동 리듬, 피모 관리만 제공한다.

### 20종 단계

- 홈 여섯 카테고리를 정식 탐색 입구로 제공한다.
- 전체 도감 상세 필터를 모두 연다.
- 관계·독립·소리·기후 축은 출처 검토가 끝난 견종만 결과에 포함한다.

### 50종 이상 단계

- 카테고리를 추가하기보다 기존 축 안의 세부 값을 확장한다.
- 지역·희소성·공식 그룹은 정렬 또는 보조 탐색으로 제공할 수 있으나 인기 순위는 만들지 않는다.
- 사용자 행동 로그는 카테고리 클릭과 상세 진입을 측정하되 이를 `가장 인기 있는 견종` 추천으로 환원하지 않는다.

## 14. 수용 기준

- [ ] 홈의 1차 카테고리가 5~7개 범위이며 본 명세에서는 6개로 고정되어 있다.
- [ ] 외모·인기·쉬운 양육이 1차 카테고리에 포함되지 않는다.
- [ ] 역사와 역할, 활동 요구와 리듬, 교감과 독립, 소리와 경계가 각각 구분된다.
