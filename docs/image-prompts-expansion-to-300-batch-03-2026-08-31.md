## 생성 공통 프롬프트와 판정

공통 프롬프트는 따뜻한 한국어 편집 삽화용 수채·구아슈, 크림 종이 질감, 4:3 가로 화면, 성견 한 마리의 자연스러운 전신을 고정했다. 사람·추가 동물·문자·로고·콜라주를 금지하고, 견종별 피모·귀·체형·모색과 닫힌 문 등 장면 경계를 프롬프트에 명시했다.

- 생성 PNG 원본은 보존하고 화면 자산 40개는 1200×900, 품질 84 WebP로 변환했다.
- 루마니안 카르파티안 셰퍼드의 첫 야외 시안은 귀가 곧게 서서 폐기했다. 늘어진 삼각 귀를 명시한 새 시안으로 교체했다.
- 대표 컷 육안 검수에서 전신 노출, 견종 외형 표지, 장면 도구와 카피의 일치, 닫힌 출입문과 4:3 크롭을 확인했다.
- 상세 데이터의 네 신규 이미지 경로와 실제 파일을 자동 검사하며, 300종 완성 뒤 한국어 편집과 이미지 전수 비교를 별도로 진행한다.
