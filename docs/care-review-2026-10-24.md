# 성격·활동량·돌봄·건강 원고 점검

2026-10-24. 로컬에서만 수정했다. 커밋·푸시·배포는 하지 않았다.

후속: 캐벌리어의 편집 상태 안내 1곳은 [유전 질환·검사 점검](genetic-health-review-2026-10-24.md)에서 구체화했다. 아래 36곳·유지 8곳은 당시 집계이며 현재 활성 문구는 35곳이다. 대체된 기록과 해시는 보존한다.

## 범위와 결과

376종 원본과 작성된 표준 상세 270종(공개 245종)을 대상으로 후보 문구를 찾고, 그중 23종 36개 텍스트 단위를 자료와 대조했다. 22종 28곳을 수정하고 8곳은 제한된 범위에서 유지했다. 전체 원고 대조나 수의학·행동 전문가 검수 완료를 의미하지 않는다.

- 공개 표준 상세: 8종 11곳 수정.
- 제작 보류 중인 아리에주아 표준 상세: 1곳 수정. 공개 전환하지 않았다.
- 원본 견종 데이터: 16곳 수정. 별도의 표준 상세를 사용하는 화면에서는 이 문구가 그대로 노출되지 않을 수 있다.
- 원문·수정문 해시, 실제 조립 데이터의 필드, 유지 이유, 출처와 공개 여부는 [검토 기록](audits/care-review-2026-10-24.json)에 있다. 이전 역사·소개문 점검의 80개 수정 기록과 별도 집계한다.

유지한 8곳은 로트바일러의 원본 행동 설명·공개 현실 안내, 골든두들의 역할 설명, 보더 콜리의 관리 안내, 콘티넨털 불도그의 현실 안내, 하바니즈·프렌치 불도그의 원본 활동량 설명, 캐벌리어의 건강 편집 상태 안내다. 마지막 항목은 전문가 미검수 표시를 유지한 것이며 질병 내용의 정확성을 승인한 것이 아니다.

## 확인한 자료와 출처 표시

Cornell 수의과대학의 호흡 곤란·피부 안내, PDSA의 눈·귀·운동 안내, AAHA의 구강 관리·분리 불안 안내, AAAAI의 반려동물 알레르기 안내, Broad Institute의 행동 유전 연구 초록, BSAVA의 훈련 입장을 확인했다. 10개 자료의 정확한 URL과 확인일은 검토 기록의 `sources`에 있다. 각 기록은 해당 주장에 필요한 범위로 연결했으며 원문을 길게 옮기지 않았다.

행동 연구의 PMC 원문은 접근 확인 화면에 막혀 Broad Institute가 제공한 초록 범위만 사용했다. RVC 호흡 자료는 접근이 차단돼 근거에 포함하지 않고 Cornell 자료를 사용했다. 읽지 못한 자료를 검토 완료로 처리하지 않았다.

기존 견종 출처를 보존하고 이번 근거를 추가했다. 표준 상세에서도 접힌 ‘정보 출처와 편집 안내’를 열 수 있게 했다. 자료별 확인일과 ‘수의학·행동 전문가 검수 전’ 안내를 유지하며, 첫 출처의 날짜가 모든 자료의 확인일처럼 보이던 요약 날짜는 제거했다.

`pnpm audit:rights`는 기존 3차 기록 39곳과 이번 36곳의 실제 문구·필드·해시, 이번 출처 연결 및 공개 여부를 확인한다. 표준 상세 원고가 존재하는 것과 실제 공개되는 것은 구분한다.

## 검증

- lint·typecheck 통과.
- 전체 테스트 65파일, 1,717개 통과. 프로덕션 빌드 387페이지 생성 완료.
- 원고·자산 감사 통과. 이미지 1,880개는 HEAD와 동일하며 이번에 변경하지 않았다.
- 홈·대상 23종·푸들 총 25페이지를 PC 1440px, 모바일 390/320px에서 확인했다(75화면). HTTP 200, 가로 넘침·JavaScript 오류 없음. 공개 수정 문구 11곳을 각 너비에서 확인하고 탭/단계 이동·이미지 로딩·출처 펼치기·키보드 접근·자료 링크를 검사했다. 프렌치 불도그·하바니즈 본문과 출처 안내 화면도 직접 확인했다.
- 첫 테스트에서 드러난 기존 출처 개수 변화와 원고 표현 계약 위반을 수정했다. 기존 테스트를 완화하거나 삭제하지 않았다.
- 검증 로그와 화면은 Git에서 제외된 `tmp/care-*`에 있다. 실기기 iOS 검증은 하지 않았다.

## 남은 검토

이번에 선택하지 않은 성격·활동·돌봄 원고, 견종별 유전 질환·권장 검사·가족력, 어린 개·노령견·질환이 있는 개의 개별 관리 계획은 후속 범위다. 초보 보호자·성장 가이드와 건강 장면 이미지 전체를 이번에 대조한 것은 아니다. 출처 연결과 표현 정리는 전문가 검수나 전체 저작권 승인과 구분한다.
