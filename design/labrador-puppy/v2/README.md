# 래브라도 v2 — 얼굴 연결 수정 시안

상업용 포토리얼 완성 모델이 아니다. 눈꺼풀과 얼굴 피부 연결, 귀 내부 위치, 안구 돌출 범위, 수염·눈썹 시작점을 수정했다. 눈 위의 작은 표면 자국, 인공적인 눈매와 볼 형태, 수작업 쿼드 리토폴로지 및 변형 검증은 남아 있다. 정적 메시이므로 애니메이션에 바로 사용할 수 없다.

- `exports/labrador-puppy-fur.blend`: 털·조명·카메라·숨겨진 고해상도 원본 포함. Blender 4.5.9, Cycles, AgX.
- `exports/labrador-puppy-base.blend`: 털 없는 기본 메시와 고해상도 원본.
- `exports/labrador-puppy.obj` / `.mtl`: 털 없는 교환용 파일.
- `textures/`: 4K Base Color·Roughness·Normal·Displacement. `exports/`와 상대 위치를 유지한다.
- `previews/`: 단계 2~6 및 최종 정면·측면·후면·3/4·얼굴 확대. 체형 단계 1은 상위 v1 폴더에 공통 보존.
- `reports/`: 메시·털·텍스처·파일 재불러오기 검사.

몸체 조형 원본 1,063,832면, 정적 렌더 몸체 340,426개 삼각형. 자동 쿼드 변환과 기존 케이지 투영을 시도했으나 실패/교차 문제로 채택하지 않았다. 현재 삼각형 메시를 프로덕션 쿼드 토폴로지로 취급하지 않는다.

털 491,121가닥, 수염·눈썹 가이드 26개. 최종 5방향 1,600×1,400 PNG. 부위별 털 흐름과 길이를 설정했지만 변형 표면 추종은 미검증이다.

개별 메시 검사에서 열린 경계·비매니폴드·불일치 면 방향·퇴화/중복 면·음의 체적·비인접 삼각형 교차·누락 텍스처는 0건. 두 Blender 파일 재열기와 OBJ 재수입에서 누락 텍스처 없음. OBJ는 57개 메시·513,446면이다. 검사는 서로 다른 부품 간 관통이나 사실적인 해부학을 보증하지 않는다.

웹사이트에 적용하지 않은 별도 시안이다. 전체 제작 기록과 v1/v2 비교 화면은 상위 폴더의 README.md와 review.html에 있다.
