# 래브라도 — 관절·목·몸통 수정

사용자가 지적한 접힌 팔꿈치/무릎의 뾰족한 표면, 가슴이 다리에 끌리는 모습, 낮고 고정된 목과 두꺼운 몸통을 수정한 별도 시안이다. `motion-physics`의 0.48초 주기와 접지 계산을 유지하고 기본 체형·가중치·목 움직임·관절 표면을 변경했다. 이전 원본은 덮어쓰지 않았다.

## 수정

- 몸통 중앙의 폭을 최대 14% 줄이고, 배 밑선과 몸통 아래쪽을 부드럽게 올렸다. 발과 발바닥에는 이 체형 변환이 적용되지 않는다.
- 머리 쪽을 최대 34mm 위·13mm 뒤로 이동하고 목 표면에 점진적으로 연결했다. 주둥이를 그대로 위로 돌리는 방식이 아니라 목이 위로 이어지도록 기본 체형을 바꿨다.
- 목 중간 컨트롤러 2개를 추가해 총 24개가 됐다. 몸통 상하 속도에 따른 목 굽힘과 머리 보정을 분리했다. 실제 경추 뼈를 재현한 프로덕션 리그는 아니다.
- 다리 영향 범위를 상완/허벅지 주변으로 좁히고 가슴 쪽 영향을 줄였다. 변형에 실제 사용하는 가중치의 합을 1로 정규화했다.
- 팔꿈치·무릎 주변에 국소 표면 평활을 적용했다. **이 보정은 부피를 보존하지 않는다.** 깊은 접힘의 뾰족한 표면을 없애면서 근육 덩어리도 일부 줄어든다.
- 털은 보정 전 피부에 붙어 있던 위치를 기준으로 표면 이동량을 받아 따라간다. 보정 후 피부의 가까운 점을 찾던 첫 방식에서 발견한 털 뿌리 들뜸을 수정했다.

## 결과물

`review.html`의 비교 메뉴는 수정 전 `motion-physics`와 같은 프레임·속도로 전환한다. 10/35프레임의 접힌 관절, 20/27프레임의 목과 몸통 선을 비교한다. 정지·¼ 속도로 시작하며 키보드·슬라이더와 숨은 탭/화면 밖 정지를 지원한다.

- `exports/puppy-run-study.blend`: 새 체형, 24개 컨트롤러, 관절 평활과 털 연결을 포함한 Blender 원본.
- `textures/`: 상대 경로로 연결한 기존 4K 맵 4장. 원본과 함께 디렉터리 구조를 유지한다.
- `frames/side`, `frames/three-quarter`: 실제 Cycles·AgX·960×720·24 samples 렌더 각 48장.
- `preview-*.webp`: 정상 480ms·¼ 속도 1,920ms 미리보기 4개.
- `../puppy-anatomy-run.zip`: 필요할 때 `package_motion.py`로 생성하는 전달용 묶음. 중복 용량 정리를 위해 2026-09-13 로컬 ZIP은 제거했으며 원본과 미리보기는 유지한다.

Blender에서 열기와 재생에는 Python 스크립트가 필요 없다. 재생성은 전체 프로젝트와 이전 `motion-physics` 원본을 요구한다. `--python build_anatomy.py -- build`, `-- render side`, `-- render three-quarter`를 사용한다. PNG가 모두 나온 뒤 Pillow가 있는 Python으로 `package_motion.py`를 실행한다.

## 검사와 한계

`reports/anatomy-verification.json`은 10·27·35·44프레임에서 평활 전후를 같은 변형 메시로 비교한다. 관절 표면과 이웃 정점 평균의 거리 95백분위가 모두 감소했고, 평활 가중치가 없는 표면의 이동은 0이다. 10프레임의 최대 표면 보정은 20.74mm로 작지 않다. 처음 설정한 12mm 검사 한도를 넘었으므로 해당 자세 PNG를 다시 확인했고, 작은 변형이나 부피 보존으로 해석하지 않도록 최대치를 기록했다. 가중치 합 오차는 0.000000045 미만이며 목 컨트롤러의 회전 변화도 확인했다.

`reports/verification.json`은 재열기 후 몸체·얼굴·귀·털 루프, 비정상 좌표, 텍스처와 지지 발 높이를 검사한다. 몸체/얼굴/귀/털 루프 차이·누락 텍스처·비정상 좌표 0, 지지 발 높이 변화 0, 발바닥/발톱 최저점 +1.20mm다. 털 연결 보정은 `reports/hair-attachment.json`에 별도로 기록한다. 선택한 9프레임에서 프레임당 약 1,500개 몸통 털 뿌리와 실제 보정 피부 사이의 거리를 확인한다. 전체 털·귀·수염의 충돌 전수 검사는 아니다.

`verify_player.mjs`는 JSDOM으로 전후 동일 속도·프레임 유지·힘 표시·키보드·화면 밖 정지와 이미지 경로를 검사한다. 실제 브라우저 렌더링이나 실기기 성능 측정은 포함하지 않는다.

관절의 정확한 근육 부피·깊은 접힘의 실루엣·얼굴과 털의 사실성·변형용 쿼드 토폴로지·전신 뼈 리그는 여전히 미완료다. 전체 자가 교차나 해부학 전문가 검수를 통과한 에셋이 아니며 라이브 푸터에는 연결하지 않았다.
