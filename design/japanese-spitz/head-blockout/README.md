# 새 머리 기본형 — 털 없는 구조 검토

사진을 다시 분석하고 머리만 새로 만들자는 제안에 대한 작업이다. 이전 머리를 변형한 모델이 아니라, 이마에서 코까지의 단면을 새로 정의한 독립 기본형이다. 몸통과 기존 07 파일에는 적용하지 않았다.

`exports/09-new-head-blockout.blend`에는 두개부/주둥이, 턱, 코 기준 형태, 양쪽 안구와 귀가 있다. 회색 재질만 사용하며 털·피부 텍스처·완성 표정·리깅은 없다. 기본형 검수는 아직 통과로 판정하지 않았다.

## 참고 해석

- `../references/face-primary.png`의 이마–코 경사와 눈/코/귀 관계를 주요 참고로 삼았다. `side-support.png`는 옆면 보조이며 동일 개체의 보정된 다중 시점 사진으로 보지 않는다.
- 사진의 외곽에는 털 두께가 포함된다. 따라서 새 메시의 단면 폭은 털 아래 형태를 추정한 수치이며 사진에서 직접 측정한 골격값이 아니다.
- 첫 조립 후 너무 길게 읽히던 주둥이를 줄이고 높이를 올렸다. 떨어져 보이던 구형 코를 짧은 단면 연결 형태로 바꾸고 주둥이 양옆의 추가 타원체를 제거했다.

## 내부 비교와 판정

`previews/front.png`, `side.png`, `reference-angle.png`는 현재 기본형이다. `previous-`가 붙은 세 장은 07 오브젝트의 임시 복사본에서 털을 제외하고 같은 회색 재질·조명·카메라·배율로 렌더했다. 비교용 복사본만 뒤쪽에서 잘랐으며 원본 07 파일은 수정하지 않았다. 카메라는 참고 사진과 유사한 각도를 추정했으며 정확히 보정한 카메라가 아니다.

이전의 큰 이마 덩어리와 긴 원통형 주둥이가 줄고 이마–주둥이의 경사가 더 연속적으로 보인다. 그러나 눈구멍의 형상/안구 노출, 턱의 뒤쪽 연결과 단순한 단면은 아직 해결할 부분이다. **사진 유사도나 최종 기본형 합격은 주장하지 않으며, 털/상세 표정 단계로 진행하지 않았다.**

## 재현과 확인

작업 중인 파일을 보존하고 새 작업 파일에서 `../new_head_blockout.py`를 import한 뒤 `build()` → `render()` → `verify()`를 실행한다. `build()`는 현재 작업 장면의 오브젝트를 비우므로 원본 작업 장면에서 실행하지 않는다. `compare_previous()`는 07 복사본을 일시적으로 불러와 비교 렌더만 만들고 복사본을 제거한다.

현재 작업 전의 미저장 상태는 로컬 `tmp/blender-session-backups/before-new-head-20260913.blend`에 별도 보관했다. 작업 시작 전에 이미 수정되어 있던 07은 변경/스테이지하지 않는다. 검사 보고서에 이번 작업에서 참조한 07의 SHA-256을 기록했다.

저장한 새 파일을 다시 열어 7개 메시의 비매니폴드 모서리와 면적 0인 면이 0개임을 확인했다. 첫 Boolean 연산의 미세한 퇴화 면은 1μm 범위 병합/정리로 수정했다. 이는 전체 자가 교차, 변형용 토폴로지, 해부학 또는 시각적 유사도 합격을 뜻하지 않는다.
