공식 표준에 없는 몸무게는 기존 카탈로그 초안에 숫자가 있어도 상세 카드에 유지하지 않았다. 포뎅고와 페루비안 헤어리스는 전체 범위 한 줄 대신 세 유형을 펼침 정보로 분리했다. 가스콩 생통주아는 큰형·작은형과 성별 네 범위를 각각 표시했다.

## 장면 설계와 최종 파일

모든 이미지는 내장 이미지 생성 도구로 서로 다른 프롬프트를 사용해 만든 뒤 1200×900 WebP로 저장했다. 공통 제약은 한 장에 성견 한 마리, 전신·발·꼬리 노출, 역사 장면 외 현대 도구 사용, 글자·로고·워터마크 금지다.

최종 파일은 `/public/illustrations/v3/{slug}-history.webp` 10장과 `/public/illustrations/v4/{slug}-feature-{id}.webp` 40장이다. 50장 접촉 검수에서 맨체스터 테리어 5장이 곧게 선 귀로 미니어처 핀셔와 혼동될 여지가 있어 모두 폐기하고, 자연스러운 작은 V자 접힌 귀가 보이는 장면으로 재생성했다. 기존 상세가 이미 있던 베들링턴 테리어는 신규 대상에서 제외했으며, 중복 확인 중 만든 특징 컷은 사용하지 않았다. 기존 역사 컷만 광산 마을 역할이 더 선명한 장면으로 갱신했다.
