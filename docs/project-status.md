# Dog Atlas 프로젝트 현재 상태

> 마지막 갱신: 2026-09-09. 현재 상태의 진입점이며 이전 실험 분석은 정리했다.

## 제품과 보존 범위

- 전달 방식: 사용자는 로컬 확인이 어려우므로 앞으로 검증을 마친 개발 변경은 바로 커밋하고 `main`에 푸시하도록 승인했다. 배포 사이트 반영 여부를 확인해 보고한다.
- 메인 `/`: 소형견 16종·중형견 12종·대형견 13종·초대형견 8종의 양면 수채화 카드. 소형은 치와와·포메라니안·요크셔 테리어·말티즈·토이푸들(실버)·비숑 프리제·시츄·미니어처 닥스훈트·미니어처 슈나우저·파피용·말티푸·퍼그·페키니즈·이탈리안 그레이하운드·꼬똥 드 툴레아·미니어처 핀셔. 초대형은 그레이트 피레니즈·세인트 버나드·그레이트 데인·아이리시 울프하운드·티베탄 마스티프·캉갈 셰퍼드 도그·코카시안 셰퍼드·몽골 방카르.
- `/discover`: 전체 376종의 발견·검색·필터·국내 익숙한 견종 시작 목록. URL/뒤로가기 상태와 점진 표시를 유지한다.
- 모든 `/breeds/[slug]` 상세와 기존 원고·그림·데이터·공통 로직을 보존했다. 8종 이외의 상세도 삭제하지 않았다. 등록된 표준 상세와 제작 초안의 구분을 유지한다.
- 상세가 연결하는 `/beginner-guide?breed=...` 및 진행 상태를 보존한다. 상세 디자인 재구성과 다른 크기 카드 추가는 다음 논의 대상이다.

## 현재 카드 디자인과 성능

- Blender MCP로 둥근 슬랫·팔걸이·금속 프레임 벤치와 꼬인 면 로프 장난감을 제작해 운동장에 적용했다. 로컬 GLB 439,808B/5개 재질 그룹을 푸터 진입 때 로드하고 정적 그림자를 1회 갱신한다. 실패 시 기존 벤치 유지, 로딩 중 해제/자원 정리 지원. 잔디는 Lambert 조명·짧은 풀잎·34,000/16,000개 인스턴스로 변경했다. 공 조작은 유지. PC/모바일 모델·공 던지기·오프스크린/동작감소, lint·typecheck·1,655개 테스트·385페이지 빌드 확인. [Blender 원본](../design/yard-blender/README.md).

- PC(901px 이상) 메인 가독성을 높였다. 검색 16px, 보기 전환/번호 14px, 주요 행동/카드 설명 15px, 카드 제목 30px, 푸터 14px로 확대하고 한 장 카드/번호 영역을 420px로 맞췄다. 뒷면 정보와 4열 펼쳐보기 설명도 확대했다. 모바일 크기는 유지하며 PC 양면/목록·모바일 넘침 없음, lint·typecheck·테스트·385페이지 빌드 확인.

- 사용자 요청으로 Blender MCP 재제작 미리보기를 진행했다. `design/blender-spitz`에 편집 가능한 .blend와 실제 Cycles 사선/정면 렌더를 저장한다. 연속 몸체·파티클 털·매립한 눈·말린 꼬리의 정지 시안이며 리깅·웹용 털 변환·성능 검증은 아직 없다. 사이트에는 미적용이다.

- 사용자 요청으로 운동장 강아지 표시와 배회·공 추적 연결을 제거했다. 잔디·벤치·테니스공 물리와 던지기는 유지한다. 스피츠 재제작은 중단하며 미승인 로컬 시안은 배포에 포함하지 않는다.

- 운동장 위 문구를 함께하기 전 이해와 끝까지 책임지는 메시지로 변경했다. 하단은 연도·견종도감 저작권 표기와 견종 정보의 개체차 안내만 남겼다. PC/모바일 줄바꿈·Three.js 동작과 정지, lint 및 타입 검사 포함 빌드를 확인했다.

- 사용자 승인으로 2색 공을 머스터드 연두색 테니스공으로 교체했다. Three.js 재질의 절차적 펠트 질감·마모와 닫힌 곡선 이음선을 사용한다. 이전 캡/토러스 자원을 제거하고 새 재질·텍스처 정리를 연결했다. PC/모바일 던지기·스크롤·reduced motion·화면 밖 정지 및 lint·타입 포함 빌드 확인.
