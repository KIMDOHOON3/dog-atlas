# 함께 갈 곳 — 사진 없는 공공데이터 장소 안내

2026-09-14 사용자가 장소 탐색 범위를 다시 승인했다. 푸터의 애견카페 마당 안내판에서 `/places`로 이동한다. 사진·병원 데이터는 추가하지 않는다. 2026-09-15 방문 편의를 위해 카카오 지도/길찾기 링크와 위치 기반 검색을 추가했다. 내장 지도 SDK는 아직 포함하지 않는다.

## 데이터 연결

- 공식 서버: `https://apis.data.go.kr/B551011/KorPetTourService2`. 이전 버전은 실호출에서 400, 현재 버전은 `DATA_PET_TOUR_SERVICE_KEY`로 정상 응답한다(2026-09-15 사용자 변경 이름 적용). 키는 `.env.local` 및 배포 환경의 같은 서버 변수에서 읽는다. 환경 파일은 Git 제외이며 키를 클라이언트로 전달하지 않는다.
- 목록: `areaBasedList2`, 이름 검색: `searchKeyword2`, 지역: `ldongCode2`. 초기 화면은 산책·관광이며 모든 장소 또는 음식점/숙박 등 다른 유형도 선택 가능하다. 20개씩 실제 총수 기반 페이지 이동, 지역·유형·검색어를 URL에 보존한다.
- 상세: `detailCommon2` + `detailIntro2` + `detailInfo2` + `detailPetTour2`. 제목/주소/소개, 운영·이용 정보, 반복 안내, 동반 조건을 표시한다. 빈 값은 생략하고 기술 코드/좌표/등록·수정 시각은 펼쳐보기에 둔다. 알려지지 않은 텍스트 필드도 버리지 않는다.
- 이미지 전용 API를 호출하지 않는다. 응답의 image/photo/img 필드는 서버에서 제거하고, 원격 HTML은 텍스트로 바꾼다. 장소 화면에 이미지·빈 썸네일·원격 이미지 요청이 없다.
- Zod 응답 검증, 12초 요청 제한, 정제한 응답 1시간 캐시. 오류는 인증 URL을 포함하지 않는 공통 문구로 바꾼다. 상세 부가 조회 중 일부 실패 시 성공한 정보는 유지하며 실패와 미제공을 구분한다.
- 출처는 한국관광공사·공공데이터포털로 표시하며 방문 전 운영·동반 조건 확인을 안내한다. 공식 서비스 설명: https://www.data.go.kr/data/15101578/openapi.do (국문 서비스의 공통 상세 항목 설명). 실연결은 반려동물 전용 서비스다.

## 마당과 접근성

Blender에 8패널 크림 파라솔, 원형 원목 테이블, 의자 2개, 뒤쪽 부분 울타리를 추가했다. 후속 배치 승인에 따라 허들·세로 막대를 제거하고 울타리를 짧게 줄였다. 벤치와 그릇은 뒤 왼쪽, 파라솔은 뒤 오른쪽, 장난감은 좌우 가장자리에 배치한다. 정적 재질 병합과 독립 장난감 루트를 유지한다. GLB 1,143,420B / 16메시 / 38,072삼각형. 충돌체도 배치와 동기화했다. 안내판은 Three.js에서 별도 생성한다.

사용자가 HTML 문구를 얹은 이전 표현을 거절했다. 이제 안내판의 판자·기둥·덮개·나사와 글씨 모두 `yard-sign.ts`의 Three.js 메시다. 표면 글씨는 투명 CanvasTexture를 Standard 재질로 입혀 카메라·조명·가림을 따른다. Raycaster로 실제 보드를 클릭하며 터치는 최소 44px에 맞춘 보이지 않는 3D 판정 볼륨을 사용한다. 드래그·pointercancel은 이동을 취소한다. 화면에 HTML 문구를 얹지 않는다. 시각적으로 숨긴 의미 링크는 키보드/스크린리더와 WebGL 실패 시 대체 이동에 사용하며, 키보드 포커스는 3D 재질 강조로 표시한다. 링크 prefetch를 끄고 클릭 시에만 장소 데이터를 조회한다.

## 검증

안내판은 앞 중앙(0, 0, 2.9)에 크림 판/갈색 글씨로 강조한다. PC와 모바일 공통 5.6초 코사인 주기로 표면 emissiveIntensity가 0.025~0.13 사이를 천천히 오간다. 포인터와 무관하게 작동하며 기존 가시성 제한 렌더 루프를 공유한다. hover/focus는 더 강한 강조를 유지하고, reduced motion은 0.08 고정이다. 단위 테스트로 자동 최대/최소, reduced motion 고정, dispose 후 중단을 확인했다.

기존 키로 전체 9,679개, 산책·관광 752개 응답 확인(조회 시점 수치). `애견` 이름 검색과 삼막애견공원 상세에서 실제 운영시간·주차·이용료·동반조건 표시를 확인했다. 새 테스트는 사진 필드 제거, HTML 정제, 빈/단일/오류 응답, 요청 범위 검증, 비밀이 포함된 오류 차단, 상세 부분 실패 유지, 잘못된 ID 차단을 다룬다.

배포 환경에도 `DATA_PET_TOUR_SERVICE_KEY`가 필요하다. 로컬 파일이 Vercel로 자동 전송되지는 않는다.

공개 배포 검증(2026-09-15): 서버 변수명을 `DATA_PET_TOUR_SERVICE_KEY`로 맞춘 기능 커밋 `f604975`의 Vercel 배포 성공을 확인했다. 공개 `/places`에서 산책·관광 752건, 경기도+삼막 검색 1건, 삼막애견공원 상세의 운영시간·주차·입장료·동반 조건을 확인했다. 상세 DOM 이미지 0개. 이전 공개 API 조회 실패는 해결됐으며 Vercel 인증을 기다리는 상태가 아니다. lint/typecheck/build 및 60파일·1,693테스트 통과. 키 값은 환경 파일·배포 서버에만 유지하고 저장소에 포함하지 않는다.

## 2026-09-15 방문 편의

- 상세 첫 화면: 전화 연결, 주소 복사와 실패 안내, 카카오 지도/길찾기. 관광공사 contentid는 Kakao 장소 ID로 쓰지 않고 유효한 위경도 URL을 만든다. 좌표가 없으면 이름+주소 검색으로 연결한다.
- 요약: 실제 동반 구역/가능 동물/준비·주의사항, 음식점 대표·취급 메뉴, 제공되는 면적/규모와 좌석, 시간·휴무·주차·요금. 없는 값은 미제공으로 표시하고 임의 평수·실시간 영업중·입장 가능 판정을 만들지 않는다. 원본의 전체 텍스트 그룹도 유지한다.
