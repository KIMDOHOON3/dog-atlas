## QA와 재생성

- 카드 7장과 역사 7장을 생성 원본과 최종 WebP에서 각각 `view_image`로 확인했다.
- 검수 항목: 견종 체형, 귀·꼬리·발의 완전한 노출, 신체 잘림, 추가 사지, 글자·목줄·소품, 역할 맥락의 과장 여부.
- 14장 모두 1차 결과가 검수 기준을 통과해 재생성하지 않았다.
- built-in ImageGen 결과를 사용했으며 원본 PNG는 Codex 생성 이미지 저장소에 보존했다.
- 프로젝트 파일은 저장소에 이미 있던 transitive `sharp`를 직접 불러 1024×1024 또는 1536×1024로 변환하고 WebP quality 88로 저장했다. 별도 패키지는 설치하지 않았다.
