# 살아 있는 견종도감 디자인 개선 명세

작성일: 2026-08-02  
적용 대상: 초기 20종 카탈로그, 홈, 견종 상세, 유사 견종, 2종 비교  
목적: 부드러운 도감 분위기를 유지하면서 읽기 쉬운 정보 구조와 확장 가능한 견종 탐색 경험을 만든다.

## 1. 구현 우선순위

| 우선순위 | 작업 | 완료 기준 |
|---|---|---|
| P0 | 전역 타이포·색 대비·본문 폭 수정 | 홈·상세·비교가 같은 폰트 체계를 사용하고 일반 본문 대비 4.5:1 이상 확보 |
| P0 | 비교 화면 타이틀과 정보 위계 통일 | 비교 타이틀이 다른 화면의 `page-title` 토큰을 사용하며 별도 장식 폰트 제거 |
| P1 | 의미 기반 일러스트 포인트 배치 | 역사·활동량·털 관리·주거환경 정보에 각각 설명 목적의 시각 요소 적용 |
| P1 | 오늘의 강아지 수동 캐러셀 | 자동재생 없이 이전·다음·스와이프·키보드 접근 가능 |
| P2 | 생활조건 기반 탐색 | 주거형태·활동량·크기·계통 필터와 비단정적 결과 언어 구현 |

P0 수정 전에는 장식 일러스트를 추가하지 않는다. 가독성을 먼저 확정한 뒤 P1 비주얼을 배치한다.

## 2. 전역 가독성 토큰

### 2.1 폰트 패밀리

```css
--font-sans: "Pretendard Variable", Pretendard, "Noto Sans KR", system-ui, sans-serif;
```

- 홈, 상세, 비교, 버튼, 표에 같은 패밀리를 사용한다.
- 비교 화면 타이틀만 다른 폰트나 영문 디스플레이 폰트를 사용하지 않는다.
- 한글 본문은 400, 요약·레이블·버튼은 500, 주요 제목은 600 또는 700을 사용한다.
- 숫자는 지원될 경우 `font-variant-numeric: tabular-nums`를 적용한다.

### 2.2 글자 크기와 행간

| 토큰 | 데스크톱 | 모바일 | 용도 |
|---|---|---|---|
| `display` | 52px / 1.12 / -0.04em | 38px / 1.16 / -0.035em | 홈 히어로 한정 |
| `page-title` | 42px / 1.18 / -0.035em | 32px / 1.22 / -0.025em | 상세·비교 페이지 제목 |
| `section-title` | 30px / 1.28 / -0.025em | 25px / 1.32 / -0.02em | 주요 섹션 제목 |
| `subsection-title` | 21px / 1.4 / -0.015em | 19px / 1.42 / -0.01em | 정보 그룹·카드 제목 |
| `lead` | 19px / 1.7 / -0.01em | 18px / 1.68 / -0.005em | 제목 아래 핵심 요약 |
| `body` | 17px / 1.75 / 0 | 16px / 1.72 / 0 | 일반 설명 본문 |
| `body-small` | 15px / 1.65 / 0 | 14px / 1.62 / 0 | 보조 설명·표 안의 설명 |
| `caption` | 13px / 1.55 / 0.005em | 13px / 1.55 / 0.005em | 출처·검토일·이미지 캡션 |

- 중요한 정보를 `caption` 크기로 내리지 않는다.
- 본문 단락은 최대 68자(`max-inline-size: 68ch`), 리드 문장은 최대 46자로 제한한다.
- 긴 상세 본문 컨테이너는 최대 720px, 읽기 중심 단락은 내부에서 최대 640px로 제한한다.
- 본문 단락 사이 간격은 16px, 제목과 첫 본문 사이는 12px, 섹션 간격은 데스크톱 88px·모바일 64px를 기본으로 한다.
- 한 단락은 모바일 기준 5줄을 넘기지 않도록 편집하고, 더 긴 내용은 소제목 또는 목록으로 분리한다.

### 2.3 색과 대비

부드러운 베이지·세이지 배경은 유지하되, 텍스트에 배경색을 섞어 흐리게 만들지 않는다.

```css
--color-bg-canvas: #F6F3EA;
--color-bg-surface: #FFFDF8;
--color-bg-soft-green: #E3EADF;
--color-text-primary: #202522;
--color-text-secondary: #4F5953;
--color-text-tertiary: #66716A;
--color-border: #C8CDC7;
--color-action: #315844;
--color-action-contrast: #FFFFFF;
--color-caution-bg: #F2E6D2;
--color-caution-text: #3B3024;
```

- 일반 본문과 링크는 실제 배경 기준 4.5:1 이상, 큰 제목은 3:1 이상을 충족해야 한다.
- `opacity`로 본문을 흐리게 하지 않는다. 보조 텍스트는 별도 색 토큰을 사용한다.
- 배경 일러스트 위에 본문을 직접 올리지 않는다. 카피와 이미지를 분리하거나 불투명한 텍스트 표면을 둔다.
- 경고·주의는 빨간색 대신 차분한 모래색 표면과 명확한 제목을 사용하되, 의미를 색만으로 전달하지 않는다.
- 다크 모드를 구현할 경우 위 값을 그대로 반전하지 말고 같은 대비 기준으로 별도 토큰을 검증한다.

## 3. 화면 공통 정보 위계

각 섹션은 아래 순서를 반복한다.

1. 13px 맥락 레이블: `과거의 역할`, `오늘의 생활`, `주의 깊게 볼 점`
2. 섹션 제목
3. 1~2문장의 요약
4. 본문 또는 구조화 데이터
5. 출처·검토일

레이블은 제목을 대신하지 않는다. 제목과 요약만 읽어도 페이지의 논리가 연결되어야 한다.

## 4. 비교 화면 타이포 및 구조

### 4.1 타이틀

- 비교 화면의 `h1`은 전역 `page-title` 토큰을 그대로 사용한다.
- 권장 문구: `재패니즈 스피츠와 사모예드, 같은 기준으로 살펴보기`
- 영문 견종명은 제목 아래 `caption` 또는 `body-small`로 분리한다.
- 타이틀에 세리프·필기체·별도 영문 폰트를 혼용하지 않는다.
- 제목 아래에는 점수나 승자를 표시하지 않고 비교 목적을 한 문장으로 설명한다.

```text
재패니즈 스피츠와 사모예드,
같은 기준으로 살펴보기

닮은 외형보다 실제 생활에서 체감할 차이를 먼저 보여드려요.
```

### 4.2 비교 정보 위계

- 상단 견종 헤더: 동일 크기의 3:4 전신 이미지, 한글명, 영문명, 계통만 표시한다.
- 1단계 요약: `가장 크게 다른 점` 2~3개를 문장으로 제공한다.
- 2단계 비교: 크기, 활동 요구, 털 관리, 더위 주의, 짖음 경향, 주거 부담 등 동일 항목을 행으로 비교한다.
- 3단계 해석: `현재 생활에서 먼저 확인할 점`을 제공한다.
- 출처와 일반적 경향 안내는 표 하단에 둔다.

### 4.3 비교 행 규격

- 데스크톱: `항목 28% / 견종 A 36% / 견종 B 36%`
- 모바일: 항목명을 한 행 전체에 먼저 표시하고 그 아래 A·B를 2열로 배치한다.
- 행 제목 15px/500, 값 16px/500, 설명 14px/1.62를 사용한다.
- 행 최소 높이는 데스크톱 88px, 모바일은 내용 기반 최소 112px로 한다.
- `높음/낮음`만 쓰지 않고 한 줄 설명을 함께 둔다.
- 우위처럼 보이는 초록·빨강 비교, 승자 체크, 백분율 적합도는 사용하지 않는다.
- 이미지·견종명 헤더는 긴 비교에서만 `position: sticky`를 고려하며, 모바일에서는 화면 높이의 25%를 넘지 않는다.

## 5. 정보 의미를 보완하는 일러스트 포인트

일러스트는 문장 옆의 장식이 아니라 `이 정보가 왜 중요한가`를 설명해야 한다.

### 5.1 유형과 배치

| 정보 | 시각 요소 | 전달할 의미 | 권장 크기 |
|---|---|---|---|
| 역사·계통 | 원산지 풍경 + 원래 역할 장면 | 현재 행동 경향이 생긴 맥락 | 데스크톱 240×180px, 모바일 100%×160px |
| 활동량 | 하루 시간대와 움직임 경로 선화 | 산책 거리만이 아니라 반복 활동과 정신 자극 필요 | 160×120px |
| 털 관리 | 피모 층 단면 + 빗질 도구 | 털의 구조와 관리 빈도 차이 | 120×96px |
| 주거환경 | 바닥·계단·소리·휴식 공간 도식 | 면적보다 소음, 동선, 휴식 환경이 중요함 | 160×120px |
| 크기 | 사람 또는 생활 가구와 중립 실루엣 | 실제 체감 크기 | 120×140px |
| 더위·추위 | 계절 장면 + 휴식 신호 | 기후 대응이 생활 관리로 연결됨 | 120×96px |

### 5.2 배치 규칙

- 한 화면 높이 안에 큰 일러스트는 1개만 둔다.
- 연속된 모든 문단에 아이콘을 붙이지 않는다. 핵심 전환 섹션마다 1개를 원칙으로 한다.
- 본문 옆 배치는 데스크톱 `본문 7 / 시각 5`, 모바일은 `시각 → 제목 → 요약 → 본문` 순으로 쌓는다.
- 작은 정보 아이콘은 24px, 설명 선화는 최소 96px 이상으로 구분한다.
- 시각 요소 아래에 1줄 캡션을 두고, 본문과 중복 설명하지 않는다.
- 실제 수치나 관계를 표현하는 도식은 장식 일러스트와 다른 중립적 선 스타일을 사용한다.
- 건강·주의 정보에는 캐릭터 표정으로 위험도를 표현하지 않는다.

### 5.3 접근성

- 정보가 이미지에만 존재하면 안 된다. 같은 의미를 제목·본문 또는 대체 텍스트로 제공한다.
- 장면 전체가 본문을 반복하면 빈 `alt`를 사용한다.
- 새로운 정보를 보충하면 80자 안의 설명형 `alt`를 작성한다.
- 텍스트가 포함된 일러스트 파일을 만들지 않는다. 라벨은 실제 HTML로 올린다.

## 6. 홈 ‘오늘의 강아지’ 수동 캐러셀

### 6.1 목적

검색 전에 낯선 견종을 발견하게 하되, 사용자의 읽기 속도를 방해하지 않는다. 캐러셀은 광고 배너가 아니라 한 견종의 이야기를 여는 편집 영역이다.

### 6.2 슬라이드 구성

한 슬라이드는 다음 정보만 포함한다.

- 통일된 히어로 일러스트 또는 승인 사진
- `오늘의 강아지 01/20`
- 견종명과 한 문장 정체성
- `처음 알게 될 점` 1개
- `이야기 열어보기` 버튼

예시:

```text
오늘의 강아지 01/20
그레이하운드
빠르게 달리지만, 집에서는 긴 휴식을 즐길 수 있어요.
[이야기 열어보기]
```

### 6.3 레이아웃

- 데스크톱: 이미지 58%, 카피 42%의 분리형 2열. 전체 최소 높이 440px.
- 모바일: 이미지 4:3 위, 카피 아래. 전체 높이를 고정하지 않는다.
- 이미지 위에 긴 문장을 겹치지 않는다.
- 다음 슬라이드 일부를 24~40px만 노출해 탐색 가능성을 암시할 수 있다. 본문 폭을 희생하면 노출하지 않는다.
- 슬라이드 수가 5개를 넘더라도 점을 모두 나열하지 않고 `현재/전체` 숫자를 사용한다.

### 6.4 조작과 상태

| 상태 | 동작·표현 |
|---|---|
| 기본 | 첫 슬라이드를 완성된 정보로 표시. 자동 이동 없음 |
| 이전·다음 | 명확한 텍스트 레이블 또는 아이콘+접근 가능한 이름 제공 |
| 첫 슬라이드 | 이전 버튼 비활성화. 무한 반복하지 않음 |
| 마지막 슬라이드 | 다음 버튼 비활성화 |
| 포커스 | 2px 이상 포커스 링, 배경과 3:1 이상 대비 |
| 전환 | 200~300ms 수평 이동. `prefers-reduced-motion`에서는 즉시 교체 |
| 로딩 | 이미지 비율을 유지하는 정적 플레이스홀더. 반짝임 반복 애니메이션 없음 |
| 이미지 오류 | 견종 실루엣과 텍스트는 유지하고 `이미지 준비 중` 표시 |

### 6.5 접근성 구현 조건

- 컨테이너에 `role="region"`, 의미 있는 `aria-label`, `aria-roledescription="carousel"`을 제공한다.
- 슬라이드는 `role="group"`, `aria-roledescription="slide"`, `aria-label="1 / 5"`를 제공한다.
- 현재 슬라이드 이외의 콘텐츠는 키보드 포커스 순서에서 제외한다.
- 사용자 조작 후 변경된 견종명만 `aria-live="polite"`로 알린다. 초기 로드에서는 읽지 않는다.
- 캐러셀 안에 포커스가 있을 때만 좌우 화살표 키를 지원한다.
- 모바일은 수평 스와이프와 버튼을 모두 제공한다.
- 자동재생, 자동재생 토글, 빠른 루프는 이번 범위에서 제외한다.

## 7. 생활조건 기반 탐색

### 7.1 위치와 진입

- 홈의 편집형 견종 섹션 뒤에 `내 생활 기준으로 살펴보기` 영역을 둔다.
- 전체 도감 페이지에서는 검색 아래 보조 탐색 방식으로 제공한다.
- 최초 진입에서 로그인이나 긴 설문을 요구하지 않는다.

### 7.2 조건 카드

| 축 | 초기 선택지 예시 | 카드가 설명할 내용 |
|---|---|---|
| 주거형태 | 원룸·소형 주택 / 공동주택 / 단독주택 | 면적보다 소음, 계단, 공용공간, 휴식 장소를 함께 확인 |
| 활동 가능 시간 | 30분 미만 / 30~60분 / 1~2시간 / 2시간 이상 | 신체 활동과 정신적 자극을 분리해 안내 |
| 체감 크기 | 소형 / 중형 / 대형 / 아직 모름 | 이동·병원·목욕·노령기 돌봄 부담 포함 |
| 계통·원래 역할 | 반려 / 목양 / 사냥·추적 / 썰매·작업 / 아직 모름 | 역사적 역할이 현재 행동 경향과 연결되는 이유 |

- 각 축은 1개 선택을 기본으로 하고 `아직 모름`을 정상 선택지로 제공한다.
- 선택 전에는 모든 견종을 숨기지 않는다. 편집형 도감은 계속 탐색할 수 있어야 한다.
- 카드 제목 19px/500, 한 줄 설명 14px/1.62, 선택지는 최소 높이 44px로 한다.
- 작은 아이콘은 조건 의미만 보조하고 `아파트=소형견` 같은 단정적 그림을 사용하지 않는다.

### 7.3 결과 구조

`추천 결과`라는 제목을 사용하지 않는다.

권장 정보 순서:

1. 현재 선택한 조건 요약
2. `먼저 비교해볼 견종` 3~6개
3. 각 견종을 보여준 이유
4. `주의 깊게 볼 특성`
5. 조건 수정과 전체 도감 이동

견종 결과 카드 구조:

```text
[전신 이미지 또는 실루엣]
재패니즈 스피츠
먼저 비교하는 이유
  선택한 체감 크기와 가깝고, 계통 탐색과 연결돼요.
주의 깊게 볼 점
  알림 짖음과 이중모 관리는 실제 생활에서 확인하세요.
[상세 보기] [비교 후보에 담기]
```

### 7.4 언어 원칙

사용:

- `현재 선택한 조건에서 먼저 비교해볼 견종`
- `이 조건과 연결되는 일반적 특성`
- `실제 개체와 생활환경에 따라 달라질 수 있어요`
- `입양 전에 직접 확인할 점`
- `조건을 바꾸어 다시 살펴보기`

금지:

- `당신에게 딱 맞는 견종`
- `아파트에 적합한 견종`
- `초보자에게 완벽한 견종`
- `궁합 92%`
- `입양 추천 / 비추천`
- `키우기 쉬움`

### 7.5 상태

| 상태 | 화면 |
|---|---|
| 미선택 | 조건 카드와 `모든 강아지 둘러보기` 제공 |
| 일부 선택 | 선택한 조건만 반영하고 정밀 결과처럼 표현하지 않음 |
| 복수 선택 완료 | 비교 후보와 주의 특성을 함께 제공 |
| 결과 없음 | 조건이 잘못됐다고 말하지 않고 범위를 넓힐 선택지 제안 |
| 초기 데이터 부족 | `현재 등록된 견종 안에서 살펴본 결과`라고 명시 |
| 조건 변경 | 결과를 즉시 갱신하되 스크롤 위치와 선택 상태 유지 |

필터 상태는 URL 쿼리에 반영해 새로고침·공유 후에도 유지하는 것을 권장한다. 개인정보가 아닌 생활조건만 포함하며 자유 입력 값은 URL에 저장하지 않는다.

## 8. 반응형 기준

- 기본 설계 폭: 360px 모바일, 736px 대화·태블릿, 1200px 데스크톱.
- 콘텐츠 최대 폭은 1200px, 읽기 본문은 640px를 유지한다.
- 736px 이하에서는 3열 정보를 2열 또는 1열로 줄이고 텍스트 크기를 임의로 축소하지 않는다.
- 480px 이하에서 비교 표는 가로 스크롤 표보다 항목별 2열 카드 구조를 우선한다.
- 터치 대상은 최소 44×44px, 인접 조작 간 간격은 최소 8px로 한다.

## 9. 데브 구현 체크리스트

### P0

- [ ] 모든 화면이 동일한 전역 폰트 패밀리를 사용한다.
- [ ] 비교 화면 `h1`이 `page-title` 토큰을 사용한다.
- [ ] 본문 기본 크기·행간·최대 폭을 적용한다.
- [ ] 본문에 opacity를 사용하지 않고 대비를 검사한다.
- [ ] 모바일 비교 구조를 별도로 확인한다.

### P1

- [ ] 일러스트 슬롯에 의미 유형과 대체 텍스트 계약을 둔다.
- [ ] 오늘의 강아지 캐러셀은 자동재생하지 않는다.
- [ ] 캐러셀의 키보드·스와이프·감소 모션 상태를 구현한다.
- [ ] 이미지가 없어도 텍스트와 플레이스홀더로 레이아웃이 유지된다.

### P2

- [ ] 생활조건 네 축에 `아직 모름` 상태가 있다.
- [ ] 결과가 추천 점수나 합격·불합격처럼 표현되지 않는다.
- [ ] 견종 카드에 비교 이유와 주의 특성이 함께 나온다.
- [ ] 초기 데이터 범위와 개체 차이 안내가 노출된다.
- [ ] URL로 공유 가능한 필터 상태를 검토한다.

## 10. 검수 질문

- 배경의 부드러움 때문에 본문이 흐려 보이지 않는가?
- 제목, 요약, 본문만 차례대로 읽어도 핵심 흐름을 이해할 수 있는가?
- 비교 화면이 승자 결정이 아니라 차이 이해로 보이는가?
- 일러스트를 제거하면 정보가 사라지는가? 그렇다면 같은 정보를 텍스트로 보완했는가?
- 캐러셀을 조작하지 않아도 첫 견종의 가치가 충분히 전달되는가?
- 생활조건 결과가 사용자의 선택을 대신 결정하는 것처럼 보이지 않는가?

## 11. 20종 확장과 카피 적용

- 초기 카탈로그는 20종을 기준으로 설계한다.
- 홈에서 20종을 한 번에 균일 그리드로 노출하지 않는다. 오늘의 강아지 캐러셀, 편집형 큐레이션, 생활조건 탐색으로 나누고 전체 도감에서 모두 확인하게 한다.
- 캐러셀 페이지 표시는 점 20개가 아니라 `현재/전체` 숫자를 사용한다.
- 카탈로그 카드는 견종명, 원산지·계통, 행동 또는 관리 항목 1개만 우선 노출한다.
- 카드와 히어로에 분위기만 있는 태그라인을 사용하지 않는다.
- 화면별 카피 구조, 금지 표현, 재패니즈 스피츠 개정안은 `docs/content-copy-guide.md`를 따른다.
