# Dog Atlas 제품 아이콘 제작 가이드

## 1. 목적

이 문서는 상세 페이지와 생활 정보 카드에 쓰는 작은 제품 아이콘을 일관되게 만들기 위한 기준이다. 사람이 직접 제작하거나 생성형 AI에 요청할 때 모두 같은 규칙을 사용한다.

핵심 목표는 다음과 같다.

> 견종을 그리는 것이 아니라, 여러 견종에서 반복되는 하나의 생활 개념을 가장 작은 형태로 설명한다.

370개 견종마다 새 그림을 만들지 않는다. 이미 같은 의미를 가진 아이콘이 있으면 반드시 재사용하고, 새로운 생활 개념이 생겼을 때만 아이콘을 추가한다.

## 2. 다른 시각 자산과의 구분

| 자산 | 역할 | 특징 |
|---|---|---|
| 제품 아이콘 | 휴식, 털 관리, 안전처럼 반복되는 생활 개념 전달 | 작고 단순한 2색 그래픽, 전체 견종에서 재사용 |
| 내비게이션 아이콘 | 메뉴 목적과 현재 위치 전달 | 단색 선형, 작은 크기에서 명확한 실루엣 |
| 견종 일러스트 | 견종 외형과 역사적 장면 전달 | 견종별 특징, 전신 비율, 배경과 서사 포함 |

제품 아이콘에 특정 견종의 얼굴·피모·체형을 넣지 않는다. 반대로 견종 외형을 설명해야 하는 곳에 범용 제품 아이콘을 대표 이미지처럼 사용하지 않는다.

## 3. 재사용 우선 규칙

새 아이콘을 만들기 전에 아래 순서로 판단한다.

1. `public/images/lifestyle-icons/`에 같은 의미의 아이콘이 있는지 찾는다.
2. 문구가 달라도 사용자가 받아들이는 행동이 같으면 기존 아이콘을 재사용한다.
3. 기존 아이콘에 작은 요소를 덧붙여 다른 뜻처럼 보이게 하지 않는다.
4. 정말 다른 행동이나 상태일 때만 새 `concept_id`를 만든다.
5. 견종명이나 페이지 경로가 아니라 의미를 파일명으로 사용한다.

예시:

| `concept_id` | 의미 | 대표 메타포 | 파일 |
|---|---|---|---|
| `rest` | 혼자 편안히 쉬기, 안정적인 휴식 | 쿠션 + 작은 달 | `rest.png` |
| `grooming` | 빗질, 털 엉킴 예방, 정기 관리 | 그루밍 브러시 + 작은 반짝임 | `grooming.png` |
| `safety` | 낙상 예방, 작은 체구 보호, 생활 경계 | 낮은 안전 게이트 + 확인 표시 | `safety.png` |
| `walk` | 가벼운 산책, 일상적인 바깥 활동 | 산책화 + 움직임 표시 | `walk.png` |
| `sofa-rest` | 낮 시간의 편안한 휴식 | 소파 + 견종 특징이 없는 작은 강아지 | `sofa-rest.png` |
| `hygiene` | 목욕, 샴푸, 위생 관리 | 샴푸 펌프 + 거품 | `hygiene.png` |
| `enrichment` | 문제 해결, 학습, 냄새 탐색 같은 정신적 자극 | 퍼즐 보드 + 뼈 모양 단서 | `enrichment.png` |
| `connection` | 사람과의 교감, 가까운 상호작용 | 펼친 손 + 작은 하트 | `connection.png` |
| `climate` | 더위·추위와 기온 변화에 맞춘 관리 | 온도계 + 중립적인 날씨 다이얼 | `climate.png` |
| `health-check` | 관절·호흡·체중 등 몸 상태 관찰 | 돋보기 + 발바닥 | `health-check.png` |
| `feeding` | 식사량, 급여와 체중 관리 | 사료 그릇 + 사료 알갱이 | `feeding.png` |
| `calm-alert` | 짖음·소리·알림 행동의 차분한 관리 | 종 + 부드러운 소리 파동 | `calm-alert.png` |

`혼자 쉬기`, `낮잠`, `안정적인 휴식`은 모두 `rest`를 쓸 수 있다. 말티즈용 휴식 아이콘, 푸들용 휴식 아이콘처럼 견종별 변형을 만들지 않는다.

## 4. 시각 규격

### 형태

- 하나의 아이콘은 하나의 핵심 개념만 전달한다.
- 중심 사물 하나와 보조 신호 하나까지만 사용한다.
- 중심 사물은 전체 시각 면적의 약 70~80%를 차지한다.
- 보조 신호는 달, 확인 표시, 반짝임처럼 의미를 보강하는 데만 쓴다.
- 모서리는 둥글고 친근하게 처리하되 유아용 캐릭터처럼 과장하지 않는다.
- 외곽선을 두껍게 두르는 방식보다 면과 최소한의 내부 구분으로 형태를 만든다.
- 40px에서도 중심 사물이 먼저 읽혀야 한다.

### 색상

- 색은 사이트 테마색으로 일괄 칠하지 않고 실제 물건의 대표 재질과 색을 따른다.
- 나무는 낮은 채도의 갈색, 금속은 은색·황동색, 천과 도자기는 따뜻한 중성색처럼 사용자가 바로 알아볼 수 있는 색을 우선한다.
- 보조 요소는 하늘색·코랄·골드처럼 중심 사물과 구분되는 색을 쓰되 채도와 광택을 절제한다.
- 한 아이콘은 보통 2~4개의 물체색 안에서 구성하고, 작은 명암 변화는 같은 재질의 입체감을 표현하는 데만 쓴다.
- 필요한 내부 여백은 흰색 또는 투명한 음영으로 처리한다.
- 색만으로 의미를 구분하지 않는다. 단색으로 보아도 실루엣이 읽혀야 한다.
- 부드러운 입체감은 허용하되 강한 광택, 과장된 투영 그림자, 발광 효과는 넣지 않는다.
- 같은 색 계열 안의 완만한 명도 변화는 사물의 둥근 형태를 구분하는 용도로만 사용한다.

### 크기와 여백

- 제작 캔버스는 정사각형으로 한다.
- 원본은 최소 1024×1024px로 제작한다.
- 사방에 캔버스의 12~16% 안전 여백을 둔다.
- 아이콘끼리 실제 픽셀 크기보다 눈에 보이는 크기와 무게를 맞춘다.
- 현재 카드 표시 크기는 모바일 60px, 데스크톱 68px이다.
- 작은 화면에서 흐려지는 미세 선, 작은 점, 촘촘한 패턴을 피한다.

### 배경과 파일

- 최종 파일은 투명 배경 PNG를 기본으로 한다.
- 카드색이나 종이색을 이미지 안에 포함하지 않는다.
- 투명 가장자리에 흰색·분홍색 등 제거 전 배경색 테두리가 남지 않아야 한다.
- 파일명은 `{concept_id}.png`로 통일한다.
- 기본 경로는 `public/images/lifestyle-icons/`이다.

## 5. 메타포 선택법

좋은 메타포는 문장을 그대로 그림으로 옮기지 않고, 가장 빨리 인식되는 사물 하나로 줄인다.

| 생활 문구 | 피해야 할 접근 | 권장 접근 |
|---|---|---|
| 혼자 편안히 쉬는 연습 | 침대에서 자는 특정 견종 전신 | 쿠션 + 작은 달 |
| 매일 이어지는 털 관리 | 장모견을 사람이 빗기는 장면 | 그루밍 브러시 + 반짝임 |
| 작은 몸을 지키는 환경 | 집, 강아지, 방패를 모두 넣은 장면 | 안전 게이트 + 확인 표시 |
| 사람과의 교감 | 사람과 강아지의 복잡한 전신 장면 | 손 + 작은 하트 |
| 활동량 | 달리는 특정 견종 | 운동화 또는 움직이는 발자국 |
| 관찰과 학습 | 견종 얼굴을 들여다보는 사람 | 눈 또는 돋보기 + 작은 발자국 |

메타포가 두 가지 뜻으로 읽힐 가능성이 크면 보조 신호를 하나만 추가한다. 사물 세 개 이상을 조합해야 이해되는 아이콘은 다시 단순화한다.

## 6. 생성형 AI용 기본 프롬프트

아래 프롬프트에서 대괄호 부분만 바꾼다. 특정 회사, 서비스, 디자이너, 아이콘 라이브러리 이름을 프롬프트에 넣지 않는다.

```text
Create one original reusable mobile UI product icon for [CONCEPT].

Primary object: [ONE CLEAR OBJECT].
Secondary cue: [ZERO OR ONE SMALL CUE].

Style: compact, friendly, polished consumer-product icon; simple rounded geometry;
soft two-tone filled shapes; minimal internal detail; immediately recognizable at 40px.

Palette: use restrained, realistic material colors for the object itself. For example,
use warm wood brown, charcoal bristles, brushed silver or brass, cream ceramic,
natural kibble brown, muted blue, or soft coral where those colors clarify the object.
Avoid a monochrome green treatment and keep saturation low enough to suit the ivory UI.
Keep the same optical weight and detail density as the existing Dog Atlas lifestyle icons.

Composition: one centered icon on a square canvas; the main object occupies 70–80% of
the visual area; 12–16% clear padding on every side.

Background: perfectly flat solid chroma-key background for later removal.

Constraints: no breed-specific dog anatomy, no human character, no text, no label,
no card, no border, no frame, no thick black outline, no dramatic cast shadow,
no photorealism, no watermark, and no imitation of an existing commercial icon.
```

강아지는 원칙적으로 중심 사물로 사용하지 않는다. 행동을 가장 빠르게 설명하는 경우에만, 사용자가 시안을 승인한 뒤 견종 특징이 없는 작은 보조 실루엣으로 제한해 사용할 수 있다.

한 번에 서로 다른 아이콘을 여러 개 생성하지 않는다. 아이콘별로 한 번씩 생성하고, 승인된 기존 아이콘 한 장을 스타일 참고 이미지로 함께 제공한다.

## 7. AI 작업 순서

1. 문구에서 반복 가능한 생활 개념을 한 단어로 정한다.
2. 기존 `concept_id`로 설명할 수 있는지 먼저 확인한다.
3. 중심 사물 하나와 보조 신호 최대 하나를 정한다.
4. 실제 카드 문맥에 세 아이콘을 나란히 합성한 시안을 먼저 보여준다.
5. 사용자가 방향을 승인하기 전에는 코드와 실제 자산을 교체하지 않는다.
6. 승인된 시안을 기준으로 아이콘을 각각 분리 생성한다.
7. 배경을 제거하고 투명 가장자리와 색 번짐을 확인한다.
8. 실제 표시 크기 40px, 60px, 68px에서 다시 확인한다.
9. 같은 행의 다른 아이콘과 눈에 보이는 크기·색 무게를 맞춘다.
10. 코드에 연결한 뒤 모바일과 데스크톱에서 정렬과 가로 넘침을 확인한다.

## 8. 금지사항과 독창성

- 특정 회사나 상용 아이콘 세트의 이름을 생성 프롬프트에 사용하지 않는다.
- 기존 아이콘의 윤곽, 비율, 내부 선을 그대로 따라 그리지 않는다.
- 검색한 아이콘 이미지를 편집하거나 색만 바꿔 프로젝트 자산으로 사용하지 않는다.
- 레퍼런스는 `작은 크기에서의 인지성`, `통일된 무게`, `단순한 메타포` 같은 원칙을 확인하는 용도로만 쓴다.
- 최종 결과는 Dog Atlas 색상, 여백, 메타포 규칙에 맞춘 새 구성이어야 한다.
- 생성 프롬프트와 최종 파일 경로를 작업 기록에 남긴다.

## 9. 접근성과 구현

- 아이콘 옆에 같은 의미의 문구가 있으면 `alt=""`와 `aria-hidden`을 사용한다.
- 아이콘만으로 동작하는 버튼이라면 모양 설명이 아니라 기능을 나타내는 접근성 이름을 제공한다.
- 정보 전달을 색상에만 의존하지 않는다.
- 이미지의 고유 `width`와 `height`를 지정해 레이아웃 이동을 막는다.
- 한 카드 그룹 안에서는 동일한 CSS 표시 크기와 `object-fit: contain`을 사용한다.
- 한 견종 상세의 `먼저 챙길 세 가지`와 `생활에 가볍게 더하기` 여섯 카드는 서로 다른 `concept_id`를 사용한다.
- 카드 제목과 설명의 핵심 단어를 함께 분석하고, 중복될 때는 남은 아이콘 중 의미 점수가 가장 높은 개념을 선택한다. 단순히 카드 순서에 고정된 아이콘을 넣지 않는다.
- `health-check`는 성향 펼치기 실행 요소의 돋보기 아이콘으로 예약해 같은 상세의 생활 카드에서 반복하지 않는다.
