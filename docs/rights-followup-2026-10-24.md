# 이미지·원고 권리 후속 점검

2026-10-24. 사용자 요청에 따라 로컬에서만 진행했다. 기존 보안 수정과 코드 정리를 유지하며 커밋·푸시·배포는 하지 않는다. 앞선 [보안·권리 점검](security-rights-review-2026-10-24.md)의 후속 기록이다.

> 아래 수치는 1차 점검 당시의 기록이다. 현재 목록과 최신 집계는 [2차 점검](rights-second-pass-2026-10-24.md)을 따른다.

## 이미지 제작 경위

사용자는 초기 v2/v3 카드·역사 그림을 어떻게 만들었는지 묻는 질문에 **“생성 AI로 새로 만든 그림만 사용했어”**라고 답했다. 해당 진술을 현재 v2/v3 파일 752개의 경로·SHA-256과 연결했다. 생성 서비스, 당시 요금제·약관, 입력 참고자료의 권리까지 확인했다는 의미로 확대하지 않는다.

| 확인 항목 | 개수 | 의미 |
| --- | ---: | --- |
| 공개 자산 전체 | 1,880 | 이미지 1,879장, GLB 1개 |
| Git 이력 연결·HEAD 바이트 동일 | 1,880 | 파일 추적 근거이며 소유권 증명이 아님 |
| 제작 기록 연결 | 905 | 파일 언급 또는 견종·장면 묶음 제작 문서와 코드 경로 연결 |
| 사용자 제작 확인 | 752 | 현재 v2/v3 파일 해시 기준 |
| 위 두 근거 중 하나 이상 있음 | 1,598 | 중복 59개를 제외한 수치 |
| 두 근거 모두 미확인 | 282 | 추가 기록을 찾아야 하며 침해 판정이 아님 |

이전의 파일명 검색으로는 묶음 제작 문서의 `{slug}`·장면 템플릿을 실제 파일에 연결하지 못했다. 이번에는 문서에 명시된 견종 범위와 대응 콘텐츠 모듈을 함께 확인했다. 단지 같은 커밋에 들어갔다는 이유로 제작 확인 처리하지 않았다. 오래된 그림을 참고 입력으로 사용했다는 기록만으로 그 원본의 권리를 승인하지도 않았다.

미확인 282개는 v4 218개, 카드 시안 41개, 생활 아이콘 12개, v6 4개, 카드 조작 아이콘 4개, UI 1개, v5 1개, 크기 아이콘 1개다. 이미지 파일은 삭제·교체하지 않았다.

파일명이 문서에 직접 등장하는 자산은 437개다. 이 숫자는 묶음 기록·제작자 확인을 포함하는 1,598개와 다른 기준이다. 모든 자산의 `permissionStatus`는 목록만으로 승인되지 않았다는 상태를 유지한다.

## 원고 검토와 수정

비테스트 소스 145파일을 검사해 92파일에서 한국어 텍스트 단위 11,106개를 수집했다. 20자 이상 문자열·JSX·템플릿 조각의 중복 제거 수치이며, 완성 문장 수나 전체 외부 원문 대조 수가 아니다. 여러 연대, 역사 인물·교배·복원 서술, 긴 문장을 검토 후보로 추렸다. 별도로 상세 역사 도입부 79개를 읽어 우선 대조 대상을 골랐다.

이번 추가 수정은 **36종의 51개 문단·소개문**이다. 아키타·퍼그·카발리에·야쿠티안 라이카의 내부 역사 원고부터 표준 상세의 도입부·역사 본문까지 확인했다. 공식 자료의 사건 선택과 배열을 가깝게 따라가는 부분은 단순한 어휘 치환 대신, 필요한 원산지·역할·형성 사실을 추리고 생활 관찰의 맥락으로 다시 구성했다. 출처에서 확인하지 못한 상세 일화는 확대하지 않았다. 견종의 과거 역할을 현재 개체에게 요구할 행동이나 성격 보장으로 제시하지 않는다.

첫 18곳 수정 이후 남은 자동 후보 44개도 수동 확인했다. 그중 33개를 추가 수정하고, 짧은 사실 설명·편집 삽화 대체 텍스트 11개는 근거와 유지 이유를 기록했다. 피카르 영문 표준의 `www` 주소는 응답하지 않아 같은 FCI의 기본 도메인 PDF로 대조를 마쳤다. 최종 자동 후보 미처리 수는 0이다. 이는 **이번 선별 규칙의 후보 처리가 끝났다는 뜻이며, 전체 11,106개 표현의 권리 확인 완료를 뜻하지 않는다.**

원고의 출처 대조는 FCI 견종 표준, UKC 핏불 표준, AKC 도고 아르헨티노·보스턴 역사 자료 등 1차 자료를 사용했다. 각 수정의 원본/수정 해시·파일·필드·직접 출처 URL은 아래 기록에 있다. 원문 기사나 표준 본문을 통째로 저장하지 않았다.

- [유지한 11곳의 이유·출처](audits/editorial-manual-triage.json)
- [전체 텍스트 단위 검사 목록과 범위](audits/editorial-screening.json)
- [자동 규칙의 미처리 후보](audits/editorial-review-queue.json)
- [376종의 출처·부분 검수 상태](audits/content-rights-inventory.json)

테스트 중 특정 연도(토르냐크의 1067년)나 단어(보스턴의 ‘투견’)를 반드시 넣도록 고정한 두 검사를 현재 원고의 사실 범위에 맞췄다. 각각 가축·농장 보호 역할, 불도그·테리어 계통과 보스턴의 형성 지역·반려 역할을 확인한다. 출처·이미지·제작 상태·문장 길이 검사와 기존 테스트 수는 유지했다.

## 재현과 남은 확인

`pnpm audit:rights`는 자산 목록·제작 근거·미확인 목록·견종 출처를 재생성한다. `pnpm audit:editorial`은 텍스트를 다시 수집하고 수동 검수 해시와 대조한다. 검수한 텍스트가 변경되거나 사라지면 오류로 알려 기록이 현재 코드와 어긋나는 일을 막는다. 새로운 표현을 자동으로 승인하거나 고치지 않는다.

남아 있는 확인은 제작 근거가 부족한 282개 자산의 생성/내보내기 기록, 생성 서비스의 해당 시점 사용 조건과 입력 참고자료, 이번 수동 대조 범위 밖 원고의 개별 표현이다. 소스 링크·제작자 진술·자동 검사만으로 상업 이용이나 무침해를 일괄 보증하지 않는다. 전문가 검수 상태를 새로 부여하지 않았다.

## 로컬 검증

- lint·typecheck·65파일/1,717테스트·387페이지 프로덕션 빌드 통과. `git diff --check` 통과(기존 LF/CRLF 안내는 남음).
- 두 감사 명령 정상 실행. 검수한 51곳과 유지한 11곳의 해시가 현재 소스와 일치한다. 공개 자산 1,880개의 바이트는 Git HEAD와 동일하다.
- 로컬 프로덕션 Chrome에서 수정 대상 36종의 PC1440px 화면, 대표 6종의 모바일390·320px 화면 등 총 48화면을 확인했다. HTTP 200, 가로 넘침·JavaScript 오류 없음. 현재 공개 표준 상세에는 수정 문구가 표시되고, 내부 원고/제작 보류 상세는 기존 노출 정책을 유지한다.
- 불테리어 PC·모바일에서 이미지 디코드와 실제 표시, PC 탭 3단계·모바일 다음 단계 이동을 확인했다. 급히 캡처한 이미지 로딩 중 화면은 최종 시각 검수로 사용하지 않았다. 로그·스크린샷은 Git에서 제외된 `tmp/rights-*`에 있다.
- 최신 빌드를 `http://127.0.0.1:3000/`에서 실행 중이다. 실기기 iOS는 이번에 재검증하지 않았다. 커밋·푸시·배포 없음.
