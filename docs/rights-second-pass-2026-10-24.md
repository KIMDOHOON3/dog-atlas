# 이미지·원고 2차 점검 — 2026-10-24

사용자가 요청한 로컬 후속 점검이다. 커밋·푸시·배포는 하지 않는다. 이전 집계는 [1차 후속 보고서](rights-followup-2026-10-24.md)에 보존한다.

## README 방향 수정

기존 README는 개발자가 실행·수정·검증하는 데 필요한 인수인계 문서에 가까웠다. 사용자가 “프로젝트 소개보다 개발 설명이 너무 많아”라고 정정했다.

루트 README는 서비스 목적 → 수채화 카드와 견종 발견 → 돌봄과 맞이 준비 → 함께 갈 곳 → 제품 원칙 → 짧은 실행법 순서로 바꿨다. 환경변수, 라우트 표, 폴더 구조, 전체 검증 명령과 배포 설명은 [개발 안내](development.md)로 옮겼다. 기존 제품 목적과 기능 범위는 바꾸지 않았다.

## 남은 이미지 282장

현재 파일 해시, 직접 기록, 관련 생성 목록, Git의 과거 문서와 같은 변경에 포함된 자산 범위를 확인했다. 원본 이미지 자체는 삭제하거나 교체하지 않았다. 다음 숫자는 출처 기록 검토 결과이며 시각적 유사도 검사나 이용 허락의 확정이 아니다.

| 근거 수준 | 수 | 확인한 내용 |
| --- | ---: | --- |
| 생성 결과 목록 | 35 | 프롬프트·생성 결과 원본 경로·제품 출력 경로가 연결된 manifest |
| 생성 도구/생성 작업 기록 | 83 | 내장 이미지 생성 언급, 견종·장면·크기별 출력 범위와 경로 대응 |
| 새 장면 제작·추가 기록 | 145 | 해당 커밋의 문서에서 신규 장면 범위와 자산 추가를 확인. 생성 도구나 최초 입력 자료까지 입증하지는 못함 |
| 제작자 확인 | 19 | 문서 검색만으로는 최초 제작을 확인하지 못했으나, 사용자가 이번 질문에 모두 생성 AI로 새로 제작했다고 확인 |
| 합계 | 282 | 모두 해시와 검토 결과를 기록 |

1차 감사가 `manifest` 파일명과 축약된 `{front,back}`, `{toy,...}` 출력 경로, 오래된 상태 문서의 제작 기록을 놓쳤다. 명시된 출력과 장면 범위를 확인한 263장을 추가 연결했다. 단순히 같은 커밋에 있었다는 이유만으로 생성 기록으로 분류하지 않는다.

전체 공개 자산 1,880개 중 제작 기록이 연결된 것은 1,168개, 사용자 진술은 기존 v2/v3 752개와 이번 19개를 합쳐 771개다. 중복 59개를 제외하면 1,880개 모두 제작 관련 기록 또는 제작자 진술과 연결된다. 1,880개 모두 기존 HEAD 파일과 동일하다.

### 사용자 확인으로 보완한 19장

- 생활 아이콘 12장: `public/images/lifestyle-icons/`. 제작 지침과 재색칠 기록은 있지만 지침이 실행됐다는 증거와 원본 생성 결과를 구분한다.
- 카드 조작 아이콘 4장: `public/images/card-controls/`. 교체·같은 원본의 변형 기록이 있어도 원본의 출처가 별도로 필요하다.
- `public/images/size-icons/approved-silhouettes.webp`: 사용자 시안 승인과 원본 보관 기록만으로 권리를 판단하지 않는다.
- `public/illustrations/ui/action-icons/readiness-checklist-3d.png`: 화면 적용 기록 외 최초 제작 근거가 부족하다.
- `public/illustrations/v4/german-spitz-feature-cooperative-play.webp`: 현대 생활 삽화 추가 기록은 있으나 생성·원본 출처는 미확인이다.

이 19장을 특정해 질문했고 사용자는 **“전부 생성 AI로 새로 만들었어”**라고 답했다. [별도 진술 기록](audits/image-origin-attestation-second-pass.json)에 질문·답변·현재 해시를 보존했다. 기존 v2/v3 진술을 확대 적용한 것이 아니다. 생성 영수증을 확보한 것으로 바꾸지 않으며 당시 서비스 이용 조건과 모든 입력 참고자료의 권리는 미확인 상태를 유지한다.

- `production-record-linked-permission-pending`은 제작 관련 기록의 연결 상태이며 법률적 허락 상태가 아니다. `permissionStatus`는 미확인으로 유지한다.

## 추가 원고 검토

7종의 선택한 소개/역할 문단과 공개 상세의 첫 이야기 본문 16곳을 대조했다. 12곳을 다시 쓰고 짧은 사실·편집 문맥 4곳은 유지했다. 견종별 전체 원고나 건강·돌봄 조언 전체를 검수한 결과는 아니다.

그레이하운드·요크셔 테리어 PDF는 조회 시 2026-10-06판이었다. 이번 수정은 제한된 기원·용도 사실과 독립적으로 작성한 독자 안내를 사용한다. 공식 표준의 문장 배열을 그대로 번역하지 않으며, 이를 침해 여부의 법률적 결론으로 표시하지 않는다.

[이번 16곳](audits/editorial-second-pass.json), [수정 누적 기록](audits/editorial-rights-changes.json), [유지 판단](audits/editorial-manual-triage.json)에 출처와 문장 해시를 기록했다. 후속 감사 기준 누적 수정은 41종 63개 텍스트 단위, 유지 기록은 15개다. 이전 검토 대상과 이번 7종이 일부 겹치므로 견종 수를 단순 합산하지 않는다.

전체 선별은 145개 비테스트 소스 파일, 한국어 문자열·JSX·템플릿 조각 11,107개를 대상으로 한다. 자동 후보 0은 모든 원고의 대조 완료를 뜻하지 않는다. 나머지 문단, 조립된 문장, 건강·행동 정보의 전문가 검수와 외부 원문 전체 유사도 확인은 남아 있다.

## 검증

- lint·typecheck 통과. 마지막 감사 스크립트 수정 후 해당 스크립트 ESLint도 통과.
- 전체 65파일·1,717테스트 통과. 최초 실행의 프렌치 불도그 문구 검사 1건은 “반려견으로 정립”이라는 기존 의미를 유지하도록 문장을 다듬고 전체 재실행해 통과했다. 테스트를 약화하거나 삭제하지 않았다.
- Next.js 프로덕션 빌드: 387페이지 생성 성공.
- 자산·원고 감사 및 Git diff 공백 검사 통과. 공개 자산 1,880개의 HEAD 동일성 유지.
- 홈+7종 상세, PC1440/모바일390·320px의 24화면에서 HTTP 200·가로 넘침·JavaScript 오류 없음. 공개 수정 문장이 나오는 요크셔/프렌치 불도그의 본문·이미지 로드를 확인했다. 모바일 프렌치 불도그는 이미지 디코딩 직후 캡처에서 그림이 비어 보여 후속 렌더와 표시를 추가 확인했다.
- 나머지 원본 소개 수정은 현재 공개 표준 상세와 별도로 보존된 데이터다. 화면에 모든 수정 문장이 표시된다고 주장하지 않는다. 기존 제작 보류·전문가 미검수 상태 유지.
- 실기기 iOS는 미검증. 최신 로컬 서버는 http://127.0.0.1:3000/ 이다.
- 로컬 검증 기록은 Git에서 제외된 `tmp/rights-second-*`에 보관한다. 커밋·푸시·배포 없음.
