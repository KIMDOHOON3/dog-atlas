# Dog Atlas 크기 데이터 통합 감사

> 감사일: 2026-09-01
> 범위: 현재 카탈로그 376종
> 상태: Dog Atlas 크기 분류 시스템 v1 데이터·UI 연결·회귀 검증 완료
> 아래 `2단계 내부 정합성 재검수`가 현재 수치이며, 1단계 수치는 변화 비교를 위해 보존한다.

## 확정 기준

- 체고: 초소형 `<25`, 소형 `<40`, 중형 `<55`, 대형 `<70`, 초대형 `>=70cm`
- 체중: 초소형 `<4`, 소형 `<10`, 중형 `<25`, 대형 `<50`, 초대형 `>=50kg`
- 완전 범위의 대표값은 `(최소값 + 최대값) / 2`이다.
- 체고와 체중 등급 중 높은 등급을 최종 등급으로 사용한다.
- 두 등급이 2단계 이상 차이나면 자동 확정하지 않는다.
- `이상`, `이하`, `최소`, 한쪽 수치 누락은 대표값을 만들지 않는다.
- 공식 크기 유형은 유형별로 계산하며 견종 전체 범위를 합치지 않는다.

## 통합 방법과 한계

`identity.size`, `breedFactOverrides`, 활성 표준 상세의 `heroSizeDetails`·`sizeVarieties`, 푸들 전용 상세를 slug별로 모았다. 각 후보에는 원래 위치, 원문, 견종 원고에 연결된 출처 URL을 보존한다. 성별별 완전 범위나 명시된 두 대표값은 전체 성견 범위로 합치지만, 최소·최대 기준은 완전 범위로 바꾸지 않는다.

같은 차원의 완전한 후보값이 다르면 더 넓게 합치거나 평균내지 않고 `conflict`로 남겼다. 이번 감사는 프로젝트 내부에 이미 연결된 근거를 정리한 것으로, 43개 충돌값과 부족값을 외부 표준에서 새로 확정한 작업은 아니다.

| 상태 | 견종 수 | 의미 |
| --- | ---: | --- |

### 전환 판단

- A — 내부 자료만으로 바로 confirmed: 위 29종.
- B — 내부 값의 의미 확인은 됐으나 완전 범위가 아닌 5종: 와이어 폭스 테리어, 케리 블루 테리어, 티베탄 테리어, 실리햄 테리어, 보어보엘. 보어보엘은 서로 다른 등록기관의 최소·이상 체고와 일반 성견 범위를 하나로 합치지 않았다.
- C — 외부 원자료에서 부족 수치 또는 충돌 의미를 확인해야 하는 단일 프로필: 94종. 이는 `provisional 86 + conflict 7 + missing 1`이며 B의 5종을 포함한다.
- D — 단일 크기로 확정하지 않는 항목: varieties 8종과 variable-parentage 2종. 골든두들과 말티푸는 단일 등급용 외부 범위를 찾는 대상이 아니다.

### 불개

## 5단계 서비스 연결 결과

최종 상태 합계는 `312 + 53 + 8 + 2 + 0 + 1 = 376`으로 검증했다. 빠져 보였던 2종은 골든두들과 말티푸의 `variable-parentage`이며, 불개는 체중만 부족한 provisional이 아니라 공인 표준과 체고·체중 수치가 모두 없는 `missing` 1종으로 유지한다.

서비스 필터는 confirmed 단일 프로필과 독립 계산이 완료된 variety만 사용한다. 실제 노출 수는 초소형 4, 소형 48, 중형 114, 대형 126, 초대형 27이다. 합계가 319가 아닌 것은 저먼 스피츠·포르투기즈 포뎅고·페루비안 헤어리스 도그가 둘 이상의 필터에 걸릴 수 있기 때문이며, 각 결과 안에서 slug가 중복되지는 않는다. 원본 수치와 계산 등급은 유지하면서 그레이하운드·폴리시 그레이하운드는 서비스 표시·필터만 대형으로, 블랙 러시안 테리어·라페이루 두 알렌테주·마렘마 앤 아브루초 셰퍼드·마케도니안 셰퍼드 도그 카라만은 초대형으로 분리한다.

provisional 53종, 골든두들·말티푸, 불개는 전체 도감과 이름 검색에는 남지만 크기 필터에는 들어가지 않는다. `identity.size`는 감사 입력으로 보존하되 발견 카드, 상세, 홈 큐레이션, 초보자 가이드의 분류 기준으로 사용하지 않는다.

## v1 완료 판정과 후속 backlog

Dog Atlas 크기 분류 시스템 v1은 데이터 정규화, 공식 자료 보완, 5단계 UI 연결과 회귀 검증을 마친 완료 상태다. 최종 집계는 `confirmed 312`, `provisional 53`, `varieties 8`, `variable-parentage 2`, `conflict 0`, `missing 1`, 합계 376종이다. 최종 기준은 체고 `<25 / 25~<40 / 40~<55 / 55~<70 / ≥70cm`, 체중 `<4 / 4~<10 / 10~<25 / 25~<50 / ≥50kg`이며 완전 범위 중앙값과 두 차원 중 높은 등급 원칙을 사용한다.
