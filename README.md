# Dog Atlas · 견종도감

**함께하기 전에 알아보고, 함께한 뒤에는 끝까지 책임져 주세요.**

견종도감은 강아지의 모습에 대한 호기심에서 시작해, 그 견종이 살아온 배경과 함께 사는 일상을 알아가는 웹 서비스입니다. 예쁜 외형뿐 아니라 행동 경향과 돌봄에 필요한 시간·환경을 살펴보고, 반려견과 함께 갈 장소도 찾을 수 있습니다.

## 그림에서 시작하는 견종 이야기

수채화로 그린 양면 카드를 넘기며 다양한 견종을 만납니다. 카드 앞면에서는 견종의 모습과 배경을, 뒷면에서는 사람 곁의 모습과 기본 정보를 살펴봅니다. 현재 메인에는 네 크기 그룹의 49종 카드가 있습니다.

더 궁금한 견종은 **견종 발견**에서 검색하거나 생활 조건별로 찾아볼 수 있습니다. 전체 376종의 목록에서 상세로 이어지며, 역사와 역할이 오늘날의 행동 경향과 어떻게 연결되는지 읽고 일상에서 확인할 점을 살펴봅니다.

## 외형 다음에는 함께 사는 생활

산책과 놀이, 혼자 쉬는 시간, 털 관리처럼 매일 마주할 일들을 구체적으로 생각하도록 돕습니다. **맞이 준비 가이드**에서는 자신의 생활과 준비할 환경을 차근차근 확인할 수 있습니다.

견종도감은 특정 견종을 정답으로 추천하지 않습니다. 견종의 특성은 일반적인 경향이며, 실제 행동과 필요는 개체의 건강·경험·환경에 따라 달라집니다. 원고는 편집과 검토를 이어가는 중이며, 모든 상세가 같은 완성도이거나 수의사·행동 전문가 검수를 마친 상태는 아닙니다.

## 반려견과 함께 갈 곳

페이지 아래 작은 3D 운동장에서 공과 장난감을 던져 보고, **함께 갈 곳** 안내판을 통해 반려동물 동반 장소를 찾습니다.

사진 없이도 방문을 판단할 수 있도록 공공데이터가 제공하는 주소, 연락처, 동반 조건과 시설 정보를 보여줍니다. 지역이나 내 주변으로 찾고, 전화하거나 카카오맵 길찾기로 이동할 수 있습니다. 메뉴·규모·운영시간 등은 제공된 경우에만 표시하며, 방문 전 최신 동반 조건은 해당 장소에 확인해야 합니다.

## 프로젝트가 지키는 방향

- 따뜻하고 호기심을 불러일으키는 표현으로 시작하되, 정보는 신중하게 전달합니다.
- 견종의 매력과 함께 실제 돌봄의 부담도 보여 줍니다.
- 모바일에서도 편하게 읽고 조작할 수 있게 만들며, 애니메이션 없이도 주요 정보를 이용할 수 있게 합니다.
- 자료의 출처와 검토 상태를 구분하고, 사용자가 스스로 판단할 근거를 제공합니다.

## 기술과 프로젝트 구성

Next.js·React·TypeScript로 만들고, CSS Modules로 화면을 구성합니다. 견종 원고는 로컬 데이터로 관리하며 Zod로 형식을 검증합니다. 운동장은 Three.js를 사용하고, 장소 정보는 서버에서 공공데이터 API로 가져옵니다.

```text
src/app/         페이지와 API 경로
src/features/    카드·견종 탐색·상세·준비 가이드·장소·운동장
src/components/  공통 UI
src/content/     견종 원고와 데이터
src/hooks/       공통 훅
src/lib/         공통 로직과 유틸리티
public/          웹에서 사용하는 이미지와 3D 자산
design/          디자인 제작 원본과 기록
scripts/         검증·자산 관리 도구
docs/            제품·설계·출처 문서
```

기능별로 컴포넌트·스타일·테스트를 함께 관리합니다. 실행과 검증 방법은 [개발 안내](docs/development.md), 상세 배치 규칙은 [코드 구조](docs/code-structure.md)에 정리했습니다.

더 자세한 목적은 [제품 소개](docs/product-brief.md), 현재 구현·검증 상태는 [프로젝트 상태](docs/project-status.md), 분야별 기록은 [문서 안내](docs/README.md)를 참고하세요.
