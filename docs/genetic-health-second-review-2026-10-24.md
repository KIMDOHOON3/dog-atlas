## 근거와 편집 원칙

- 공식 자료 22개를 대조했다(새 URL 21개, 이전 차수에서도 사용한 AKC 소형견 검사 페이지 1개). AKC가 제공하는 견종 협회 건강 성명 19개, AKC 퍼그 검사 요약, UC Davis의 PDE 설명, OFA의 RFGS 설명을 확인했다. 이전 공통 OFA CHIC·UC Davis 유전 검사 해석 자료도 유지했다.
- 각 문장의 이전·수정 텍스트, 해시, 근거 키, 수정 이유와 파일은 [2차 감사 기록](audits/genetic-health-second-review-2026-10-24.json)에 있다. 각 출처에는 제목·기관·URL·확인일이 있으며, 화면의 ‘정보 출처와 편집 안내’에서도 확인할 수 있다.
- 시츄는 [ASTC 2024년 성명](https://s3.amazonaws.com/cdn-origin-etr.akc.org/wp-content/uploads/2024/07/05091018/Health-Statement-American-Shih-Tzu-Club.pdf)을 직접 확인해 협회의 의무와 CHIC 요건을 구분했다. ‘권장 검사 없음’을 질환이 없다는 뜻으로 바꾸지 않았다.
- 퍼그는 [UC Davis PDE 설명](https://vgl.ucdavis.edu/test/pde-susceptibility)에 따라 유전적 감수성 결과를 확진으로 표현하지 않았다. [OFA 호흡 평가](https://ofa.org/diseases/rfgs/)는 별개의 임상 평가로 연결했다.
- PDF 업로드 경로나 파일명이 본문의 승인일과 다를 때 본문 날짜를 따른다. 오래된 성명을 현재의 완전한 CHIC 요건이라고 단정하지 않는다. 국내 모든 반려견의 의무 검사·고정 주기로 바꾸지 않는다.
- `german-spitz` 주소는 대표 이름이 포메라니안인 기존 구조를 유지하며, 검사 설명의 적용 범위를 포메라니안으로 한정했다.
- 기존 공개/보류 상태, 본문·돌봄 문구·이미지는 유지했다. 상세의 기존 ‘유전 질환과 검사 기록’ 영역이 새 20종에도 연결된다.

## 검증

- `pnpm lint`, `pnpm typecheck`, 전체 65파일·1,717테스트, 387페이지 프로덕션 빌드 통과.
- `pnpm audit:rights`, `pnpm audit:editorial` 통과. 두 차수의 원고·해시·출처 연결 및 공통 안내를 검증했고 공개 자산 1,880개는 기존 HEAD와 동일하다.
- 수정 전 조립 데이터와 비교해 건강 안내 20곳 외의 텍스트 변경이 없고 공개 목록도 동일함을 확인했다.
- 로컬 프로덕션 Chrome에서 홈·새 20종·기존 푸들·미점검 재패니즈 스피츠를 PC 1440px, 모바일 폭 390/320px로 확인했다(69화면). HTTP 200, 실제 수정 원고·공통 안내·출처 링크, 키보드 펼치기/접기, 미점검 페이지의 잘못된 표시가 없음을 확인했다. 가로 넘침·JavaScript 오류 없음.
- 퍼그·시츄·허스키의 PC/320px 캡처를 생성하고 퍼그 모바일·시츄 PC의 글자와 배치를 시각 확인했다. 실기기 iOS는 미검증이다.
- 로그와 캡처는 Git 제외 경로 `tmp/genetic-second-*`에 있다. 최신 로컬 확인 주소: http://127.0.0.1:3002/breeds/pug.

## 남은 범위

[견종별 점검 목록](audits/genetic-health-review-queue.json)은 전체 376종을 포함한다. 32종은 선택 문장에 대한 근거 점검 이력이 있고, 나머지 344종은 이 유전 질환·검사 점검의 대상이 아직 아니다. 점검한 32종도 전체 건강 본문·모든 유전 질환·모든 검사 패널의 검토 완료를 의미하지 않는다. 일부 견종의 검사 근거가 부족하면 다른 견종의 목록을 대입하지 않고 보류한다.

`pnpm audit:rights`는 두 차수의 문구·해시·출처 연결과 공통 안내를 확인하고 점검 목록을 다시 생성한다. 이전 감사 기록은 보존한다.
