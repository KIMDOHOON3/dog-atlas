# 200종 확장 배치 05 — 이미지 제작 기록

## 범위와 방식

- 대상: 해리어, 잉글리시 폭스하운드, 페티 바셋 그리폰 방데앙, 핀니시 하운드, 알파인 닥스브라케, 바바리안 마운틴 센트 하운드, 저먼 와이어헤어드 포인터, 스몰 문스터랜더, 와이어헤어드 포인팅 그리폰 코르탈스, 잉글리시 포인터.
- Codex ImageGen 신규 생성으로 견종마다 역사·현재 활동·활동 뒤 휴식·생활 현실 2장, 합계 50장을 만들었다.
- 공통 조건은 4:3 가로형, 성견 한 마리, 전신과 환경이 함께 읽히는 단일 순간, 크림 종이 질감의 절제된 수채화·색연필 표현이다. 확대 컷, 같은 개 반복, 순차 콜라주, 글자·로고·워터마크는 금지했다.
- 서비스 자산은 1200×900, quality 84 WebP로 `public/illustrations/v3`와 `v4`에 저장한다.

## 장면 구분

| 견종 | 다섯 장면 |
| --- | --- |
| 해리어 | 영국의 도보 토끼 추적, 긴 리드 냄새 길, 도구 수납·휴식, 이중 경계 동선, 늘어진 귀·발 점검 |
| 잉글리시 폭스하운드 | 영국 기마 무리 사냥, 넓은 냄새 지점, 장거리 뒤 평면 휴식, 현관 이중 멈춤, 짧은 털·발 점검 |
| 페티 바셋 그리폰 방데앙 | 방데 덤불의 토끼 수색, 낮은 냄새 통로, 도구 수납·낮은 침대, 낮은 틈 차단, 거친 털·긴 귀 관리 |
| 핀니시 하운드 | 핀란드 숲의 독립 추적·울음, 숲길 갈림점, 장비 정리·휴식, 조용한 귀가, 날씨별 귀·발 관리 |
| 알파인 닥스브라케 | 알프스의 다친 사슴 추적, 낮은 경사 냄새 길, 평면 휴식, 점프 대신 경사판, 배 털·발 관리 |
| 바바리안 마운틴 센트 하운드 | 바이에른 산악의 오래된 흔적 추적, 시간 둔 냄새 구분, 추적 장비 수납, 긴 리드 동선 계획, 귀·발 점검 |
| 저먼 와이어헤어드 포인터 | 들·숲·물의 다목적 포인팅, 찾기·멈춤·회수, 더미 건조·휴식, 안전한 넓은 공간, 수염·거친 털·발 관리 |
| 스몰 문스터랜더 | 문스터의 포인팅·회수, 찾기·표시·운반, 장식털 건조·휴식, 여러 과제 조합, 귀·장식털 관리 |
| 와이어헤어드 포인팅 그리폰 코르탈스 | 코르탈스의 계통 정립, 얕은 물 회수, 더미·수염 건조, 야생동물과 거리, 수염·거친 털·발 관리 |
| 잉글리시 포인터 | 넓은 들의 빠른 수색·포인팅, 달리기 뒤 멈춤, 그늘 평면 휴식, 이중문 운동장, 얇은 털·발 점검 |

역사 장면은 사냥감을 직접 대면하거나 공격하는 모습 대신 발자국, 지형, 작업 자세만 보여준다. 이미지는 편집 설명용이며 수의학·행동학·컨포메이션 전문가 검수를 뜻하지 않는다.
