# 견종별 유전 질환·검사 기록 점검

2026-10-24. 로컬 수정·검증이며 커밋·푸시·배포는 하지 않았다.

## 범위

전체 견종 데이터와 표준 상세에서 유전·가족력·검사·질환 관련 표현을 검색한 뒤 12종의 선택 원고를 대조했다. 기존 원고 17곳(건강 편집 안내 12곳, 돌봄 안내 4곳, 말티푸 공개 표준 상세 1곳)을 수정하고 공통 검사 해석 안내 3개를 추가했다. 모든 견종의 유전 질환이나 검사 목록을 완성한 것은 아니다.

대상은 푸들, 말티즈, 말티푸, 골든두들, 골든 리트리버, 래브라도 리트리버, 캐벌리어 킹 찰스 스패니얼, 도베르만, 바센지, 닥스훈트, 오스트레일리안 셰퍼드, 셔틀랜드 시프독이다. 질환의 발생률·유전 확률·검사 가격·치료법·약물 용량은 추가하지 않았다.

## 자료 선택과 한계

- PCA 홈페이지의 예전 목록과 날짜가 명시된 2024년 성명서 사이에 스탠더드 푸들 검사 구성이 달랐다. 공식 성명서를 사용하고 과거 홈페이지 목록을 혼합하지 않았다. 미국 분류를 FCI의 모든 크기 구분에 그대로 적용하지 않는다.
- AMA 웹페이지는 접근되지 않아 AKC가 제공하는 협회 성명서와 현재 AKC 목록을 함께 확인했다. 2018년 성명서를 최신 작성 문서로 표시하지 않았다.
- GANA의 기존 주소는 새 기준 페이지로 연결됐다. 현재 적용 조건을 함께 읽었으며 모든 등급의 항목을 하나의 의무 목록으로 옮기지 않았다.
- 해외 협회의 번식 선별 기준을 국내 반려견의 법적 의무나 동일한 정기 검진 일정으로 바꾸지 않았다. 기존 자료의 홍보성 건강 보장 문구도 옮기지 않았다.

16개 출처의 URL·확인일, 수정 전 문장·해시와 변경 이유는 [기계 검증 기록](audits/genetic-health-review-2026-10-24.json)에 있다. 이는 선택한 주장의 대조 기록이며 전문의가 원고를 검수했다는 뜻은 아니다.

## 코드와 화면

- 기존 견종 데이터의 건강 원고를 직접 수정했다. 공통 문장을 공유하던 두 목양견만 개별 건강 문구를 가질 수 있도록 기존 배치 데이터에 선택 필드를 추가했다.
- 12종 상세 하단에 접힌 ‘유전 질환과 검사 기록’을 추가했다. 건강 안내 12곳과 공통 해석 안내를 실제로 읽을 수 있다. 기존 표준 상세의 카드·그림·체크리스트는 보존했다.
- ‘정보 출처와 편집 안내’에서 근거를 확인할 수 있다. 별도 출처 배열을 쓰던 푸들 상세에도 이번 자료가 빠지지 않게 연결했다. 재확인한 기존 URL의 확인일은 갱신하고 원래 출처 항목은 보존했다.
- 이전 돌봄 점검의 캐벌리어 편집 상태 안내 1곳은 이번 설명으로 대체했다. 예전 기록을 삭제하지 않고 이전 해시와 새 기록의 연결을 검사한다. 이전 점검 36곳 중 현재 활성 문구는 35곳이고, 당시 유지 8곳 중 1곳이 이번에 대체됐다.
- 작성된 표준 상세에는 기존 달마시안 항목이 두 번 존재한다(270개 항목, 269종). 이번에 정리하거나 공개 상태를 바꾸지 않았다. 전후 비교는 항목 순서를 보존해 수행했다.

## 검증

- 전체 테스트 65파일·1,717개, lint·typecheck, 387페이지 프로덕션 빌드 통과.
- 실제 조립 데이터 비교에서 예상한 원고 17곳 외의 변경 없음. 견종·표준 상세의 구성과 공개 순서 유지. 출처 변경은 별도 감사로 확인했다.
- 원고·자산 감사 통과. 기존 점검 기록, 새 문구·해시·출처·공개 여부, 공통 안내 3개와 출처 연결을 검사했다. 이미지 1,880개는 HEAD와 동일하다.
- 최신 빌드 서버 `http://127.0.0.1:3002/`에서 홈·대상 12종·미대상 시바 총 14페이지를 PC1440/모바일390·320px로 확인했다(42화면). HTTP 200, 가로 넘침·JavaScript 오류 없음. 12종의 정확한 건강 원고·공통 안내·자료 링크, 키보드 펼치기/접기, 말티푸 공개 본문을 확인했다. 푸들·캐벌리어·도베르만 화면도 직접 확인했다. 대상이 아닌 시바에는 새 건강 안내를 표시하지 않는다.
- 3000번 서버는 이전 화면을 제공해 최종 검증에서 제외했고, 최신 빌드를 별도 3002번 서버로 실행했다.
- 기존 말티푸 검사 기록 테스트가 첫 실행에서 실패해 문구를 명확히 보완했다. 테스트를 완화하거나 삭제하지 않았다.
- 로그·비교 자료·화면은 Git에서 제외된 `tmp/genetic-*`에 보관한다. 실기기 iOS 검증은 하지 않았다.

## 남은 범위

이번 12종에서도 모든 유전 질환·최신 검사 패널을 열거한 것은 아니다. 나머지 견종과 유전적 검사 근거가 부족한 집단, 질환별 유병률, 국가별 권장 검사 차이, 실제 국내 검사 접근성은 후속 대조가 필요하다. 초보자·성장 가이드와 건강 장면 전체도 이번에 검수하지 않았다. 미확인 범위를 자동으로 ‘안전’ 또는 ‘검수 완료’로 바꾸지 않는다.
