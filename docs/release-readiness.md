# Dog Atlas 출시 준비와 전문가 검수 체크리스트

> 기준일: 2026-08-11
>
> 현재 판정: 기술 QA 완료, 외부 전문가 검수 대기. 전체 콘텐츠는 `mvp-editorial-draft`
>
> 원칙: 자동 테스트·편집 검수·전문가 검수를 서로 대신하는 표현으로 사용하지 않는다.

## 1. 현재까지 확인한 범위

| 영역 | 현재 상태 | 근거 |
|---|---|---|
| 데이터 구조 | 370종 스키마 검증, slug·관련 견종·출처 참조 검사 | Vitest 데이터·마스터 카탈로그 테스트 |
| 견종 발견 | 실제 필드 기반 필터, 같은 범주 OR·다른 범주 AND, URL 복구 확인 | 390px·768px 브라우저 조작 QA |

| 시각 자산 용량 | 카드 최대 514,412B, 역사 최대 644,186B | 카드 550KB·역사 700KB 상한 테스트 |

## 2. 출시 차단 기준

다음 항목 중 하나라도 실패하면 배포 후보로 표시하지 않는다.

- lint, TypeScript, 전체 Vitest, production build 중 하나라도 실패
- 게시 견종의 카드·역사 이미지 누락 또는 동일 파일 해시 중복
- `/discover` 필터 결과와 URL query 복구 결과 불일치
- 390px, 768px, 1440px, 1920px에서 문서 전체의 의도하지 않은 가로 넘침
- 모바일 고정 메뉴가 주요 버튼·결과를 영구적으로 가림
- 출처 없는 건강·행동 단정, 순위·궁합·추천 점수 표현 노출
- `mvp-editorial-draft`를 전문가 검수 완료 정보처럼 표시

## 3. 전문가 검수 기록 양식

검수자는 한 번에 전체 견종을 승인하지 않고 아래 단위로 기록한다.

| 필드 | 기록 내용 |
|---|---|
| 견종 | slug, 한글명, 영문명 |
| 검수 분야 | 형태·피모 / 역사·역할 / 행동 표현 / 수의학·돌봄 / 등록·보존 지위 |
| 검수 대상 | 정확한 데이터 경로 또는 화면 문장 |
| 기준 자료 | 등록단체 표준, 국가기관 기록, 논문 등 1차 자료 URL |
| 판정 | 승인 / 수정 후 승인 / 보류 |
| 심각도 | 차단 / 중요 / 경미 |
| 수정 제안 | 사실 범위와 권장 문구를 분리해 기록 |
| 검수자 | 이름, 전문 분야·자격, 검수일 |
| 적용 버전 | commit SHA와 반영 확인일 |

## 4. 분야별 체크리스트

### 형태·이미지

- 성견의 비율, 머리, 귀, 꼬리, 피모와 대표 모색이 기준 범위 안에 있는가?
- 다른 견종의 핵심 특징이 섞이지 않았는가?
- 카드와 역사 장면 속 개가 같은 견종으로 읽히는가?
- 랜드레이스·토종 개체군의 다양성을 단일 쇼 타입처럼 고정하지 않았는가?
- 작업 장면이 위험하거나 고통스러운 역할을 낭만화하지 않는가?

### 역사·역할

- 기원국, 형성 지역, 등록단체의 원산국 표기를 구분했는가?
- 이름의 어원과 실제 역할을 인과관계처럼 과장하지 않았는가?
- 불확실한 고대 기원이나 전승은 확정 문장으로 쓰지 않았는가?
- 과거 역할을 오늘날 모든 개체의 행동 보장으로 연결하지 않았는가?

### 행동

- `할 수 있다`, `나타날 수 있다`처럼 경향과 개체 차이를 함께 표현했는가?
- 공격성, 입질, 사회성이나 훈련 가능성을 품종만으로 예측하지 않았는가?
- 활동·교감·독립성 등 필터 값이 원고와 명백히 충돌하지 않는가?
- 보호자의 환경·학습·건강 맥락을 함께 안내하는가?

### 수의학·돌봄

- 질환명, 수명, 체중·체고 범위의 출처와 날짜가 명확한가?
- 증상·진단·예후를 일반 정보가 대신하지 않는가?
- 단두, 척추, 관절, 체온 조절 관련 문장이 과도한 안심 또는 공포를 만들지 않는가?
- 의료 판단이 필요한 문장은 수의사 상담으로 자연스럽게 연결되는가?

### 등록·보존 지위

- FCI 정식·잠정, 다른 국제 단체 등록, 국가유산, 랜드레이스를 구분했는가?
- `non-fci`를 가치가 낮거나 존재하지 않는 견종이라는 뜻으로 사용하지 않았는가?
- 국가유산·국가등록에는 담당기관과 공식 기록이 연결되는가?
- `documented-population`을 독립 표준 견종으로 승격해 표현하지 않았는가?

## 5. 우선 검수 묶음

1. 토종견·랜드레이스: 경산의 삽살개, 경주개 동경이, 풍산개, 제주개, 몽골 방카르
2. 등록체계가 다른 견종: 아메리칸 핏불 테리어, 아메리칸 불리, FCI 잠정 인정 17종
3. 외형 오인 위험이 큰 묶음: 흰 가축보호견, 지역 스피츠, 희귀 후각하운드, 포인팅견
4. 수의학 표현 민감도가 높은 묶음: 단두형, 초대형견, 긴 허리·짧은 다리 체형
5. 핵심 진입 견종: 홈·비교·프리셋에서 자주 노출되는 견종

## 6. 현재 남은 외부 검수

- 수의학·행동 전문가의 이름과 자격이 연결된 승인 기록은 아직 없다.
- 전체 370종의 형태 승인이 끝난 것은 아니다. `breed-visual-audit.md`의 교체·유지 확인 범위 밖 자산은 계속 편집 일러스트로 표시한다.
- 풍산개·제주개는 국가기관 또는 보존기관의 1차 자료를 더 확보하기 전까지 `documented-population`을 유지한다.
- 수명·계통 5개 편집 보류 필드는 근거가 확보될 때까지 현재의 확인 중 문구를 유지한다.

## 7. 최종 배포 후보 승인

아래 네 주체의 승인 기록을 분리한다.

- 개발: 자동 검사와 production build
- 디자인·접근성: 네 기준 폭과 키보드·스크린리더 흐름
- 편집: 한국어 문맥, 출처와 불확실성 표현
- 전문가: 형태, 행동 또는 수의학 등 담당 분야만 승인

한 분야의 승인을 다른 분야의 승인으로 확대하지 않는다. 최종 배포 후보에는 각 승인 날짜와 commit SHA를 남긴다.
