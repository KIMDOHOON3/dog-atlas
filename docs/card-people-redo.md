# 카드 인물 재제작 — 2026-09-06

사용자는 뒷면 번호 삭제, 토이푸들 앞면을 뒷면의 작은 체구와 인상에 맞게 재제작, 모든 뒷면 인물의 지역 적합성 재확인과 재제작을 요청했다. 기존 소형견 여러 장에 같은 인물이 반복된 문제를 바로잡는 작업이다.

## 범위

- 공통 CardBack의 표시 번호와 전용 스타일 제거. 슬라이드 번호 탐색은 유지.
- 토이푸들 앞면 한 장만 재제작. 프랑스 마당 배경과 실버 털색을 유지하고 작은 성견 비율과 여백을 살린다. 다른 견종 앞면은 보존.
- 전체 19종 뒷면의 인물과 복장 재제작. 각 그림 자체를 편집 대상으로 삼아 강아지·배경·비교 크기·왼쪽 정보 및 하단 여백을 유지한다. 다른 카드의 인물 이미지를 공통 참고로 쓰지 않는다.
