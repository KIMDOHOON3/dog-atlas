# 래브라도 — 온몸으로 달리는 모션 시안

기존 `../motion`의 외형·밝은 표정·털을 보존한 별도 수정 3이다. 기존 Blender와 프레임은 덮어쓰지 않았다. `review.html`에서 측면/3⁄4 각 48장을 정지 상태부터 한 장씩 확인한다. 정상 60fps, 0.8초 주기이며 ½·¼ 속도를 제공한다.

## 바뀐 동작

- 대각선 속보 대신, 시차를 둔 뒷발 지지 → 공중 신전 → 앞발 착지 → 공중 회수 순서.
- 가슴·골반을 따로 움직여 몸의 길이·등선·기울기와 상하 이동을 함께 변경. 머리는 가슴 회전을 일부 상쇄한다.
- 귀 뿌리는 머리에 붙이고, 귀판과 끝의 회전에 지연과 좌우 차이를 적용했다. 꼬리 뿌리/끝도 골반을 따라간다.
- 원본의 피부와 Hair Curves에 같은 가중 변환을 사용한다. 기존 웃는 얼굴은 다시 조형하지 않았다.

## 참고와 해석

실제 촬영된 [Eadweard Muybridge, Dog Dread galloping, plate 707, 1887](https://commons.wikimedia.org/wiki/File:Dog_Dread_galloping_(rbm-QP301M8-1887-707).jpg)의 8개 측면 연속사진을 직접 관찰했다. 모이는 자세, 길게 펴는 자세, 머리·귀 방향의 변화를 동작 참고로 사용했다. 래브라도 자견의 계측 영상이나 모션 캡처가 아니므로 동일한 운동학을 검증했다는 뜻은 아니다. 원본은 USC Libraries 소장 자료이며 참고 사진은 결과물에 포함하지 않는다.

[University of Minnesota, Canine Gaits](https://vanat.ahc.umn.edu/mGaits/)는 지지·추진·회수 단계와 비대칭 보행의 발 순서를 참고했다. 해당 애니메이션은 발 순서를 설명하는 도해이며 몸통 역학을 묘사하지 않는다는 원문의 범위를 따른다.

움직임은 수작업으로 정한 키프레임과 2관절 IK, 가중 변환이다. 실제 영상을 추적한 데이터·물리 시뮬레이션이라고 표현하지 않는다.

## 파일

- `exports/puppy-run-study.blend`: 편집 가능한 22개 컨트롤러, 1–48프레임/루프 종점 49 키프레임, 메시와 털 포함.
- `textures/`: 상대 경로로 연결한 기존 4K 맵 4장. `.blend`를 옮길 때 상위 폴더 구조를 함께 유지한다.
- `frames/side`, `frames/three-quarter`: 실제 Cycles 960×720, 24 samples, AgX 렌더 각 48장.
- `preview-normal.webp`, `preview-quarter.webp`, `preview-three-quarter.webp`, `preview-three-quarter-normal.webp`: 같은 렌더로 인코딩한 움직이는 미리보기.
- `../puppy-whole-body-run.zip`: 필요할 때 `package_motion.py`로 생성하는 전달용 묶음. 중복 용량 정리를 위해 2026-09-13 로컬 ZIP은 제거했으며 원본과 미리보기는 유지한다.
- `build_run.py`: 원 프로젝트의 `../motion/build_motion.py`, 정적 제작 도우미와 이전 Blender를 재사용한다. ZIP의 `.blend` 열기에는 Python 도우미가 필요 없다. 재생성에는 원 프로젝트가 필요하다.

## 검증과 남은 부분

검증 결과는 `reports/verification.json`에 기록한다. 재열기 후 평가된 몸체·얼굴·귀·털의 루프, 비정상 좌표, 텍스처 경로, 귀 끝의 머리 상대 이동, 지지 발의 높이를 확인한다. 플레이어 DOM 검사와 PNG 시각 확인을 별도로 수행한다.

2026-09-12 재열기 검사: 22개 키프레임 컨트롤러, 122,068가닥 털. 몸체·얼굴·귀·털 루프 차이 0, 누락 텍스처/비정상 몸체·얼굴 좌표 0. 피부 최저점 +0.094mm, 지지 발 높이 변화는 수치 오차 수준이다. 몸통 상하 폭 19.95mm, 머리 기준 귀 끝 전후 폭 약 40mm, 공중 구간 17/48프레임이다. 몸체·구강·혀 비매니폴드 모서리/면적 0 면 0건. 첫 검사에서 발견된 발 안쪽의 몸통 가중치를 발바닥 컨트롤로 옮기고 다시 검사했다.

별도 발바닥 패드/발톱 메시도 49프레임에서 평가해 최저점 +1.20mm와 유한 좌표를 확인했다. 플레이어 DOM의 프레임 이동/순환·속도·슬라이더·방향 전환·자세 문구·키보드·화면 밖 정지 검사를 통과했다. 프로젝트 lint·typecheck·54파일/1,667테스트·385페이지 빌드 통과. 실제 브라우저에서 이 로컬 파일 플레이어를 새로 렌더링한 검증과 실기기 성능 측정은 포함하지 않는다.

얼굴의 사실성, 관절 부피 보존과 어깨/골반 조형, 쿼드 리토폴로지, 프로덕션 뼈 리그는 아직 미완료다. 특히 깊게 접힌 뒷다리의 압축과 연결부가 남는다. 자가 교차 전수 검사나 실동물 해부학 전문가 검수는 하지 않았다. 상업용 포토리얼 에셋의 완성 판정이 아니며 라이브 푸터에는 연결하지 않았다.
