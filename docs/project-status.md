## 운동장 조명·정면 시점·수동 회전 개선 (2026-10-26)

- 중립적인 주변광과 그림자를 만들지 않는 보조광으로 어두운 부분을 밝히고, 잔디를 밝은 초록과 낮은 대비의 입자로 조정했다. 해상도·기하·잔디 질감 크기는 유지한다. 기본 카메라는 모바일 약 28→22도, PC 약 26→20도로 낮췄다.
- 빈 곳을 가로로 드래그하면 좌우 24도 범위에서 둘러볼 수 있다. 세로 드래그는 페이지 스크롤, 장난감은 집기/던지기를 유지한다. 좌우 버튼과 시점 초기화를 제공하며 확대·관성·자동 회전은 없다. 화면 밖·취소·다중 터치·창 포커스 상실 시 드래그를 종료한다. 동작 감소 상태에서도 직접 시점 조작은 가능하다.
- 회전 시 겹치는 장난감 터치 영역은 화면상 가장 가까운 장난감을 선택하도록 보완했다. 로딩 미리보기 두 장을 새 조명·각도로 갱신했다(모바일 19,360B / PC 56,110B, `v=2`). 자체 제작 출처와 해시를 갱신했다.
- lint·typecheck·70파일/1,736테스트·387페이지 빌드 통과. 320/390/900/1440px에서 화면·양방향 회전 한계·초기화와 가로 넘침 없음 확인. 모바일 모사 터치로 가로 회전, 세로 스크롤, 회전 후 네 장난감의 실제 잡힘·던지기·초기화, 안내판 이동, 동작 감소 시 수동 조작을 검증했다. JS 오류 없음. 실제 iOS 기기에서는 미검증이다.
- 로컬 확인: http://127.0.0.1:3002/. 로컬 커밋은 완료했다. 비대화형 GitHub 푸시가 인증 정보 부족으로 실패해 운영 배포에는 아직 반영되지 않았다.

- 공·뼈다귀·원반·터그를 집으면 지면에서 살짝 들리고 이름과 얇은 선택 표시가 나타난다. 높이에 따른 그림자·공중에서 다시 잡기·초기화·동작 감소 설정은 유지한다.
