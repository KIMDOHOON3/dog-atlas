# Dog Atlas 프로젝트 현재 상태

> 마지막 갱신: 2026-09-07. 현재 상태의 진입점이며 이전 실험 분석은 정리했다.

## 제품과 보존 범위

- 전달 방식: 사용자는 로컬 확인이 어려우므로 앞으로 검증을 마친 개발 변경은 바로 커밋하고 `main`에 푸시하도록 승인했다. 배포 사이트 반영 여부를 확인해 보고한다.
- 메인 `/`: 소형견 11종·중형견 7종·대형견 8종·초대형견 8종의 양면 수채화 카드. 소형은 치와와·포메라니안·요크셔 테리어·말티즈·토이푸들(실버)·비숑 프리제·시츄·미니어처 닥스훈트·미니어처 슈나우저·파피용·말티푸. 초대형은 그레이트 피레니즈·세인트 버나드·그레이트 데인·아이리시 울프하운드·티베탄 마스티프·캉갈 셰퍼드 도그·코카시안 셰퍼드·몽골 방카르.
- `/discover`: 전체 376종의 발견·검색·필터·국내 익숙한 견종 시작 목록. URL/뒤로가기 상태와 점진 표시를 유지한다.
- 모든 `/breeds/[slug]` 상세와 기존 원고·그림·데이터·공통 로직을 보존했다. 8종 이외의 상세도 삭제하지 않았다. 등록된 표준 상세와 제작 초안의 구분을 유지한다.
- 상세가 연결하는 `/beginner-guide?breed=...` 및 진행 상태를 보존한다. 상세 디자인 재구성과 다른 크기 카드 추가는 다음 논의 대상이다.

## 현재 카드 디자인과 성능

- 기본 진입을 소형견으로 변경했다. 크기 필터 위에 겹친 카드/정렬된 네모 선 아이콘과 `한 장씩 보기 / 펼쳐보기`를 배치했다. 펼쳐보기는 모바일 2열·PC 3열이며 기존 앞뒷면 디자인을 그대로 축소해 사용한다. 모바일은 2열 목록을 유지하며 크게 보기에서 중앙 모달로 카드를 연다. 목록 아래 버튼은 2칸, 모달 아래는 뒤집기·자세히 보기·닫기 3칸이다. 배경 스크롤을 잠그고 닫으면 목록 위치와 포커스를 복원한다. PC는 기존 크기에서 독립적으로 뒤집히며 각 카드 아래 뒤집기·상세 버튼을 제공한다. 홀로그램 조절은 표시하지 않고 뒷면은 첫 뒤집기 때 로드한다. 크기 필터와 선택을 유지하며 펼쳐보기 동안 렌더러를 해제하고 뒷면 선로딩을 중단한다.

- 대형견 8종(골든·래브라도·사모예드·허스키·셰퍼드·도베르만·롯트와일러·달마시안)을 추가해 메인은 총 34종이다. 역사 배경과 지역 인물을 담은 양면 WebP 16장, 합계 3,085,848B. 빈 대형견 상태를 제거하고 상세 링크와 기존 렌더러에 연결했다. [제작·자료](large-cards-eight.md).

- 재패니즈 스피츠를 중형견 7번째 카드로 추가했다. 일본 정원 앞면과 일본인 여성 보호자의 체구 비교 뒷면을 제작했다. 기존 발견·상세 분류는 유지한다. AKC 기준 약 30–38cm·4.5–11kg·10–14년을 표시하며, 그림은 정밀 측정도가 아닌 편집 삽화다. [출처](https://www.akc.org/dog-breeds/japanese-spitz/), 제작 프롬프트는 `design/card-medium/japanese-spitz-prompts.json`.

- 중형견 첫 6종: 진돗개·시바견·웰시 코기 펨브로크·비글·보더콜리·잉글리시 코커 스패니얼. 역사 배경 앞면과 지역별 성인 크기 비교 뒷면 12장(2,871,690B), 한국/일본 국기, 짧은 역사·체격·수명·기존 상세를 연결했다. 기존 전환과 모바일 동작을 유지한다. [제작·출처](medium-cards-six.md).

- 뒷면의 장식 번호를 모두 제거했다. 토이푸들 앞면은 작은 성견 비율과 부드러운 인상으로 재제작했고, 19종 뒷면도 각 지역에 맞는 서로 다른 인물·복장으로 교체했다. 다른 견종 앞면은 유지했다. 교체 WebP 20장 합계 3.66 MB이며 이전 파일은 제거했다. [인물 기준과 제작 기록](card-people-redo.md).

- 이번 인물 교체는 lint·typecheck·1,650개 테스트·385페이지 production build를 통과했다. Chrome 390px/1200px에서 19종 뒷면 이미지 로딩, 장식 번호 제거, 페이지 오류 없음을 확인하고 토이푸들 앞면과 모바일 정보 배치를 시각 점검했다.

- 홀로그램 눈 결정/산 능선 각인을 뼈다귀 장난감·공·밥그릇·목줄 네 모티프로 교체했다. 네 배치의 RGB 아틀라스(1536×528, 244,575B)를 한 번 로드하고 견종 slug 해시로 고정 선택한다. 같은 카드의 양면·재방문에서 무늬를 유지하며 두 색상 테마 모두 용품 각인을 표시한다. 텍스처 샘플 수·캔버스 수·30Hz 제한은 그대로다. 이전 눈 결정 텍스처는 제거했다.

- 소형견 8종 추가: 새 수채화 양면 16장, 지역 배경과 앉은 성인/신발 비교 구도, 역사·체격·수명·기존 상세 링크. 말티즈는 중앙 지중해 기원/이탈리아 관리, 비숑·파피용은 프랑스·벨기에 공동 표시. 실버는 토이푸들 털색으로만 표기하고 말티푸는 국기와 고정 체격 수치 없이 부모견 차이를 설명한다. [정보·자산 근거](small-cards-eight.md).

- 사용자 승인으로 초소형 분류를 소형에 통합했다. 메인 네 메뉴와 견종발견 네 필터를 일치시키고 기존 `size=extra-small` URL은 소형으로 해석한다. 원본 체격 측정/계산 데이터는 보존하고 서비스 표시/필터에서 합친다. 소형 필터 52종, 중형 114종, 대형 126종, 초대형 27종.

- 초소형견에 포메라니안·요크셔 테리어를 추가했다. 독일 정원·영국 작업장 배경과 지역 일상복의 성인/신발 비교 구도, 국기·역사·크기·수명·상세 링크를 연결했다. 새 WebP 4장 합계 1,165,174B. 기존 렌더러/모바일 스크롤·스와이프 로직은 유지한다. [자료·프롬프트](extra-small-expansion.md).

- 초소형견 첫 카드 치와와: 멕시코 돌마당의 전신과 앉은 성인의 신발 옆 크기 비교 장면. 두 WebP 합계 548,246B. 앞뒤 같은 개체·수채화 톤을 유지하고 뒷면 발끝과 역사 문구가 겹치지 않게 배치했다. 멕시코 국기·크기/수명·짧은 반려견 역사·기존 상세 링크를 연결했다. [자료와 프롬프트](chihuahua-card.md).

- 메인 상단에 소형견→중형견→대형견→초대형견 크기 메뉴를 추가했다. 선택 항목은 가로 스크롤로 가운데 정렬하며 reduced motion에서는 즉시 이동한다. 소형견 11종·중형견 7종·대형견 8종·초대형견 8종을 전시한다. 분류 변경 시 첫 카드 앞면으로 돌아간다. 전환 중 분류 변경은 막아 비동기 이미지 준비와 충돌하지 않게 했다. 카드 앞면 하단 표기는 `DOG ATLAS`다.
- 모바일 터치 드래그는 카드 기울기에 연결하지 않으며 포인터를 직접 캡처하지 않는다. 카드 위 세로 스크롤·핀치 확대를 브라우저에 맡긴다. 터치 취소/이탈도 버튼 시연을 중단하지 않는다. `카드 움직여 보기` 시연과 뒤집기 버튼, PC 마우스 기울기는 유지한다.
- 모바일 단일 터치의 좌우 스와이프로 이전/다음 견종을 넘긴다. 초기 방향을 고정하고 가로 이동 48px 이상·세로 이동의 1.4배 초과일 때 기존 카드 전환을 실행한다. 세로/대각선·다중 터치·취소는 넘김에서 제외하며 처음/마지막 경계와 전환 중 중복 실행을 막는다.
- 뒷면 8장의 인물을 검토하고 세인트 버나드·티베탄 마스티프·캉갈·코카시안 셰퍼드·몽골 방카르 5장을 지역/역사에 어울리는 복장으로 편집했다. 피레니즈·그레이트 데인·아이리시 울프하운드는 기존 야외 복장을 유지한다. 새 WebP 5장 합계 869,534B, 이전 대체 자산 5장 제거. [그림·자료·프롬프트](regional-card-backs.md).
- 사용자가 30개 후보 중 로고 **L01**, 뒤집기 **F08**, 자세히보기 **D10**을 최종 승인했다. 한글 로고와 32px 아이콘을 승인된 원래 색으로 적용했다. 현재 견종 상세 링크·모바일 두 버튼·prefetch OFF를 유지한다. 정적 WebP 3개 합계 53,760B이며 렌더러 변경은 없다. [승인 자산과 프롬프트](brand-mark.md).
- 사용자 요청으로 비교 페이지·3003 서버·미선택 시안·이전 로고/아이콘 실험 자산을 정리했다. 승인된 PNG 3개와 프롬프트만 `design/brand/`에 보존했다. 기록된 미선택 생성 원본 35개도 삭제했다.

- 앞면은 견종 전신·역사 배경, 뒷면은 사람 옆 크기 비교와 출신/국기·크기·수명·짧은 역사. 생성 그림은 비교 예시이며 정확한 측정 도식이 아니다. 방카르 수명은 자료 부족으로 남긴다.
- 현재 이동은 실제 WebGL 격자/버텍스 변형이다. 다음 카드는 위부터 왼쪽으로 휘어 빠지고, 이전 카드는 왼쪽에서 돌아와 펴진다. 카드 전체 HTML을 준비 단계에서 텍스처로 캡처하며 그림·글이 함께 휜다. 이동은 820ms다.
- 포일 1개와 전환 1개의 캔버스/컨텍스트를 재사용한다. 전환 때 기본 포일 렌더링은 멈추며 두 면만 그린다. 최대 60Hz·110만 픽셀·GPU 텍스처 LRU 4장으로 제한하고 유휴/숨김/화면 밖에서는 중지한다. reduced motion은 즉시 교체하며 WebGL/캡처 실패만 CSS 대체 경로를 사용한다. [구현·예산·검증 한계](card-transition.md).
- 번호 선택 밑줄, 카드 이미지 뒤집기 아이콘과 순차 문구 전환, 붉은 ON 표시등을 유지한다. 시연 버튼은 삼각형 아이콘을 유지하고 `카드 움직여 보기`/`움직임 멈추기`로 표기해 영상 재생과 구분한다. 홀로그램 OFF 시 강도 영역은 280ms 동안 접히고 사라지며, ON 시 이전 값을 유지해 펼쳐진다. 숨겨진 슬라이더는 키보드/접근성 탐색에서 제외하며 reduced motion은 즉시 전환한다.

## 2026-09-06 승인된 정리

- 사용자는 현재 메인·견종발견·모든 상세와 공유 파일 보존을 최종 승인했다. 이전의 과도한 2,078개 삭제안은 폐기했다.
- 기존 메인 전용 스타일/생활조건 컴포넌트·이름/주제 탐색·중복 card-lab, 게임·퀴즈·엽서, 장소 검색·공공 API 수집 데이터·카카오 지도, 영상 분석 및 관련 임시 자료를 삭제했다.
- 305개 기능/분석 파일과 참조 없는 이미지 6개를 삭제했다. 이미지 참조 검사는 로컬 콘텐츠를 실행해 동적 경로도 확인했으며, 남은 1,794개 이미지는 보존했다.
- 지도 전용 proj4와 전용 의존 패키지를 manifest/lock에서 제거하고 메타데이터·사이트맵·메뉴를 남은 경로에 맞췄다. API 키 환경 파일은 변경하지 않았다.
- 상세·발견 제작 지침과 현재 카드 자산/출처 문서는 보존했다. 내용은 편집 초안이며 수의사·행동 전문가 검수 완료로 표시하지 않는다.

## 검증

- 중형견 첫 6종: lint/typecheck·51파일 1,650테스트·385페이지 production build 통과. Chrome 390px/1200px에서 6종 앞뒤 이미지 로딩, 상세 링크, 중형→소형→중형 첫 카드 복귀, 가로 넘침·페이지 오류 없음 확인. 모바일 뒷면 6장과 긴 제목 앞면을 시각 확인했다. 새 WebP 12장 합계 2,871,690B.

- 용품 홀로그램: lint/typecheck·51파일 1,650테스트·385페이지 빌드 통과. Chrome에서 새 아틀라스 로딩·두 테마 시연·뒤집기·포일 유지·브라우저 오류 없음 확인. 프레임별 텍스처 업로드나 모티프 계산은 추가하지 않았다.
