# 중형견 첫 6종 — 2026-09-06

사용자의 중형견 제작 요청에 따라 진돗개·시바견·웰시 코기 펨브로크·비글·보더콜리·잉글리시 코커 스패니얼을 첫 묶음으로 제작한다. 기존 발견/상세를 연결하며 새 상세 원고를 추가하지 않는다. 인기 순위가 아닌 편집 구성이다.

## 그림과 연결

- 앞면: 기존 견종발견 삽화를 외형 참고로 사용해 역사 배경을 새로 그린 전신 수채화. 코기는 자연스러운 긴 꼬리를 표현한다.
- 뒷면: 해당 앞면을 참고해 같은 털색·배경을 유지하고 지역에 어울리는 서로 다른 성인과 같은 바닥에 서 있는 체구 비교 장면. 왼쪽 정보 영역과 하단 역사 여백 확보. 실제 측정 도식은 아니다.
- 진도 돌담/한국 여성, 일본 산길/일본 남성, 웨일스 목장/여성 농장인, 영국 들판/노년 남성, 영국 접경 양 목장/여성 목동, 영국 숲/젊은 남성. 지역 표현은 복장과 배경을 함께 사용하며 외형이 국적을 증명한다는 의미가 아니다.
- 기존 양면·포일·전환·모바일 스크롤/스와이프를 사용한다. 캔버스·GPU 캐시 예산 변경 없음. 한국/일본 국기 지원을 추가한다.
- 프롬프트·생성 원본·최종 파일과 치수는 `design/card-medium/prompts.json`에 기록한다.
