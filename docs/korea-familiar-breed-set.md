# 한국 사용자에게 익숙한 견종 시작 목록

> 확정일: 2026-08-24
> 목적: 376종 전체 도감을 없애지 않고, `/discover`에서 처음 고를 수 있는 부담을 줄이는 편집 시작점

## 선정 방식

- **국내 양육 자료:** KB경영연구소의 `2025 한국 반려동물 보고서`에서 양육 비중 상위로 제시된 몰티즈·푸들·믹스견·포메라니안·비숑 프리제·치와와·시추를 가장 강한 출발 근거로 삼았다.
- **변화 확인:** 같은 기관의 2023 보고서에서 진돗개, 요크셔 테리어, 골든 리트리버와 의도적 교배 집단이 국내 양육 맥락에서 함께 언급된 점을 보조 근거로 봤다.
- **편집 보완:** 국내 조사 상위권만 쓰면 소형 반려견에 과도하게 치우치므로, 한국에서 이름과 외형이 널리 알려진 사냥견·목양견·작업견·대형견을 보완했다.
- 이 목록은 **인기 순위, 추천 결과, 국내 등록 개체 수 순위가 아니다.** 낯선 376종을 한 번에 보여주기 전에 제공하는 32종의 편집 입구다.
- 일반 믹스견은 하나의 견종 상세로 단정할 수 없어 이번 견종 카드 목록에서는 제외했다. 말티푸는 도감 안에서 `designer-cross`로 구분한 기존 상세가 있어 포함했다.

## 첫 화면 12종

말티즈, 푸들, 포메라니안, 비숑 프리제, 치와와, 시추, 진돗개, 요크셔 테리어, 말티푸, 재패니즈 스피츠, 웰시 코기 펨브로크, 골든 리트리버

## 펼쳐보는 20종

닥스훈트, 비글, 미니어처 슈나우저, 퍼그, 프렌치 불도그, 페키니즈, 파피용, 이탈리안 그레이하운드, 잭 러셀 테리어, 래브라도 리트리버, 보더콜리, 사모예드, 시베리안 허스키, 시바견, 저먼 셰퍼드 독, 도베르만, 롯트와일러, 달마시안, 그레이트 덴, 세인트 버나드

## 구현 원칙

- 첫 12종만 이미지 카드로 바로 보여준다.
- 나머지 20종은 사용자가 원할 때 같은 이미지 카드 형식으로 펼친다.
- 모든 카드는 점수나 적합도 없이 상세 페이지로 이동한다.
- 검색·생활 조건 필터·전체 376종 결과는 그대로 유지한다.
- 목록 원본은 `src/content/familiar-korea-breeds.ts`에서 Zod로 검증하고, 슬러그 중복과 전체 도감 연결을 테스트한다.

## 상세 적용 상태

2026-08-25부터 첫 화면 12종과 펼쳐보는 20종 모두 공식 상세 기준을 사용한다. 푸들은 네 크기 선택이 있는 전용 모듈을 유지하고, 나머지 31종은 같은 01~04 공용 구조와 Zod 데이터 경계를 사용한다. 각 상세는 배경·현재 경향·생활 현실의 기본 세 단계, 이미지 생활 현실 두 장, 생활 질문 세 개와 관련 견종 직접 이동을 제공한다. 공식 자료로 현재의 전문 역할이 확인된 래브라도 리트리버·골든 리트리버·저먼 셰퍼드 독·도베르만은 이미지가 있는 네 번째 `현재의 역할` 단계를 추가한다. 목록의 선정 의미는 바뀌지 않으며 공식 기준 적용이 인기 순위나 추천을 뜻하지 않는다.
