# 스피츠 — 눈·턱·귀 연결 수정

사용자가 순한 표정 수정본을 확인하고 계속 진행하도록 요청해, `06-soft-expression.blend`를 기준으로 얼굴의 접합을 다듬었다. 승인된 전신 체형과 기존 버전은 보존한다.

[Blender 원본](exports/07-face-integration.blend) · [얼굴 3/4](previews/face.png) · [정면](previews/front.png) · [측면](previews/side.png) · [전신](previews/body.png)

## 실제 수정

- 얼굴 코트 안에 눈 포켓을 만들고 기존 눈 표면 중심을 약 1.9mm 안쪽으로 옮겼다. 눈 표면의 중심 삼각형/바깥 고리 사이에 달랐던 면 방향을 통일한 뒤 뒤쪽 두께를 추가했다. 눈꺼풀 연결 곡면·가는 눈물선·짧은 바깥 잔털을 추가하고 강한 반사를 줄였다.
- 아랫턱을 더 얇은 별도 폐곡면으로 다시 만들고 입안 바닥과 연속된 U자 아랫입술을 맞췄다. 혀의 순한 표정과 숨겨진 송곳니는 유지했다.
- 각 귀를 10정점의 평평한 프리즘에서 굽은 앞면·뒤쪽 두께가 있는 닫힌 귀 형태로 바꿨다. 06의 다섯 윤곽 기준점을 따라 둥글게 보간하고 안쪽 분홍색과 짧은 털을 적용했다.
- 코트 Boolean 연산 후 달라진 삼각형 분할에 맞춰 얼굴 털 뿌리 288개를 다시 맞췄다. 최종 털은 314,886가닥, 별도 수염은 12가닥이다.

## 재현

원본 `../soft-expression/exports/06-soft-expression.blend`를 새로 연 뒤 `../integrate_face.py`를 import한다. `apply()` → `ear_cups()` → `lid_fringe()` → `settle_roots()` → `render()` → `verify()`를 각각 1회 실행한다. 동일 장면에 반복 적용하는 함수가 아니므로 다시 만들 때는 원본 06에서 시작한다.

## 검수

- 저장한 07을 다시 열어 검사했다. 승인 기본 피부 전체, 얼굴 밖 코트 93,808정점, 꼬리 두 메시의 좌표 서명이 기준과 동일하다. 06 파일 해시도 보고서에 기록했다.
- 코트·새 턱·코·양쪽 눈 폐곡면·양쪽 귀 폐곡면의 비매니폴드 모서리/면적 0인 면은 0개다. 이는 전체 오브젝트 간 관통 검사와 다르다.
- 털 좌표는 유한하고 반지름은 양수다. 각 오브젝트의 약 500개 뿌리 표본에서 표면까지 최대 약 0.025mm 이내다. 누락된 외부 텍스처는 없다.
- 이전과 동일한 카메라/조명, Cycles 48샘플·AgX로 4방향 렌더를 생성하고 눈·입·귀를 확인했다. [06 얼굴 비교](../soft-expression/previews/face.png).
- Python 구문, ESLint, TypeScript, Vitest 54파일/1,667개 테스트, Next.js 빌드를 통과했다.

## 남은 범위

정적 얼굴 개선본이며 포토리얼 완성 모델은 아니다. 눈의 흰 테두리와 색 경계, 주둥이/입꼬리의 단순한 덩어리, 균일한 털 흐름은 더 다듬을 부분이다. 눈의 닫힌 두께가 실제 공막·홍채·각막의 분리된 광학 구조 완성을 뜻하지 않는다. 눈꺼풀 변형용 쿼드 리토폴로지·리깅·동적 털 바인딩·전체 자가 교차·웹 성능은 검증하지 않았다. 사이트/푸터에는 적용하지 않았다.
