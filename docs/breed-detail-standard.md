# 견종 상세페이지 기준 — 푸들 상세에서 확정한 구조

## 1. 문서의 지위

푸들 상세 `/breeds/poodle`은 앞으로 개편하는 견종 상세페이지의 공식 기준이다. 기준으로 삼는 것은 푸들의 문장이나 네 가지 크기 기능을 그대로 복제하는 일이 아니라, 사용자가 한 견종의 배경과 오늘의 생활을 짧은 흐름 안에서 이해하도록 만든 정보 순서·시각 위계·상호작용 원칙이다.

기존 375개 상세를 한 번에 자동 변환하지 않는다. 견종마다 근거와 생활 조건을 다시 검토한 뒤 작은 배치로 적용하며, 아직 개편하지 않은 상세는 현재 공통 화면을 유지한다.

## 2. 페이지가 답해야 할 질문

처음 보는 사용자가 상세를 읽고 다음을 이해할 수 있어야 한다.

1. 이 견종의 기본 생활 조건은 무엇인가?
2. 과거에 어떤 역할을 했고 그 배경은 무엇인가?
3. 그 배경이 오늘날 어떤 행동 경향으로 나타날 수 있는가?
4. 보호자는 일상에서 무엇을 체감할 수 있는가?
5. 내 생활에서 확인해야 할 조건은 무엇인가?
6. 망설여진다면 어떤 다른 생활 조건의 견종을 살펴볼 수 있는가?

핵심 흐름은 `과거의 역할 → 현재의 경향 → 보호자가 체감하는 현실 → 스스로 확인할 생활 조건`이다. 견종의 적합 여부를 점수나 정답으로 판정하지 않는다.

## 3. 필수 화면 구조

### 첫 화면 — 정체성과 기본 조건

- 대표 이미지를 가장 먼저 보여준다. 태블릿과 모바일에서는 이미지가 정보보다 위에 온다.
- 한국어 이름, 영문 이름, 한 줄 핵심 문장, 기본 정보, 세 가지 핵심 경향만 노출한다.
- 한 줄 문장은 견종을 규정하거나 수사적으로 과장하지 않고 현재 생활에서 가장 먼저 이해할 핵심 단서 하나를 말한다.
- 상단 한 줄은 견종의 정체성과 출발점을 요약하고, 2단계 제목은 오늘 보일 수 있는 행동을 설명한다. 두 위치에 같은 문장을 반복하지 않는다.
- 기본 정보는 크기, 평균 수명, 과거 역할, 현재 역할처럼 첫 판단에 필요한 항목으로 제한한다.
- 과거 역할과 현재 역할이 사실상 같으면 같은 내용을 반복하지 않고 `과거부터 현재까지` 카드 하나로 합친다. 이때 역할 카드는 한 줄 전체를 사용한다.
- 과거 역할과 현재 역할이 다르면 두 역할을 각각 표시해 2×2 카드 구성을 유지한다. 전문 작업이 확인되지 않는 견종의 현재 역할은 과장하지 않고 `반려견`으로 적는다.
- 세부 분류가 길면 푸들·닥스훈트의 크기 요약처럼 접힌 보조 정보로 제공한다. 첫 화면에는 전체 범위만 짧게 보여주고 펼친 목록에서 각 분류와 측정값을 확인하게 한다.
- 큰 유색 프로필 보드, 장식 실루엣, 반복 이미지로 정보를 감싸지 않는다. 독립된 흰 카드와 부드러운 그림자로 위계를 만든다.

### 01 — 과거에서 오늘까지

- 한 견종의 과거 역할, 오늘의 경향, 보호자가 체감할 현실을 기본 세 단계로 연결한다.
- 각 단계는 `단계 설명 → 짧은 제목 → 1~2문장 본문 → 한 의미의 이미지`로 구성한다.
- 데스크톱에서는 키보드 조작 가능한 탭과 연결선을 사용한다. 모바일에서는 손으로 넘기는 가로 스크롤 카드로 바꾸되 같은 내용을 모두 읽을 수 있어야 한다.
- 견종의 과거는 행동을 이해하는 단서일 뿐이라는 주의 문장을 `*` 표시와 함께 둔다.
- 견종의 배경과 현재 행동을 연결할 근거가 약하면 인과관계를 만들지 않는다. 이 경우 첫 단계를 형성 배경이나 몸의 구조처럼 더 정확한 출발점으로 바꿀 수 있다.
- 안내견·탐지견·경찰견처럼 오늘도 이어지는 전문 역할이 공식 기관 자료로 확인되는 견종은 같은 이야기 흐름에 이미지가 있는 `4 현재의 역할` 단계를 추가한다. 별도 역할 모듈을 반복하지 않으며, 역할명만 나열하지 않고 그 일이 요구하는 집중·환경 적응·사람과의 협업을 설명한다. 직업견의 선발 결과를 같은 견종 전체의 성격으로 일반화하지 않는 문장과 내부 출처 URL을 반드시 함께 둔다.

### 02 — 함께 살 때 체감하는 것

- 해당 견종을 실제로 키울 때 반복해서 체감하는 조건 두 개를 우선한다.
- 푸들은 `예상 성견 크기`와 `곱슬 피모 관리`를 사용하지만, 다른 견종은 활동 리듬, 경계 행동, 계절 털갈이, 체구와 힘, 사람과의 협업 등 근거 있는 다른 주제를 선택한다.
- 예방접종·배변·사회화처럼 모든 강아지에게 적용되는 양육 안내는 견종 상세에 넣지 않는다.
- 선택형 변이가 실제 판단에 중요할 때만 푸들의 네 크기나 닥스훈트의 세 크기처럼 전용 인터랙션을 사용한다. 여러 개를 한 장에 반복 배치한 합성 이미지 대신 같은 바닥선과 화풍의 독립 이미지로 비교하고, 선택 상태는 이미지·대체 텍스트·이미지 안 라벨에 함께 반영한다.

### 03 — 함께 살기 전에

- 세 가지 질문으로 사용자가 자신의 시간, 환경, 반복 관리 부담을 확인하게 한다.
- 질문은 추상적인 적합성 대신 실제 행동으로 쓴다. 예를 들어 비용을 감당할 수 있는지가 아니라 정기적인 미용과 집 빗질을 이어갈 수 있는지를 묻는다.
- 네이티브 체크박스를 사용하고 정답, 점수, 추천 결과를 제공하지 않는다.
- 세 항목을 모두 확인하면 더 자세한 맞이 준비 페이지로 가는 보조 행동을 부드럽게 연다.

### 04 — 다음으로 살펴보기

- 관련 견종은 2~3개만 보여준다.
- 카드에는 작은 이미지, 견종 이름, 현재 견종과 다른 생활 조건 한 문장, 상세 이동 링크만 둔다.
- `추천 견종`, `당신에게 맞는 견종`처럼 결과를 단정하지 않는다.
- 비교 기능이나 순위로 연결하지 않고 다른 상세로 바로 이동한다.

## 4. 콘텐츠 작성 기준

- 한 화면에는 한 가지 이야기, 한 이미지에는 한 가지 의미를 둔다.
- 노출 본문 한 블록은 최대 1~2문장으로 제한한다.
- 제목·설명·카드가 같은 사실을 반복하지 않게 한다.
- `나타날 수 있어요`, `경향이 있어요`처럼 개체 차이를 남긴다.
- 훈련법, 진단, 의료 조언을 견종 특징처럼 제시하지 않는다.
- 여러 출처로 사실을 확인한 뒤 사이트 자체 순서와 문장으로 다시 쓴다. 한 출처의 문장 배열을 번역하거나 바꿔 쓰지 않는다.
- 기준 상세에서는 공개 출처 블록을 렌더링하지 않지만, 실제 문장을 뒷받침하는 출처 데이터·확인일·스키마 검증은 내부에 유지한다.
- 과거 역할, 현재 경향, 생활 현실에서 같은 내용을 세 번 반복하지 않는다.
- 현재 직업은 실제 운용 기관이나 공인 견종단체의 직접 근거가 있을 때만 쓴다. 역사적으로 사용된 역할과 현재 운용 중인 역할을 같은 시제로 섞지 않는다.

## 5. 시각 디자인 기준

- 기본 배경은 흰색이다. 코코아 계열 글자, 오트밀 계열 보조 면, 캐러멜 계열 행동색을 제한적으로 사용한다.
- 컬러 테두리로 카드를 구분하지 않는다. 흰 카드, 명도 차이, 부드러운 그림자와 여백으로 위계를 만든다.
- 01~04 번호는 선 없는 캐러멜 배지로 표시한다. 단계 탭의 번호 사이에는 순서 관계를 보여주는 가는 연결선만 허용한다.
- 모바일 큰 제목은 24px 이하를 기본으로 하고, 데스크톱도 과도하게 키우지 않는다.
- 생활 현실 카드 제목은 설명 본문보다 한 단계만 크게 두고, 데스크톱 약 18px·모바일 약 17px 범위에서 이미지보다 앞서 보이지 않게 한다.
- 섹션 머리글의 번호·소제목은 한 줄, 큰 제목은 다음 줄의 공통 왼쪽 축에서 시작한다.
- 페이지 최대 폭과 섹션 왼쪽 축을 통일하고, 본문은 더 좁은 읽기 폭을 사용할 수 있다.
- 대표 이미지, 단계 이미지, 생활 현실 이미지, 관련 견종 썸네일은 각각 한 번의 역할만 담당한다.

## 6. 반응형과 인터랙션 기준

- 데스크톱 단계 화면은 이미지와 설명을 나란히 두고 시각적 무게를 맞춘다.
- 940px 이하에서는 이미지와 설명을 위아래로 놓고, 모바일에서는 가로 손 스크롤·스냅으로 다음 카드 일부가 보이게 한다.
- 모바일 가장자리 캐러셀은 공용 `mobile-edge-to-edge`와 `mobile-edge-to-edge-track` 규칙을 사용해 첫 카드 시작과 마지막 카드 끝 여백을 동일하게 유지한다.
- 활성 도트는 짧은 캐러멜 막대, 비활성 도트는 보이는 연한 원으로 표현한다.
- 단계 전환은 이미지를 같은 프레임에서 약 400ms 교차 전환하고, 카피는 기존 내용이 접힌 뒤 `단계 설명 → 제목 → 본문` 순서로 나타낸다.
- 약 820ms의 단계 시퀀스가 끝나기 전에는 다음 입력을 받지 않아 카피가 겹치지 않게 한다.
- 패널 높이는 단계별 문장 길이에 따라 덜컹거리지 않되 불필요한 빈 공간이 생기지 않는 범위로 맞춘다.
- 선택 버튼, 크기 이미지, 체크 상태, 완료 행동, 접기 아이콘은 짧고 일관된 전환을 사용한다.
- `prefers-reduced-motion`에서는 교차 전환, 펼침 모션, 부드러운 스크롤 같은 비필수 모션을 제거한다.

## 7. 접근성 기준

- 단계 탐색은 `tablist`, `tab`, `tabpanel` 관계와 선택 상태를 제공한다.
- 방향키, Home, End로 단계를 이동할 수 있고 포커스 순서가 시각 순서와 같아야 한다.
- 전환 중에는 바쁜 상태와 비활성 상태를 보조기기에 알린다.
- 캐러셀 도트와 크기 선택 버튼에는 대상과 현재 상태가 이해되는 이름을 제공한다.
- 이미지에는 장면과 정보 목적을 설명하는 대체 텍스트를 쓴다.
- 체크 질문은 커스텀 그림만 쓰지 않고 실제 체크박스와 연결된 레이블을 사용한다.
- 애니메이션이 없어도 모든 핵심 콘텐츠와 링크에 접근할 수 있어야 한다.

## 8. 현재 코드 구조

- `src/app/breeds/[slug]/page.tsx`: 공통 상세 진입점이다. 현재는 `breed.slug === "poodle"` 조건으로 푸들 히어로와 푸들 전용 경험을 분기한다.
- `src/components/breed-detail-standard.tsx`: 국내 익숙한 32종이 공유하는 01~04 섹션 구조를 조합한다.
- `src/components/breed-detail-standard-interactions.tsx`: 공용 단계 탭, 모바일 스냅 캐러셀, 이미지 생활 카드, 선택형 크기 비교와 체크리스트 상태를 담당한다.
- `src/components/poodle-detail.tsx`와 `src/components/poodle-detail-interactions.tsx`: 공용 구조에 푸들 전용 네 크기 선택 카드를 연결한다.
- `src/components/poodle-detail.module.css`: 현재 기준 상세들이 공유하는 레이아웃, 반응형, 전환, 모션 감소 규칙을 담는다. 파일명은 후속 정리 대상이다.
- `src/content/poodle-detail/data.ts`: Zod로 검증하는 히어로 문장, 네 크기, 세 단계 이야기, 두 생활 현실, 세 질문, 관련 견종 차이, 내부 출처 데이터다.
- `src/content/standard-breed-detail/schema.ts`와 `data.ts`: 공용 Zod 구조, 앞선 개별 적용 데이터와 전체 조회 경계를 제공한다.
- `src/content/standard-breed-detail/familiar-data.ts`: 국내 익숙한 28종 추가 적용의 공용 팩토리, 전용 카드가 없던 9종의 편집 데이터와 닥스훈트처럼 특정 견종에만 필요한 크기 비교 데이터를 제공한다.
- `src/app/breeds/[slug]/page.module.css`: 푸들 히어로와 공통 상세 컨테이너의 연결 규칙을 담는다.

재패니즈 스피츠 적용에서 공용 구조를 추출했고 말티즈와 비숑 프리제에서 서로 다른 반려 배경과 관리 현실을 검증했다. 이후 국내 익숙한 32종 전체로 범위를 넓혀 소형 반려견, 디자이너 교배견, 테리어·하운드·목양견·회수견·초대형 작업견까지 같은 정보 순서로 표현하되 견종별 원고와 이미지는 분리했다. 다음 견종도 `standard-breed-detail` 데이터에 추가하고, 네 크기 선택처럼 특정 견종에만 필요한 부분만 선택형 모듈로 연결한다. 페이지 파일에 견종별 구조 조건문을 계속 늘리지 않는다.

2026-08-27에는 그레이하운드를 익숙한 32종 밖의 첫 후속 적용으로 추가했다. 기존 `standard-breed-detail` 스키마와 공용 렌더링을 그대로 사용하고, 시각하운드의 질주·회복·보온·안전한 휴식 의미를 로컬 데이터와 서로 다른 이미지 다섯 장으로 구성했다.

같은 날 휘펫을 두 번째 후속 적용으로 추가했다. 영국의 작은 사냥감 추적과 직선 경주 배경을 현재의 시각 추적·짧은 질주 뒤 회복으로 연결하고, 푹신한 휴식 자리와 야외 보온을 서로 다른 생활 현실과 이미지로 분리했다.

## 9. 그대로 복제하지 않을 것

- 푸들의 네 가지 크기 선택 UI
- 물 회수견이라는 역사와 세 단계 문장
- 곱슬 피모 관리 카드
- 래브라도 리트리버·말티즈 관련 카드
- 푸들 이미지와 대체 텍스트

이 항목들은 푸들 콘텐츠다. 다른 견종에는 조사 결과와 실제 생활 차이에 맞는 데이터와 이미지를 새로 넣는다.

## 10. 다음 견종 적용 체크리스트

- [ ] 첫 화면에서 대표 이미지, 이름, 핵심 문장, 기본 조건이 바로 읽힌다.
- [ ] 과거 배경과 현재 경향의 연결에 직접 근거가 있다.
- [ ] 세 단계가 서로 다른 정보를 말하고 한 단계가 1~2문장을 넘지 않는다.
- [ ] 생활 현실 두 항목이 그 견종에 실제로 구별되는 조건이다.
- [ ] 세 질문이 사용자의 구체적인 일상 행동을 묻는다.
- [ ] 관련 견종의 표시 이유를 한 문장으로 이해할 수 있다.
- [ ] 같은 핵심 이미지와 문장이 반복되지 않는다.
- [ ] 모바일 손 스크롤, 부분 노출, 마지막 여백과 도트가 정상이다.
- [ ] 탭 키보드 조작과 체크박스 레이블이 정상이다.
- [ ] 모션 감소 설정에서도 내용과 기능이 손실되지 않는다.
- [ ] 내부 출처가 실제 노출 문장에 직접 연결되고 Zod 검증을 통과한다.
- [ ] 다른 견종 상세의 화면과 동작이 의도치 않게 바뀌지 않는다.
