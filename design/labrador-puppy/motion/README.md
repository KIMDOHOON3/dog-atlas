v3 모델로 만든 제자리의 가벼운 달리기 시안이다. 대각선 두 발이 번갈아 지지하며 짧은 공중 전환 구간을 갖는다. 48프레임 / 기준 60fps / 한 주기 0.8초. 49프레임에는 1프레임과 같은 자세의 연결 키를 넣었으며 플레이어와 타임라인 범위는 1~48이다. 운동장 이동이나 공 추적에 연결하지 않았다.

모션 수정 2: 꼬리 뿌리와 끝의 두 변환을 섞어 좌우로 흔들고 끝에 위상 지연을 주었다. 윗눈꺼풀을 열고 아래 안구 돌출을 줄였으며 입꼬리·볼을 올렸다. 입에는 작은 실제 개구부와 별도 안쪽 면을 만들고 혀 위치를 조정했다. 개구부 안에 시작하는 털 739가닥을 제외했다. 정적 v3는 보존하며 이 변경은 모션 파일에만 들어 있다. [얼굴 확대](face-closeup.png)와 [3/4 저속 모션](preview-three-quarter.webp)에서 확인할 수 있다.

## Blender 파일

`exports/puppy-run-study.blend`와 `textures/`의 상대 위치를 유지한다. 원본을 열고 타임라인 1~48에서 모션을 확인할 수 있다. 외부 Python 핸들러나 자동 실행 스크립트에 의존하지 않는다.

16개의 키프레임 컨트롤러와 Geometry Nodes의 가중 변환을 메시·Hair Curves에 함께 적용한다. 네 다리의 두 관절 위치는 길이를 유지하는 평면 IK 계산으로 정하고, 발은 지지 구간의 높이를 유지하며 회수 구간에서 들어 올린다. 몸통의 작은 상하 이동과 머리·꼬리 움직임을 추가했다. 뼈대가 완성된 범용 캐릭터 리그로 표현하지 않는다.

검토 성능을 위해 v3 털을 약 ¼ 밀도로 줄였다. 실제 파일의 털은 122,068가닥(별도 수염/눈썹 포함)이며 숨겨진 고해상도 조형은 모션 파일에서 제외했다. 원래 v3 원본은 상위 폴더에 보존한다. 4K 텍스처는 v3에서 이어받았다. 새 입 안쪽은 별도 절차적 재질이다.

구현 방식은 Blender의 [포인트 속성](https://docs.blender.org/manual/en/4.5/modeling/geometry_nodes/attributes_reference.html)과 [오브젝트 정보](https://docs.blender.org/manual/en/4.1/modeling/geometry_nodes/input/scene/object_info.html)를 이용한다.

## 확인한 범위와 남은 문제

`verify_motion.py`로 저장된 `.blend`를 다시 열어 평가된 몸체 메시를 1~49프레임에서 확인했다. NaN/무한 좌표 0건, 누락 텍스처 0건, 1/49프레임의 최대 정점 차이 0m. 발 변환에 거의 완전히 배정된 피부 정점 집합에서 지지 구간 최저 높이의 변화는 0m였다. 키프레임 컨트롤러 16개와 Hair Curves 오브젝트 4개를 확인했다. 꼬리 끝 정점군 중심의 좌우 이동 폭은 약 7.89cm였다. 얼굴 부품은 1/13/25/37/49프레임에서 비정상 좌표 0건, 루프 양끝 차이 0m. 몸체·입 안쪽·혀의 기본 메시 비매니폴드 모서리/면적 0인 면은 0건이었다. 전체 자가 교차 검사는 아니다. 상세 결과는 `reports/verification.json`에 있다.

피부 최저점은 프레임에 따라 바닥보다 약 0.61mm 아래로 내려간다. 이 검사는 모든 발바닥 부품, 털, 관절 사이의 충돌을 검증한 것이 아니다. 접힌 허벅지·어깨의 부피와 몸통 연결에는 압축·주름이 남아 있다. 변형용 수작업 토폴로지, 보정 쉐이프, 실제 동작의 해부학 검수는 미완료다. 완성된 달리기 모션이나 프로덕션 리그로 판정하지 않는다.

플레이어 DOM 검사에서 프레임 이동/경계 반복, 재생 시간에 따른 정상·¼ 속도 프레임 선택, 슬라이더, 방향 변경 시 프레임 유지, 주요 자세 이동, 방향키, 화면 밖 정지를 확인했다. 96개 렌더 경로가 모두 존재한다. 브라우저에서 실측한 FPS나 새로 수행한 브라우저 화면 검증은 아니다. 주요 실제 PNG는 시각 검토했다.

프로젝트 lint·typecheck·385페이지 빌드 통과. 52개 파일/1,661개 테스트 중 최초 실행의 시간 제한 1건은 해당 파일 5개 테스트 재실행에서 모두 통과했다. 테스트 설정과 제한 시간은 변경하지 않았다.

## 재생성

Blender 4.5.9에서 `--python build_motion.py -- build`로 원본과 주요 확인 프레임을 만들고 검토한다. 이후 `--python build_motion.py -- render side`, `--python build_motion.py -- render three-quarter`를 실행한다. `--python verify_motion.py`로 저장된 원본을 다시 검사한다. 제작 입력은 상위 `v3/exports/labrador-puppy-fur.blend`다.

`expression.py`가 얼굴 조형을 적용한다. `--python build_motion.py -- details`는 같은 원본의 확대 렌더를 만든다. `package_motion.py`는 PNG를 검사하고 WebP 미리보기와 전체 ZIP을 갱신한다.
