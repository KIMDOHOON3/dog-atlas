# 카드 뒷면 지역별 인물 · 2026-09-06

사용자는 출신 국가에 맞는 인물로 교체하되 뚜렷한 특징이 필요하지 않은 그림은 유지하도록 요청했다. 8장 모두 확인한 후 5장의 인물을 내장 ImageGen 편집으로 바꾸고, 피레니즈·그레이트 데인·아이리시 울프하운드는 기존 야외 복장을 유지했다.

| 카드 | 인물 방향 |
| --- | --- |
| 세인트 버나드 | 알프스 호스피스 수도사, 짙은 수도복과 방한 망토 |
| 티베탄 마스티프 | 갈색 모직 추바를 입은 고원 목축인 |
| 캉갈 | 밝은 펠트 목동 망토를 걸친 아나톨리아 목동 |
| 코카시안 셰퍼드 | 짙은 모직 망토를 걸친 산악 목동 |
| 몽골 방카르 | 청회색 델과 허리띠를 착용한 유목민 |

이는 특정 국가의 모든 사람을 대표하는 외모나 정확한 시대 복식 복원이 아니라, 견종의 역사·지역에 연결한 삽화다. 강아지의 크기·구도·배경과 글 여백을 유지하도록 편집했다. 의복은 절제된 생활 복장으로 표현했다.

자료: [호스피스 역사, 베른 자연사박물관](https://www.nmbe.ch/sites/default/files/2021-12/Barry_Broschuere_14_E.pdf), [티베트 의복, Smithsonian](https://www.si.edu/object/tibetan-clothing%3Ayt_YxbeIj1Eb_Q), [Kepenek, Türk Tarih Kurumu](https://sozluk.ttk.gov.tr/detay/10732/Kepenek-%28%DA%A9%D9%BE%D9%86%DA%A9-/-%D9%83%D9%BE%D9%86%D9%87%D9%83%29--), [몽골 국립박물관 델 소장품, MONTSAME](https://www.montsame.mn/en/read/245614). 코카서스는 특정 국가의 정복 대신 일반적인 산악 목축 복장으로 해석했다.
