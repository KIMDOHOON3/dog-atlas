# 흰색 래브라도 강아지 — 미완성 제작 시안

**요청한 상업용 포토리얼 품질에는 도달하지 못했다.** 실제 Blender 모델·털·텍스처·각 방향 렌더를 제작했지만 얼굴의 자연스러움과 변형용 프로덕션 토폴로지는 미충족이다. 납품 완료 또는 애니메이션에 바로 사용할 수 있는 모델로 판정하지 않는다.

[최신 뒷다리 수정 미리보기](motion-hindlegs/review.html) · [단계별·방향별 렌더 보기](review.html)

2026-09-13 정리: 중복 전달용 ZIP 9개는 로컬에서 제거했다. 각 버전의 Blender 원본·텍스처·프레임·제작 스크립트는 그대로 보존했다. ZIP은 필요할 때 패키징 스크립트로 생성한다. 최신본 재생성에 이전 버전 코드와 원본이 필요하므로 버전 폴더를 개별 삭제하지 않는다.

## v3 모션 — 48프레임 검토

모션 수정 2에서는 꼬리의 좌우 흔들기와 끝의 지연, 더 열린 눈과 살짝 벌린 입·올라간 입꼬리를 추가했다. 같은 플레이어에서 갱신된 96프레임과 얼굴 확대를 확인할 수 있다. Blender 원본과 전체 ZIP도 갱신했다.

[달리기 프레임 플레이어](motion/review.html)에 측면·3/4 각 48장과 이전/다음·슬라이더·정상/½/¼ 속도·다리 상태 표시를 추가했다. 현재 v3의 제자리 달리기 시안이며, 키프레임과 메시/털 변환이 들어 있는 별도 Blender 파일을 제공한다. 정적 모델과 고밀도 털 원본은 보존한다. 검토용 모션에서는 털 밀도를 약 ¼로 낮췄다. 관절 압축과 변형용 토폴로지는 미완료다. [원본·검수·제한](motion/README.md).

## v3 — 다운받은 리트리버를 참고한 측면 수정

사용자의 `golden-retriever-dog-3d-model-free.zip` 안 GLB를 Blender에서 열어 측면과 3/4 렌더를 확인했다. 긴 목, 처진 가슴 밑선, 짧은 어깨~골반 간격, 약한 뒷다리 굴곡을 비교했다. v3는 머리를 낮추고 목~등 윗선을 조정하며 가슴과 복부 밑선을 올리고 무릎~발목 각도를 바꾼 시안이다. 비례 변경 후 목의 접힌 표면을 국소적으로 완화하고 해당 부위의 털 시작점을 맞췄다.

수정 대상은 이 프로젝트의 v2 메시와 Hair Curves다. 참고 모델의 메시·텍스처를 이식하거나 결과물에 포함하지 않았다. 참고 모델은 성견 형태이므로 자견의 큰 머리·짧은 주둥이·큰 발은 v2에서 유지하며 일부 비례만 조정했다. 실측 해부학이나 포토리얼 품질이 완성됐다는 의미는 아니다.

`v3/exports`에 털 포함/제외 `.blend`와 OBJ·MTL, `v3/textures`에 v2에서 이어받은 4K 맵을 보존한다. UV와 털 가닥 수는 유지했으며 새 베이크나 새 리토폴로지를 했다고 주장하지 않는다. `v3/previews/03-*`는 털 없는 체형 확인용이고 나머지 최종 5방향은 털 포함 렌더다. 이전 v1/v2는 비교용으로 보존한다.

재생성: Blender에서 `--python silhouette.py -- shape` 실행 → 정면·측면·3/4 시각 검토 → `--python silhouette.py -- finish`. 원본 재열기/OBJ 재수입은 `--python verify_exports.py -- v3`. 검수 결과는 `v3/reports`에 기록한다.

## v2 — 얼굴 피부 연결 수정

후속 작업은 `v2/`에 분리하여 v1을 보존한다. 눈꺼풀 바깥쪽과 얼굴을 하나의 닫힌 조형으로 합치고, 눈의 열린 부분 바깥만 국소적으로 부드럽게 했다. 귀 안쪽을 뒤로 넣고 귀 곡률에 작은 차이를 추가했다. 이마 위로 돌출된 안구 윗부분은 확대 렌더와 화면 좌표의 광선 교차로 확인하여 돌출 범위를 줄였다. 수염·눈썹 뿌리는 새 피부에 맞춰 배치했다. 최종 확대 렌더에는 눈 위의 작은 표면 자국과 인공적인 눈매가 남아 있어 추가 조형이 필요하다.

**리토폴로지 단계는 미완료다.** 전체 QuadriFlow 변환은 실패했고, 기존 케이지에 새 얼굴을 투영하는 방식은 면 교차 551건 때문에 폐기했다. 이번 v2는 1,063,832면 고해상도 원본에서 줄인 340,426개 삼각형의 정적 렌더 메시다. 쿼드 프로덕션 메시로 표시하거나 v1의 케이지 수치를 v2에 적용하지 않는다. 수작업 얼굴·관절 토폴로지 및 변형 검증이 필요하다.

v2에도 4K 맵을 새로 베이크하고 털 491,121가닥과 수염·눈썹 가이드 26개를 다시 생성했다. 파일 구성은 `v2/exports`, `v2/textures`, `v2/previews`, `v2/reports`다. 체형 단계 1은 v1을 공통으로 사용하며 단계 2부터 별도 렌더를 제공한다. 아래 기존 단계 표와 검수 수치는 **v1 기록**이다. v2 최종 검사에서도 개별 메시의 열린 경계·비매니폴드·면 방향·퇴화/중복 면·음의 체적·비인접 삼각형 교차·누락 텍스처는 모두 0건이다. 최종 검수는 `v2/reports/06-audit.json`, 재불러오기는 `v2/reports/07-reopen.json`을 따른다. 이 수치가 부품 간 관통이나 조형 품질을 보증하지는 않는다.

v2 변경에서 lint·typecheck·1,661개 테스트·385페이지 빌드를 통과했다. 비교 화면의 60개 시안/단계/방향 조합에서 이미지 및 다운로드 경로를 코드로 확인했다. 브라우저 UI 재검증을 의미하지 않으며 실제 PNG는 별도로 시각 검토했다.

재생성은 Blender에서 `--python refine.py -- shape`, `topology`, `material`, `groom`, `render` 순서로 실행한다. v1 기본 `.blend`를 입력으로 쓰며 각 단계의 실제 렌더를 확인한 후 다음 단계를 실행한다. 재불러오기 검사는 `--python verify_exports.py -- v2`다.

## 파일

- `exports/labrador-puppy-fur.blend`: Hair Curves, 피부/눈/구강/발 부품, 조명·카메라와 숨겨진 고해상도 조형 원본을 포함한다.
- `exports/labrador-puppy-base.blend`: 털을 제거한 기본 메시 버전. 편집 가능한 기본 케이지와 고해상도 원본을 보존한다.
- `exports/labrador-puppy.obj`, `.mtl`: 털을 제외한 평가 메시와 재질. OBJ는 Blender Hair Curves를 담지 않는다.
- `textures/`: 공유 UV 아틀라스의 4,096×4,096 PNG 4장. Base Color는 sRGB, Roughness·Normal·Displacement는 Non-Color다. Blender 파일과 함께 상대 경로를 유지해야 한다.
- `previews/`: 6개 단계의 정면·측면과 최종 정면·측면·후면·3/4·얼굴 확대 렌더.
- `build.py`, `audit.py`, `verify_exports.py`: 제작·렌더·검수·재불러오기 스크립트. Blender 4.5.9에서 실행했다.
- `stages/01.blend`~`06.blend`: 로컬 단계별 작업 파일. 중복 바이너리이므로 Git에서는 제외하고 제작 스크립트와 최종 원본을 보존한다.

## 검사

최종 검사에서 개별 오브젝트의 열린 경계·비매니폴드·불일치 면 방향·음의 체적 성분·퇴화 면·중복 면·비인접 삼각형 교차·누락 텍스처는 모두 0건이었다. 두 `.blend`를 다시 열어 털 포함 6개 Hair Curves 오브젝트/털 제외 0개를 확인했고, OBJ를 빈 장면에 재불러와 59개 메시·245,730면과 텍스처 경로를 확인했다. 자세한 재불러오기 결과는 `reports/07-reopen.json`에 있다.

`reports/06-audit.json`에 오브젝트별 면 수, 비매니폴드/경계, 면 방향 일관성, 음의 체적 연결 성분, 퇴화·중복 면, 인접하지 않은 삼각형 교차, 이미지 경로와 해상도를 기록한다. 렌더 서브디비전에서 평가하며 보존된 고해상도 조형도 포함한다. 검사 중 얇은 입술/눈가의 열린 끝, 꼬리 찌그러짐, 무릎 안쪽의 작은 면 교차를 수정했다.

이 검사는 서로 다른 오브젝트 사이의 모든 관통을 제거했다는 뜻이 아니다. 안구/각막과 피부/입술처럼 의도적으로 접하거나 포개진 부품이 있고, 애니메이션 중 관통과 변형 품질은 검증하지 않았다.

프로젝트 lint·typecheck·52개 파일/1,661개 테스트·385페이지 빌드는 통과했다. 기존 Next Image quality 설정 경고가 있으며 이번 모델과 관련된 런타임 변경은 없다. 시안은 실제 사이트 운동장에 연결하지 않았다.

## 참고와 제작 방식

사용자가 지정한 [TurboSquid 제품](https://www.turbosquid.com/ko/3d-models/white-labrador-retriever-puppy-fur-for-maya-3d-model-2434583)은 브라우저 장치 확인 화면 때문에 직접 렌더를 확인하지 못했다. 동일 이름·판매자의 [CGTrader 공개 제품 렌더](https://www.cgtrader.com/3d-models/animal/mammal/white-labrador-retriever-puppy-fur-for-maya)에서 측면과 3/4 자세를 시각적으로 참고했다. 판매 모델이나 텍스처를 다운로드·추출하지 않았다. 이 작업의 형상과 텍스처는 Blender 스크립트로 제작했다.

재생성: Blender를 `--background --factory-startup --python build.py -- 1`로 실행하고 1~6을 순서대로 실행한다. 각 단계가 이전 `.blend`를 읽는다. 저장한 렌더를 직접 검토한 뒤 다음 단계를 실행한다. `review.html`은 외부 통신 없이 해당 PNG를 보여준다.
