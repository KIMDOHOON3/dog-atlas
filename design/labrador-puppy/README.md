# 흰색 래브라도 강아지 — 미완성 제작 시안

**요청한 상업용 포토리얼 품질에는 도달하지 못했다.** 실제 Blender 모델·털·텍스처·각 방향 렌더를 제작했지만 얼굴의 자연스러움과 변형용 프로덕션 토폴로지는 미충족이다. 납품 완료 또는 애니메이션에 바로 사용할 수 있는 모델로 판정하지 않는다.

[단계별·방향별 렌더 보기](review.html)

## 파일

- `exports/labrador-puppy-fur.blend`: Hair Curves, 피부/눈/구강/발 부품, 조명·카메라와 숨겨진 고해상도 조형 원본을 포함한다.
- `exports/labrador-puppy-base.blend`: 털을 제거한 기본 메시 버전. 편집 가능한 기본 케이지와 고해상도 원본을 보존한다.
- `exports/labrador-puppy.obj`, `.mtl`: 털을 제외한 평가 메시와 재질. OBJ는 Blender Hair Curves를 담지 않는다.
- `textures/`: 공유 UV 아틀라스의 4,096×4,096 PNG 4장. Base Color는 sRGB, Roughness·Normal·Displacement는 Non-Color다. Blender 파일과 함께 상대 경로를 유지해야 한다.
- `previews/`: 6개 단계의 정면·측면과 최종 정면·측면·후면·3/4·얼굴 확대 렌더.
- `build.py`, `audit.py`, `verify_exports.py`: 제작·렌더·검수·재불러오기 스크립트. Blender 4.5.9에서 실행했다.
- `stages/01.blend`~`06.blend`: 로컬 단계별 작업 파일. 중복 바이너리이므로 Git에서는 제외하고 제작 스크립트와 최종 원본을 보존한다.

## 검사

최종 검사에서 개별 오브젝트의 열린 경계·비매니폴드·불일치 면 방향·음의 체적 성분·퇴화 면·중복 면·비인접 삼각형 교차·누락 텍스처는 모두 0건이었다. 두 `.blend`를 다시 열어 털 포함 6개 Hair Curves 오브젝트/털 제외 0개를 확인했고, OBJ를 빈 장면에 재불러와 59개 메시·245,730면과 텍스처 경로를 확인했다. 자세한 재불러오기 결과는 `reports/07-reopen.json`에 있다.

`reports/06-audit.json`에 오브젝트별 면 수, 비매니폴드/경계, 면 방향 일관성, 음의 체적 연결 성분, 퇴화·중복 면, 인접하지 않은 삼각형 교차, 이미지 경로와 해상도를 기록한다. 렌더 서브디비전에서 평가하며 보존된 고해상도 조형도 포함한다. 검사 중 얇은 입술/눈가의 열린 끝, 꼬리 찌그러짐, 무릎 안쪽의 작은 면 교차를 수정했다.

이 검사는 서로 다른 오브젝트 사이의 모든 관통을 제거했다는 뜻이 아니다. 안구/각막과 피부/입술처럼 의도적으로 접하거나 포개진 부품이 있고, 애니메이션 중 관통과 변형 품질은 검증하지 않았다.

프로젝트 lint·typecheck·52개 파일/1,661개 테스트·385페이지 빌드는 통과했다. 기존 Next Image quality 설정 경고가 있으며 이번 모델과 관련된 런타임 변경은 없다. 시안은 실제 사이트 운동장에 연결하지 않았다.

## 참고와 제작 방식

사용자가 지정한 [TurboSquid 제품](https://www.turbosquid.com/ko/3d-models/white-labrador-retriever-puppy-fur-for-maya-3d-model-2434583)은 브라우저 장치 확인 화면 때문에 직접 렌더를 확인하지 못했다. 동일 이름·판매자의 [CGTrader 공개 제품 렌더](https://www.cgtrader.com/3d-models/animal/mammal/white-labrador-retriever-puppy-fur-for-maya)에서 측면과 3/4 자세를 시각적으로 참고했다. 판매 모델이나 텍스처를 다운로드·추출하지 않았다. 이 작업의 형상과 텍스처는 Blender 스크립트로 제작했다.

재생성: Blender를 `--background --factory-startup --python build.py -- 1`로 실행하고 1~6을 순서대로 실행한다. 각 단계가 이전 `.blend`를 읽는다. 저장한 렌더를 직접 검토한 뒤 다음 단계를 실행한다. `review.html`은 외부 통신 없이 해당 PNG를 보여준다.
