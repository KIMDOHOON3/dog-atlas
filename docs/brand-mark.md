# 승인된 로고와 행동 아이콘 — 2026-09-06

사용자가 후보 30개를 비교한 뒤 **L01 / F08 / D10**을 직접 선택하고 메인 적용을 승인했다.

| 용도 | 선택 | 웹 자산 | 크기 / 용량 |
|---|---|---|---|
| 한글 로고 | L01 책등의 리듬 | `public/images/brand/wordmark-l01.webp` | 624×208 / 37,508B |
| 뒤집어서 알아보기 | F08 대각선 회전 | `public/images/card-controls/flip-f08.webp` | 192×192 / 9,830B |
| 견종 자세히 보기 | D10 자세히 읽기 | `public/images/card-controls/detail-d10.webp` | 192×192 / 6,422B |

## 표현과 동작

- Pinterest 2번에서 사용자가 선택한 명확한 윤곽선·제한된 색·손그림·구분되는 실루엣을 기준으로 했다. 금박과 강한 입체 표현은 사용하지 않는다.
- 비교판의 원래 아이보리·세이지 색과 32px 아이콘 크기를 보존한다. 회색 필터나 밝기 보정은 적용하지 않는다.
- 로고는 156×52px, 모바일 126×42px. 아이콘은 두 버튼 모두 32×32px이며 버튼 터치 높이는 46px 이상이다.
- 홈 링크의 접근성 이름과 로고 대체 텍스트, 버튼 문구, reduced motion을 유지한다.
- 자세히보기는 현재 카드의 `/breeds/{slug}`를 가리킨다. 자동 prefetch를 끄고 기존 8종 상세로 연결한다.
- 이미지 세 개 합계 53,760B. 정적 자산으로 기존 WebGL 카드 렌더러에 작업을 추가하지 않는다.

## 제작·정리

각 시안은 built-in ImageGen으로 개별 생성했다. 승인된 원본은 `design/brand/wordmark-l01.png`, `flip-f08.png`, `detail-d10.png`, 최종 프롬프트와 매핑은 같은 폴더의 `prompts.json`에 보존했다. 기존 Sharp로 리사이즈·WebP 변환만 수행하고 투명 알파를 보존했다.

사용자 지시에 따라 3003 비교 서버를 중지하고 비교 페이지/비교판/미선택 원본·WebP·이전 로고 실험 자산을 삭제했다. 이번 생성 기록에 있는 미선택 원본 34개와 이전 별 모양 아이콘 원본 1개도 Codex 생성 폴더에서 명시적으로 삭제했다. 선택한 세 원본은 해시 일치를 확인한 뒤 별도 경로에 보존했다.
