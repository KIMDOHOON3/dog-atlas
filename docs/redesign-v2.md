# Dog Atlas redesign v2

## 0. 목표

첫 화면에서 사용자가 느껴야 하는 것은 “큰 문구를 읽는다”가 아니라 “한 마리의 강아지와 마주친다”이다.

이번 재설계는 다음 한 문장으로 판단한다.

> 재패니즈 스피츠를 귀엽고 생생하게 발견하고, 바로 검색하거나 다섯 견종을 둘러본 뒤, 상세에서 실제 생활까지 차분하게 이해한다.

제품 원칙은 유지한다.

- 호기심과 따뜻함으로 초대한다.
- 정보는 명확하고 비교 가능하게 제공한다.
- 견종의 특성은 일반적 경향으로 표현한다.
- 특정 견종을 정답으로 단정하지 않는다.
- 출처와 검수 상태는 숨기지 않되 첫인상의 주인공으로 만들지 않는다.

## 1. 현 화면에서 제거하거나 축소할 것

### 제거

- 영문 이니셜 `J`, 추상 원·언덕·발자국으로 구성된 `BreedVisual` 표현
- “일러스트 플레이스홀더”, “실제 외형 자료 아님”, “사진 준비 중”처럼 제작 상태를 전면에 노출하는 문구
- 모든 섹션에서 반복되는 거대한 세리프 제목과 인위적인 `<br>` 줄바꿈
- 홈 첫 화면 아래에 따로 떨어져 있는 대형 검색 섹션
- 사용자가 읽기 전에 내부 편집 상태를 길게 설명하는 카드

### 축소

- 상단 헤더 높이와 메뉴 개수
- 홈 히어로의 설명 문장 길이
- 섹션 사이 100px 이상의 공백
- 상세 페이지의 번호 타임라인 장식
- 출처·검수 상태의 시각적 비중

### 유지

- 편집형 도감이라는 방향
- 역사 → 역할 → 행동 경향 → 현대 생활의 연결
- 다섯 견종 데이터와 동일 기준 비교
- 검색, 관련 견종, 출처 필드
- 접근성, 성능, `prefers-reduced-motion`

## 2. 전체 시각 언어

### 인상

- 귀엽지만 유아적이지 않다.
- 밝고 부드럽지만 장난감 쇼핑몰처럼 보이지 않는다.
- 종이 도감, 자연사 삽화, 현대적인 반려동물 앱의 중간 지점이다.
- 화면마다 장식하기보다 강아지 실루엣, 이름, 핵심 정보의 위계를 분명히 한다.

### 컬러

기존 자연색 계열을 유지하되 대비와 사용 범위를 단순화한다.

| 토큰 역할 | 제안값 | 사용 |
|---|---|---|
| canvas | `#F7F4EC` | 페이지 바탕 |
| surface | `#FFFDF8` | 검색, 카드, 정보 패널 |
| ink | `#24302B` | 제목과 본문 |
| muted ink | `#69736E` | 보조 정보 |
| line | `#D9D4C8` | 구분선 |
| moss | `#3F6653` | 주 CTA, 활성 상태 |
| spitz tint | `#DFECE6` | 스피츠 히어로 배경 |
| warm tint | `#EFE4D2` | 생활 현실·주의 패널 |

- 한 화면에서 강한 배경색은 한 영역에만 사용한다.
- 견종별 팔레트는 히어로 배경과 카드 하단의 얇은 포인트에만 적용한다.
- 건강·주의 정보에는 분홍색 경고나 캐릭터 이모지를 사용하지 않는다.

### 타이포그래피

- 기본: Pretendard 또는 Noto Sans KR.
- 세리프는 역사 장면의 한 문장 인용처럼 제한된 곳에만 사용한다.
- 강제 줄바꿈을 최소화하고 컨테이너 폭으로 자연스럽게 줄을 바꾼다.

권장 데스크톱 크기:

- 홈 H1: 52~60px, 1.08, 최대 12~14자 단위의 짧은 문구
- 상세 견종명: 48~56px
- 섹션 H2: 30~36px
- 본문: 16~18px
- 카드 이름: 18px
- 메타: 12~14px

권장 모바일 크기:

- 홈 H1: 34~40px
- 상세 견종명: 34~38px
- 섹션 H2: 25~30px
- 본문: 15~17px

폰트 굵기는 400, 500, 700 세 단계만 사용한다.

### 모서리와 깊이

- 검색: 16px
- 견종 카드: 18px
- 큰 히어로 비주얼: 28px
- 정보 칩: 완전한 pill
- 그림자는 카드 hover 또는 히어로 비주얼에만 약하게 사용한다.
- 카드 외곽선을 모두 진하게 두르지 않는다. 배경색, 간격, 얇은 선으로 묶는다.

## 3. 공통 헤더

### 데스크톱 1440

- 콘텐츠 최대 폭: 1200px.
- 헤더 높이: 68px.
- 왼쪽: 로고 마크 + `강아지 도감` 임시명.
- 오른쪽: `견종 둘러보기`, `비교하기`, 검색 아이콘.
- 헤더 아래 진한 전체 폭 선은 제거하고 옅은 1px 구분선만 사용한다.

### 모바일 390

- 높이: 56px.
- 왼쪽: 작은 로고 + 짧은 서비스명.
- 오른쪽: 검색 아이콘, 메뉴 아이콘.
- 첫 화면을 방해하지 않도록 텍스트 메뉴는 숨긴다.

## 4. 홈 화면

### 4.1 데스크톱 1440 구조

첫 뷰포트 760~820px 안에 아래 세 가지가 모두 보여야 한다.

1. 재패니즈 스피츠 주인공 비주얼
2. 짧은 제품 메시지와 검색
3. 다섯 견종 카드의 상단 또는 전체

```text
┌──────────────────────────────────────────────────────────────┐
│ header                                                       │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  아직 모르는 강아지를       [재패니즈 스피츠 전신 일러스트] │
│  만나보세요.                  이름 라벨 / 오늘의 강아지      │
│                                                              │
│  생김새 너머의 역사와        배경: 낮은 풀, 작은 바람선      │
│  함께 사는 현실까지.                                         │
│                                                              │
│  [ 견종 이름을 검색해보세요                    🔍 ]          │
│                                                              │
│  [스피츠] [말티즈] [보더콜리] [그레이하운드] [사모예드]    │
└──────────────────────────────────────────────────────────────┘
```

#### 히어로

- 콘텐츠 폭 1200px, 좌우 48:52 비율.
- 높이 400~450px. 현재 `68vh`와 5.9rem 제목을 사용하지 않는다.
- 왼쪽 문구:
  - 보조 라벨: `살아 있는 강아지 도감`
  - H1: `아직 모르는 강아지를 만나보세요.`
  - 본문: `생김새 너머의 역사와, 함께 사는 현실까지.`
- CTA 버튼을 크게 두 개 놓지 않는다. 주 행동은 검색이며, `오늘의 강아지 보기`는 작은 텍스트 링크로 둔다.
- 오른쪽은 재패니즈 스피츠 3/4 전신 일러스트가 면적의 60% 이상을 차지한다.
- 스피츠의 얼굴·귀·꼬리가 제목보다 먼저 시선을 잡아야 한다.
- 배경 장식은 낮은 풀 선화, 바람선, 둥근 색면 한 개까지만 허용한다.
- `Living dog atlas · 001` 같은 내부 인덱스는 홈 첫 화면에서 제거한다.

#### 검색

- 히어로 왼쪽 본문 바로 아래 배치한다.
- 폭 480~520px, 높이 56px.
- 입력과 버튼을 하나의 surface로 묶는다.
- placeholder: `견종 이름을 검색해보세요`
- 검색 버튼은 아이콘 + `찾기`로 짧게 표현한다.
- 검색 오류는 입력 바로 아래 한 줄로만 노출한다.

#### 다섯 견종 카드

- 히어로 직후 20~28px 간격으로 바로 보인다.
- 데스크톱은 5열 고정, 카드 높이 190~220px.
- 카드 상단 65%는 견종 일러스트 또는 승인된 실루엣이다.
- 하단 정보는 다음 네 가지만 노출한다.
  - 견종명
  - 국가·지역
  - 핵심 성향 1개
  - 상세 이동 화살표
- 번호, 영문 이름, 계통, 긴 설명을 한 번에 넣지 않는다.

카드 예시:

```text
┌──────────────────┐
│                  │
│  [스피츠 전신]   │
│                  │
├──────────────────┤
│ 재패니즈 스피츠 ↗│
│ 일본 · 가족 교감 │
└──────────────────┘
```

카드별 첫 라벨 제안:

| 견종 | 국가·지역 | 카드 핵심 성향 |
|---|---|---|
| 재패니즈 스피츠 | 일본 | 가족과의 교감 |
| 말티즈 | 지중해권 | 사람 곁을 선호 |
| 보더콜리 | 영국 접경 | 높은 집중과 활동 |
| 그레이하운드 | 고대 기원의 시각 하운드 | 질주와 휴식의 리듬 |
| 사모예드 | 시베리아 북부 | 교감과 털 관리 |

표현은 현재 데이터의 검수 상태에 맞춰 조정한다.

### 4.2 첫 화면 아래 편집 섹션

카드 이후에는 균일한 그리드가 아니라 두 개의 큐레이션 섹션만 둔다.

1. `오늘 처음 만나는 강아지`
   - 한 견종을 큰 가로 카드로 소개.
   - 일러스트 45%, 한 문장과 2개 사실 55%.
2. `외모만 보면 놓치는 것`
   - 보더콜리와 그레이하운드의 서로 다른 생활 리듬을 2열로 소개.

현재의 `오늘의 발견`, `첫 번째 서가`, `다섯 견종 다섯 개의 하루`가 중복되므로 하나의 카드 목록으로 합친다.

섹션 사이 간격은 데스크톱 72px, 모바일 48px를 기본으로 한다.

```text

├────────────────────────┤
│ 살아 있는 강아지 도감  │
│ 아직 모르는 강아지를   │
│ 만나보세요.            │
│                        │

│                        │
│ [견종 이름 검색    🔍] │
│                        │
```

- 히어로는 텍스트 → 강아지 → 검색 순서.
- H1은 2~3줄 이내. 수동 `<br>` 없음.
- 강아지 비주얼 높이 220~250px.
- 검색은 가로 한 줄 유지. 버튼 글자는 숨기고 아이콘만 사용 가능.
- 카드는 2열, gap 10px, 높이 180~200px.
- 다섯 번째 카드는 두 열 전체 폭을 사용하거나 2열 카드와 같은 폭으로 왼쪽 정렬한다. 가로 캐러셀은 사용하지 않는다.
- 첫 화면에서 최소 2개 카드가 보여 다음 탐색을 암시해야 한다.

## 5. 견종 상세 화면

### 5.1 정보 우선순위

상세 진입 직후 사용자가 먼저 확인해야 하는 것은 다음이다.

1. 실제로 어떤 강아지인지 보이는 전신 비주얼
2. 견종 이름과 한 문장 요약
3. 국가, 크기, 평균 수명, 원래 역할
4. 핵심 성향 3개

역사적 서사는 이 기본 이해 뒤에서 시작한다.

### 5.2 데스크톱 1440 상세 히어로

```text
breadcrumb
┌──────────────────────────────────────────────────────────────┐
│ [스피츠 전신 일러스트] │ 재패니즈 스피츠                    │
│                         │ Japanese Spitz · 일본              │
│                         │ 가족 곁을 좋아하는 기민한 스피츠  │
│                         │                                    │
│                         │ [중소형] [10~14년] [스피츠 계열]  │
│                         │                                    │
│                         │ 활동 중간  교감 높은 편  털관리 높음│
└──────────────────────────────────────────────────────────────┘
```

- 콘텐츠 폭 1120~1200px.
- 좌우 50:50, 최소 높이 460px.
- 기존처럼 태그라인을 5rem H1으로 쓰지 않는다. H1은 견종명이다.
- 태그라인은 20~24px 한 문장으로 둔다.
- 기본정보 4개는 얇은 구분선이 있는 칩 또는 2×2 목록으로 제공한다.
- 성향 3개는 숫자 점수나 별점 없이 `중간`, `높은 편`, `개체별 확인` 같은 텍스트 배지로 제공한다.
- `이야기를 따라가 볼까요?` 대형 CTA는 제거한다. 스크롤이 자연스럽게 이어지도록 아래 섹션 일부가 보이게 한다.

### 5.3 실제 외형 확인

- 상세 히어로 일러스트 아래, 역사 섹션 전에 얇은 가로 영역으로 둔다.
- 승인 사진이 있으면 3장의 작은 갤러리: 성견 전신 측면 / 얼굴과 귀 / 피모와 체형 차이.
- 사진이 없으면 회색 dashed 박스를 노출하지 않는다.
- 대신 승인된 일러스트의 `정면`, `측면`, `뒤쪽 꼬리 형태` 3개 도식으로 구성하고 제목을 `대표 형태 살펴보기`로 쓴다.
- `사진 준비 중`, `라이선스 확인 중`은 사용자 화면에 표시하지 않는다.
- 에셋 상태는 접근 가능한 소형 메타로만 표시한다: `외형 자료: 일러스트 참고`.

### 5.4 상세 본문 순서

#### A. 역사와 원래 역할

- 제목: `어디에서, 어떤 역할을 하며 살아왔을까요?`
- 2열 구성: 역할 장면 일러스트 / 2~3문단 설명.
- 원산지 → 원래 역할 → 오늘의 행동 경향 연결을 화살표 도식 대신 한 문장 캡션으로 표현한다.
- 64px 원형 번호와 긴 세로선을 제거한다.

#### B. 행동 경향

- 6개 카드를 동일한 무게로 나열하지 않는다.
- 상단에는 핵심 3개: 활동, 사람과의 교감, 털 관리.
- 나머지 3개는 `더 알아보기` 아코디언 또는 작은 목록으로 제공한다.
- 각 항목은 라벨, 경향, 1문장 설명만 포함한다.
- 섹션 시작에 고지 1회: `견종의 일반적 경향이며 개체와 환경에 따라 달라질 수 있어요.`

#### C. 함께 사는 현실

- 따뜻한 모래색 배경의 넓은 패널.
- `예쁜 특징`과 `생활에서 필요한 책임`을 한 쌍으로 보여준다.

```text
풍성한 이중모  →  정기적인 빗질과 털갈이 관리
기민한 경계    →  소리 자극과 알림 짖음 관리
가족과의 교감  →  혼자 쉬는 연습도 천천히
```

- 긴 훈계 문장 대신 3개의 연결 항목을 사용한다.
- 그 아래 `평범한 하루`를 아침 / 낮 / 저녁의 3단 타임라인으로 제공한다.

#### D. 보호자의 한마디

- 검증된 경험이 아직 없으면 섹션 자체를 숨긴다.
- 내부 편집 계획을 사용자에게 보여주지 않는다.
- 데이터가 생기면 2~3문장 인용, 양육 기간, 생활 맥락만 표시한다.

#### E. 관련 견종과 비교

- `비슷해 보여도 생활은 달라요.`
- 재패니즈 스피츠와 사모예드를 나란히 보여주는 큰 비교 카드 1개.
- 보조 후보 말티즈는 작은 카드로 둔다.
- 비교 CTA: `스피츠와 사모예드 비교하기`.
- 추천 이유를 `닮은 점`과 `다른 점` 각각 한 줄로 구분한다.

#### F. 출처와 검수

- 페이지 맨 아래 `정보 출처와 편집 기준` 접이식 영역.
- 기본 닫힘 상태.
- 닫힌 상태에서도 `편집 초안 · 출처 1개 · 2026-08-01 확인`을 한 줄로 표시한다.
- 상세 내부에서 건강 정보가 미검수라면 해당 건강 섹션을 만들지 않는다. 큰 경고 상자로 대체하지 않는다.

### 5.5 모바일 390 상세

- breadcrumb은 한 줄의 작은 뒤로가기 링크로 단순화한다.
- 견종명과 한 문장 → 전신 비주얼 → 기본정보 2×2 → 핵심 성향 순서.
- 히어로 비주얼 280~320px.
- 역사 섹션은 일러스트 위, 텍스트 아래.
- 행동 경향 핵심 카드는 1열.
- 현실 연결 항목은 화살표 대신 위아래 2행으로 표시한다.
- 하루 타임라인은 세로 목록.
- 관련 견종 카드는 1열, 비교 CTA는 full width.
- 가로 스크롤이 필요한 표는 상세에 넣지 않는다.

## 6. 견종 카드 상세 명세

### 공통

- 전체가 링크.
- 최소 터치 영역 44px.
- 이미지 영역과 텍스트 영역의 배경을 분리하되 카드 전체는 하나의 면으로 보이게 한다.
- hover: 3px 위로 이동 + 그림자 강화. 이미지 확대는 최대 1.02배.
- focus-visible: 3px 파란색 또는 moss 대비 링.

### 정보 구조

```text
[견종 일러스트]

재패니즈 스피츠        ↗
일본 · 가족과의 교감
```

- 핵심 성향은 사실 검수 전 임의의 점수로 변환하지 않는다.
- `초보 추천`, `아파트 추천`, `키우기 쉬움` 배지를 사용하지 않는다.
- `희귀`, `SSR`, 수집 번호 같은 게임식 표기를 사용하지 않는다.

## 7. 이미지와 에셋

기존 `docs/design-visual-guide.md`의 혼합 원칙을 따른다.

- 히어로와 역사·역할: 통일된 일러스트.
- 외형 확인과 비교: 라이선스가 명확한 사진.
- 미검수 생성 이미지는 실제 외형 근거처럼 사용하지 않는다.

필요한 신규 에셋 이름:

```text
public/illustrations/v2/japanese-spitz-hero.webp
public/illustrations/v2/japanese-spitz-card.webp
public/illustrations/v2/japanese-spitz-role.webp
public/illustrations/v2/maltese-card.webp
public/illustrations/v2/border-collie-card.webp
public/illustrations/v2/greyhound-card.webp
public/illustrations/v2/samoyed-card.webp
```

- 아직 신규 에셋을 생성하지 않았다.
- 승인 전에는 기존 `BreedVisual`을 새 시안에 재사용하지 않는다.
- 이미지가 준비되기 전 구현용 임시 상태는 CSS 도형이 아니라 견종별 선화 실루엣이어야 한다.
- 실제 이미지를 제작할 때는 `design-visual-guide.md`의 견종 외형 체크리스트를 통과해야 한다.

## 8. 반응형 기준

| 구간 | 레이아웃 |
|---|---|
| 1200px 이상 | 최대 폭 1200, 홈 히어로 2열, 카드 5열 |
| 768~1199px | 히어로 2열 유지 가능, 카드 3열 또는 5개 재배치 |
| 480~767px | 히어로 1열, 카드 2열, 상세 모든 섹션 1열 |
| 320~479px | 좌우 16px, H1 34~38px, 카드 2열 유지 |

모바일에서는 첫 화면의 세로 길이를 줄이기 위해 헤더 + 메시지 + 스피츠 비주얼 + 검색을 약 650~720px 안에 배치한다.

## 9. 접근성과 성능

- 모든 견종 카드에는 견종명과 이동 목적이 포함된 접근 가능한 이름을 제공한다.
- 장식용 배경은 빈 대체 텍스트, 견종 전신은 외형과 자세를 간단히 설명하는 대체 텍스트를 사용한다.
- 검색 오류는 `aria-live="polite"` 유지.
- 밝은 배경 위 보조 텍스트 대비 4.5:1 이상.
- `prefers-reduced-motion`에서 hover 이동과 이미지 모션을 제거한다.
- 홈 히어로 이미지만 우선 로딩하고 카드·본문 이미지는 지연 로딩한다.
- 이미지 고유 폭과 높이를 지정해 레이아웃 이동을 방지한다.

## 10. 구현 순서

Root 검수 후 Dev는 다음 순서로 진행한다.

1. 글로벌 색·타입·간격 토큰 정리
2. 신규 헤더와 홈 첫 뷰포트
3. 5종 견종 카드
4. 재패니즈 스피츠 상세 히어로와 기본정보
5. 역사·행동 경향·생활 현실 섹션
6. 관련 견종과 비교 CTA
7. 출처 접이식 영역
8. 1440px / 390px 수동 검수

첫 구현 검수는 홈과 스피츠 상세까지만 한다. 비교 페이지의 시각 재설계는 동일한 카드와 정보 토큰이 안정된 뒤 이어간다.

## 11. Root 육안 검수 체크리스트

### 홈 1440

- 첫 시선이 문구가 아니라 재패니즈 스피츠에 가는가?
- 검색과 5종 카드가 첫 화면 또는 한 번의 짧은 스크롤 안에 보이는가?
- 제목이 3줄을 넘거나 어색하게 끊기지 않는가?
- 카드만 보고 이름·지역·핵심 차이를 빠르게 이해할 수 있는가?
- 내부 편집 상태 문구가 보이지 않는가?

### 홈 390

- 스피츠 얼굴과 전신이 잘리지 않는가?
- 검색을 바로 사용할 수 있는가?
- 최소 2개의 견종 카드가 다음 콘텐츠로 보이는가?
- 카드 텍스트가 3줄 이상 쌓이지 않는가?

### 상세 1440 / 390

- 진입 직후 견종명, 외형, 크기, 수명, 원래 역할이 보이는가?
- 역사와 책임이 기본 정보 뒤에 자연스럽게 깊어지는가?
- 미검수 정보가 거대한 경고 상자로 노출되지 않는가?
- 관련 견종과 비교로 끝 흐름이 이어지는가?
- 일러스트와 실제 외형 자료의 역할이 혼동되지 않는가?
