# 아기 곰 외형 시안

사용자 요청으로 제작한 앉아 있는 아기 곰의 첫 3D 외형 시안이다. 둥근 귀, 짧은 주둥이, 낮은 몸통과 굵은 앞다리, 바닥을 짚는 네 발을 표현했다. 기존 강아지 모델이나 외부 모델/텍스처를 사용하지 않고 Blender에서 형상을 구성했다.

- `bear-cub.blend`: 편집 가능한 Blender 원본, 1,213,299B.
- `bear-cub.glb`: 1,341,112B, 메시 4개·재질 4개. 리깅/애니메이션 없음.
- `preview.png`: 내보낸 GLB를 빈 Blender 장면으로 다시 불러온 뒤 조명과 배경을 추가해 렌더한 이미지.
- `create.py`: 형상 제작·내보내기·재불러오기·렌더 스크립트. Blender 4.5.9에서 실행 확인.

현재는 외형 검토용이며 푸터 런타임에는 연결하지 않았다. 기존 운동장과 나비는 유지한다. GLB 재불러오기와 렌더 이미지의 외형을 확인했다.
